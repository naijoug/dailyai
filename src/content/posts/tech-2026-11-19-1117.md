## 新产品
1. **Maritime**: a YC F26 “agent-native cloud” that gives each agent its own isolated, persistent microVM and configurable environment (Windows, Android, persistent browsers, custom images), plus services for provisioning, sleep/wake, triggers, scheduling, per-user spend caps and monitoring. The founders argue sandboxes solve “maybe 10%” of agent infrastructure; they note a $0.04/hour sandbox left running costs about $29 a month per user, which is why auto-snapshotting and event-driven wakeups matter. The site lists OpenClaw, Hermes, Claude Agent SDK and Codex among supported harnesses. https://maritime.sh [Launch HN](https://news.ycombinator.com/item?id=50549188)
> [zh] **Maritime**：YC F26 的「Agent 原生云」，给每个 Agent 分配独立、持久的 microVM 和可配置环境（Windows、安卓、保持登录态的浏览器、自定义镜像），并提供开通、休眠/唤醒、触发器、定时任务、按用户的花费上限和监控等服务。创始人认为沙箱只解决了 Agent 基础设施「大概 10%」的问题；他们算过，每小时 0.04 美元的沙箱若一直开着，每个用户每月约 29 美元，所以自动快照和事件驱动唤醒很关键。官网列出的可接入 harness 包括 OpenClaw、Hermes、Claude Agent SDK 和 Codex。
2. **Mastra Factory**: the open-source “software factory” Mastra uses to maintain its own TypeScript agent framework: a configurable agentic kanban board you can @-mention in Slack that turns issues into plans, implementations and reviewed PRs, built on Mastra’s durable agents, memory, a cited Markdown wiki and a cloud sandbox. The team says Factory opened and merged 238 PRs last week alongside 630 human PRs, and that they now mostly drive it from Slack and have closed the repo to outside contributors in favor of detailed issue repros. Start with `npm create factory`; it can run fully on your own infra. https://factory.mastra.ai [Show HN](https://news.ycombinator.com/item?id=50548660)
> [zh] **Mastra Factory**：Mastra 用来维护自家 TypeScript Agent 框架的开源「软件工厂」：一个可配置的 Agent 看板，能在 Slack 里 @ 它，把 issue 变成计划、实现和经过审查的 PR，底层用的是 Mastra 的持久化 Agent、记忆系统、带引用的 Markdown 知识库和云端沙箱。团队说上周 Factory 开出并合并了 238 个 PR，人类合并了 630 个；现在他们主要在 Slack 里驱动它，并对外部贡献者关闭了仓库，改为要求提交详细的问题复现。用 `npm create factory` 即可上手，也可以完全跑在自己的基础设施上。
3. **DaisyRose-27B**: RadixArk’s first model, Qwen3.8-27B post-trained with RL on its open-source Miles framework using about 1,200 curated long-horizon agent tasks (sessions up to 1M tokens) in 18 days on 144 H200s; it lifts Terminal-Bench 4.1 pass@1 from 5.6% to 12.0%. Tasks were built with Eigent AI, each redesigned to target a mistake the base model makes and screened against reward hacking; RadixArk says its backend reached 37% MFU versus 16% for the Megatron-based open-source trainer. BF16, FP8 and NVFP4 checkpoints are released. https://www.radixark.com/blog/daisyrose-27b [HN](https://news.ycombinator.com/item?id=50551046)
> [zh] **DaisyRose-27B**：RadixArk 的首个模型，在 Qwen3.8-27B 基础上用自家开源框架 Miles 做强化学习后训练，只用了约 1200 个精选长程 Agent 任务（单次会话最长 100 万 token），在 144 张 H200 上训练 18 天；Terminal-Bench 4.1 pass@1 从 5.6% 提到 12.0%。任务与 Eigent AI 合作构建，每个都针对基座模型会犯的错误重新设计，并逐个排查奖励作弊；RadixArk 称其训练后端的 MFU 达到 37%，基于 Megatron 的开源训练器只有 16%。已发布 BF16、FP8 和 NVFP4 权重。
4. **Clairic and Clairic-flash go open-weight**: Cloudflare, now calling its frontier research group the Workers AI superintelligence team, released an updated Clairic extraction model, redesigned since the preview with parallel slot autoregressive generation and special heads for estimates, durations, dates and arithmetic, plus a 9B Clairic-flash. Both now handle images and PDFs, keep confidence scores and character spans in the typed API, run on Workers AI, and have full weights on Hugging Face; in Cloudflare’s internal evals Clairic scored 1,263/1,263 on tracked customer assertions versus 1,033 for the preview. https://blog.cloudflare.com/open-clairic/
> [zh] **Clairic 与 Clairic-flash 开放权重**：Cloudflare 把前沿研究团队改称 Workers AI 超级智能团队，发布了更新版的 Clairic 信息抽取模型：相比预览版重新设计了架构，改用并行槽位自回归生成，并为估算、时长、日期计算和算术训练了专门的输出头；同时推出 90 亿参数的 Clairic-flash。两者都能处理图片和 PDF，类型化 API 里保留置信度和字符位置，托管在 Workers AI 上，完整权重放在 Hugging Face；在 Cloudflare 内部评测中，Clairic 在跟踪的客户断言上得 1263/1263，预览版是 1033。
5. **Mistral Vibe Desktop**: Mistral’s agent Vibe (formerly Le Chat) gets a desktop app for macOS and Windows (Linux planned) where you can hand it several tasks at once and watch them run in parallel. It combines Vibe CLI’s local features with Vibe Code Web’s cloud sessions, works in a local repo or a cloud sandbox, uses Git worktrees to keep parallel tasks apart, and its Work mode can now access local files; The Decoder notes Mistral doesn’t mention computer use, which rivals already offer. https://mistral.ai/products/vibe/ [The Decoder](https://the-decoder.com/mistral-plays-catch-up-with-vibe-desktop-as-rivals-already-command-full-operating-systems/)
> [zh] **Mistral Vibe Desktop**：Mistral 的 Agent Vibe（原 Le Chat）推出 macOS 和 Windows 桌面应用（Linux 版在计划中），可以一次交给它多个任务并看着它们并行执行。它把 Vibe CLI 的本地能力和 Vibe Code Web 的云端会话结合起来，可以在本地仓库或云端沙箱里工作，用 Git worktree 隔开同一项目里的并行任务，Work 模式现在也能访问本地文件；The Decoder 指出，Mistral 没提电脑操作能力，而竞争对手早已具备。
6. **RockDesk：给开发者和 AI Agent 用的 P2P 远程设备工具**：V2EX 楼主做的远控软件，一个 9 位数字 ID 管所有机器，点对点直连、端到端加密，支持远程桌面（最高 4K 60 帧）、终端、文件、端口转发和 VPN。亮点是自带 `rds` 命令行（`rds shell`、`rds mount` FUSE 挂载、`rds forward` 端口映射、剪贴板同步）以及开源 Agent Skill 和 MCP Server，让 Claude Code、Codex、WorkBuddy 等 Agent 能在另一台机器上执行命令、截图、点击和输入、拷文件。https://rockdesk.io [V2EX](https://www.v2ex.com/t/1258171)
> [en] **RockDesk: a P2P remote-device tool for developers and AI agents**: a remote-control app from a V2EX poster: one 9-digit ID for all your machines, peer-to-peer and end-to-end encrypted, covering remote desktop (up to 4K 60fps), terminal, files, port forwarding and VPN. The highlight is the built-in `rds` CLI (`rds shell`, `rds mount` via FUSE, `rds forward`, clipboard sync) plus an open-source Agent Skill and MCP server, so agents like Claude Code, Codex and WorkBuddy can run commands, take screenshots, click and type, and copy files on another machine.

## 科技新闻
1. **Two critical unauthenticated RCEs in NGINX, found with an AI harness**: Wiz Research, Ikotas Labs, Metnir, Rapid7 and Xint independently found CVE-2026-123633 (an HTTP/2 use-after-free) and CVE-2026-123007, both CVSS 4.0 9.2; both require HTTP/2, and the latter reaches back to NGINX 1.9.5 from 2015, with Wiz showing code execution on NGINX serving plain static files. F5 shipped fixes in its November 18 release. Wiz says it found both with Wiz Atlas, the harness behind its AI code scanning, and used Gemini 4 Carbon and ChatGPT 5.6 Sol to validate impact. Top HN comments note the fix landed in the open-source repo a week earlier with a “Reported by Xint.io” commit message, and that disabling HTTP/2 isn’t an option for gRPC-heavy services. https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities [HN](https://news.ycombinator.com/item?id=50547374)
> [zh] **NGINX 曝两个无需认证的严重远程代码执行漏洞，由 AI 工具链发现**：Wiz Research、Ikotas Labs、Metnir、Rapid7 和 Xint 各自独立发现了 CVE-2026-123633（HTTP/2 释放后使用）和 CVE-2026-123007，CVSS 4.0 评分均为 9.2；两者都要求开启 HTTP/2，后者可追溯到 2015 年的 NGINX 1.9.5，Wiz 演示了在只提供静态文件的 NGINX 上执行代码。F5 已在 11 月 18 日的版本中修复。Wiz 称它用自家 AI 代码扫描背后的 Wiz Atlas 找到了这两个漏洞，并用 Gemini 4 Carbon 和 ChatGPT 5.6 Sol 验证影响。HN 高赞评论指出，修复一周前就进了开源仓库，提交信息里还写着「Reported by Xint.io」；也有人说对大量使用 gRPC 的服务来说，关掉 HTTP/2 不现实。
2. **OpenAI says its models delivered a year of chip gains on AMD’s flagship GPU in under five months**: OpenAI reports up to 14% PPA improvement over heavily optimized baselines on AMD’s flagship GPU IP by having its model rewrite SystemVerilog RTL and verify each change with Synopsys tools; AMD has put some changes into a design sent for manufacturing and verified single-digit PPA gains on blocks of its next flagship CPU. On its own Jalapeño inference chip, model-proposed changes cut standard-cell area about 13% in the vector unit and 10% in the matrix unit, silicon-proven. In RISC-V tests GPT-6.2 Astra scored highest, and OpenAI is training GPT-Synopsys with Synopsys to drive EDA tools. https://openai.com/index/advancing-chip-design-with-our-models [HN](https://news.ycombinator.com/item?id=50549493)
> [zh] **OpenAI 称其模型在不到五个月里为 AMD 旗舰 GPU 做出了约一年的芯片优化**：OpenAI 表示，让模型重写 SystemVerilog RTL、并用 Synopsys 工具验证每处改动后，AMD 旗舰 GPU IP 在高度优化的基线上取得最高 14% 的功耗、性能、面积（PPA）改进；AMD 已把部分改动放进送去流片的设计，并在下一代旗舰 CPU 的关键模块上验证了个位数百分比的 PPA 提升。在 OpenAI 自研的 Jalapeño 推理芯片上，模型提出的改动让向量单元标准单元面积减少约 13%、矩阵单元减少约 10%，并已在硅片上验证。RISC-V 测试中 GPT-6.2 Astra 得分最高；OpenAI 还在与 Synopsys 合作训练会使用 EDA 工具的 GPT-Synopsys。
3. **Banks tell customers that whatever their AI agents do is on them**: TechCrunch reports Citi updated its online user agreement so customers who give third-party AI agents account access are responsible for what those agents do, including what hackers do if the tool leaks credentials; JPMorgan and Bank of America announced similar policies last month, PNC changed its terms this week, and Citizens emailed customers the same warning. It contrasts this with Anthropic’s new personal finance tool, billed as read-only. https://techcrunch.com/2026/11/18/more-banks-says-customers-using-ai-agents-are-on-their-own-even-if-they-get-hacked/
> [zh] **银行告诉客户：AI Agent 干了什么都由你自己负责**：TechCrunch 报道，花旗更新了网银用户协议：客户若授权第三方 AI Agent 访问账户，要为 Agent 的一切操作负责，连工具泄露凭据后黑客的所作所为也算在客户头上；摩根大通和美国银行上个月已宣布类似政策，PNC 本周修改了条款，Citizens 也给客户发邮件作出同样提醒。文章对比称，Anthropic 新推出的个人理财工具明确标榜「只读」。

5. **腾讯承认元宝「没有预期的那样成功」，大幅削减投入**：IT之家援引业绩会报道，腾讯总裁刘炽平表示元宝不再只把用户规模当目标，重心回到提升模型能力，腾讯已大幅削减在元宝上的投入；微信「小微」测试池持续扩大，日活 3000 万，全面上线后的季度成本将低于今年早些时候元宝的季度成本。腾讯三季度收入 2073.36 亿元、同比增 8%，非国际财务报告准则经营盈利同比降 6%，剔除新 AI 产品后同口径增长 8%。https://www.ithome.com/1/029/192.htm
