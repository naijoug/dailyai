## 新产品
1. **OpenMausBot: an open-source, local-first take on the "chat app full of AI bots" idea**: every bot in the sidebar is a real agent running on the `claude`, `codex` or `grok` CLI already installed on your machine (your own logins, no proxy), each with its own personality, model, connected apps (500+ via Composio) and a cloud Linux desktop or isolated local VM; one harness server on 127.0.0.1 owns all agent processes and keeps transcripts and keys in `~/.openmausbot`; Apache-2.0, macOS/Windows/Ubuntu builds, ~8.7k stars and on GitHub Trending today. https://www.openmausbot.com/ [GitHub](https://github.com/milind-soni/OpenMausBot)
> [zh] **OpenMausBot：把「装满 AI 机器人的聊天应用」做成开源、本地优先的版本**：侧边栏里每个机器人都是真正的 agent，跑在你本机已装好的 `claude`、`codex` 或 `grok` CLI 上（用你自己的登录，无中间代理），各有自己的性格、模型、连接的应用（经 Composio 接 500 多个）以及云端 Linux 桌面或隔离的本地虚拟机；一个监听 127.0.0.1 的 harness 服务统管所有 agent 进程，记录和密钥都存在 `~/.openmausbot`；Apache-2.0，提供 macOS/Windows/Ubuntu 安装包，约 8.7k star，今天上了 GitHub Trending。
2. **Palomino: run Claude Code, Codex and Pi side by side in one Rust, GPU-rendered Mac window**: tabs and panes mix agent chats with terminals, a browser and files, so you can watch tests, the dev server and the agent's edits together; free with unlimited workspaces and agents, and it already lists GPT-6.1 Terra. https://trypalomino.com/ [HN](https://news.ycombinator.com/item?id=50310055)
> [zh] **Palomino：在一个 Rust 编写、GPU 渲染的 Mac 窗口里并排跑 Claude Code、Codex 和 Pi**：标签页和窗格里可以混排 agent 对话、终端、浏览器和文件，测试、开发服务器和 agent 改动能同时看到；免费，工作区和 agent 数量不限，已支持 GPT-6.1 Terra。
3. **Tangled relaunches as "the federated code forge" on the AT Protocol**: self-host only the parts you want (Git hosting "knots", CI runners "spindles") or the whole stack including the API server and UI, and still collaborate with everyone else; extensions can subscribe to the firehose, someone already runs a knot on Cloudflare Workers, and the team pitches it as agent-friendly; lexicons are now stable, orgs shipped, private repos arrive in a couple of weeks. HN commenters want SHA-256 repo support. https://tangled.org/blog/forge/ [HN](https://news.ycombinator.com/item?id=50305573)
> [zh] **Tangled 以「联邦式代码托管平台」重新发布，基于 AT Protocol**：可以只自建想要的部分（Git 托管 knot、CI 运行器 spindle），也可以连 API 服务和界面整套自建，照样和其他人协作；扩展可以订阅 firehose，已有人把 knot 跑在 Cloudflare Workers 上，团队主打对 agent 友好；lexicon 已稳定，组织功能上线，私有仓库几周内推出。HN 评论区希望支持 SHA-256 仓库。
4. **nesformer: an NES CPU compiled into the weights of a stock Qwen3.5 model**: the 6502 CPU, 2 KB of work RAM and the cartridge ROM live inside a standard `Qwen3_5ForCausalLM` checkpoint whose weights were computed by a compiler, not trained; the model predicts the CPU execution log token by token while a small host draws frames, reads the controller and fires vblank, and test games match a conventional emulator frame for frame (Super Mario Bros. World 1-1 runs). Built on Qwenputer's trick of using Gated DeltaNet state as memory. HN (189 points) is split between delight and "of course logic reduces to weights". https://github.com/dbreunig/nesformer [HN](https://news.ycombinator.com/item?id=50306442)
> [zh] **nesformer：把一颗 NES CPU 编译进原版 Qwen3.5 模型的权重**：6502 CPU、2 KB 工作内存和卡带程序 ROM 都放进一个标准的 `Qwen3_5ForCausalLM` 检查点，权重全由编译器算出而非训练；模型逐 token 预测 CPU 执行日志，一个小宿主程序负责画面、手柄和 vblank 中断，自带测试游戏与常规模拟器逐帧一致（能跑超级马里奥 1-1）。沿用 Qwenputer 把 Gated DeltaNet 状态当内存的技巧。HN（189 分）评论一半叫好，一半觉得「数字电路当然能化成权重」。

## 科技新闻
1. **Northflank breached: assume every environment variable is decrypted, and customers' AI API keys are already being abused**: after a Wiz threat alert at 11:43 UTC on Oct 30 the PaaS told all users to rotate every secret (workload secrets, secret groups, global secrets), disable public access to addons and rotate Postgres/MongoDB credentials; by 23:38 UTC users confirmed unauthorized use of the AI keys they had stored, with IPs resembling those in Wiz's "Black October" report on attacks targeting AI credentials; audit logs are now on for everyone, free tier included. HN (358 points) reads it, after Railway, as a push back toward hyperscalers. https://status.northflank.com [HN](https://news.ycombinator.com/item?id=50305025)
> [zh] **Northflank 遭入侵：所有环境变量都应视为已被解密，用户存的 AI API 密钥已被盗用**：10 月 30 日 11:43 UTC 收到 Wiz 威胁告警后，这家 PaaS 要求所有用户轮换全部密钥（workload secrets、secret groups、global secrets），关闭附加组件的公网访问，并轮换 Postgres/MongoDB 凭据；到 23:38 UTC，已有用户确认存放的 AI 密钥被盗用，攻击 IP 与 Wiz《Black October》报告里针对 AI 凭据的攻击相似；现已为所有用户（含免费版）开启审计日志。HN（358 分）认为继 Railway 之后，这会把企业推回大云厂商。
2. **OpenAI, Google, Microsoft and Anthropic will honor one shared AI-training opt-out in robots.txt**: a "policy token" proposed at the IETF by Anthropic standards lead Kevin Kelley lets publishers state their AI training preference once for multiple crawlers instead of setting it company by company. https://www.theverge.com/tech/1023763/openai-google-microsoft-ai-scraping-standard-opt-out
> [zh] **OpenAI、谷歌、微软和 Anthropic 将遵守 robots.txt 里统一的 AI 训练退出标记**：由 Anthropic 标准技术负责人 Kevin Kelley 在 IETF 提出的「policy token」，让网站只需声明一次 AI 训练偏好就对多家爬虫生效，不必逐家设置。
3. **"AI isn't replacing SREs, it's deskilling them"**: SigNoz's essay applies Bainbridge's 1983 "Ironies of Automation" to incident response: if AI handles 95% of incidents, humans get less practice for the novel 5% that matters most. Top HN thread (501 points): one team spent two hours debugging with Claude what was obvious without it, and others suggest weekly hand-coding hours or having the agent quiz you before merging. https://newsletter.signoz.io/p/ai-isnt-replacing-sres-its-deskilling [HN](https://news.ycombinator.com/item?id=50305693)
> [zh] **《AI 没在取代 SRE，而是在让他们退化》**：SigNoz 的文章用 Bainbridge 1983 年的《自动化的反讽》分析故障响应：AI 处理掉 95% 的事故后，人反而更缺练习，应付不了最关键的那 5% 新型故障。HN 热帖（501 分）里有人说团队花两小时让 Claude 排查一个不用它也一眼能看出的问题；也有人建议每周留出手写代码时间，或合并前让 agent 先考考自己。
4. **AI spending jitters hit markets, and OpenAI trims its round**: per the FT via Techmeme, OpenAI now seeks about $20B at a $1.25T valuation, down from $30B at $1.4T, as some investors cut commitments; TechCrunch notes Big Tech plans over $740B in capex this year while the Nasdaq fell 2.9% Friday and Alphabet reported negative free cash flow of $9.1B in Q3. https://www.techmeme.com/261030/p30#a261030p30 [TechCrunch](https://techcrunch.com/2026/10/30/cracks-are-emerging-in-the-ai-spending-boom/)
> [zh] **AI 投入焦虑冲击市场，OpenAI 下调融资目标**：据 FT（经 Techmeme），部分投资人削减认购后，OpenAI 本轮改为以 1.25 万亿美元估值融资约 200 亿美元，原计划是 1.4 万亿估值融 300 亿；TechCrunch 指出大厂今年资本开支计划超过 7400 亿美元，而周五纳斯达克跌 2.9%，Alphabet 三季度自由现金流为负 91 亿美元。
