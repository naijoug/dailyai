## 科技新闻
1. **Kimi K3.1 Pro weights are out: 2.8T-parameter MoE, 104B active, 1M context**: Moonshot's open-weight multimodal agentic model (MXFP4 quantization-aware training, KDA + gated DeepSeek Sparse Attention) reports 65.7 on Terminal-Bench 4.0 vs 66.4 for Claude Opus 5.5 and ranks #1 among open-weight models on Agent Arena; API on platform.kimi.ai, recommended on vLLM/SGLang. HN (~400 points) noted few can run it locally—BF16 weights are ~5.6TB—so the value is in third-party hosting; Huawei announced day-0 Ascend support. https://huggingface.co/moonshotai/Kimi-K3.1-Pro [HN](https://news.ycombinator.com/item?id=50366999)
> [zh] **Kimi K3.1 Pro 开放权重：2.8 万亿参数 MoE，激活 1040 亿，1M 上下文**：月之暗面的开源多模态 Agent 模型（MXFP4 量化感知训练，KDA + 门控 DeepSeek 稀疏注意力），Terminal-Bench 4.0 得分 65.7（Claude Opus 5.5 为 66.4），在 Agent Arena 开源模型中排第一；API 在 platform.kimi.ai，推荐用 vLLM/SGLang 部署。HN（约 400 分）讨论指出很少有人能本地跑——BF16 权重约 5.6TB——意义更多在第三方托管压价；华为宣布昇腾 0 Day 支持。
2. **Debian APT MITM can swap a package after verification and run code as root (CVE-2026-109518)**: per DSA-6607-1, APT can merge two different downloads after an HTTP redirect gives them the same URI, and improper file handling when resuming an HTTP download allows the swap; found by Max Justicz. Fixed in apt 3.0.4 for trixie (with several out-of-bounds fixes); no exploitation reported, and Ubuntu and other apt-based distros hadn't published status yet. https://pwn.watch/i/debian-apt-http-resume-mitm-root-rce-cve-2026-109518 [HN](https://news.ycombinator.com/item?id=50366575)
> [zh] **Debian APT 中间人可在校验后替换软件包并以 root 执行代码（CVE-2026-109518）**：据 DSA-6607-1，HTTP 重定向让两个不同下载的 URI 相同时 APT 会把它们合并，加上断点续传时文件处理不当，攻击者就能在校验后调包；由 Max Justicz 发现。trixie 已在 apt 3.0.4 修复（同时修了几个越界访问）；暂无利用报告，Ubuntu 等基于 apt 的发行版尚未公布状态。
3. **Cloudflare adds analytics and per-agent access policies for personal AI agents**: Security Analytics now shows "Personal Assistants" as a bot category, with a widget listing which agents visit, which paths they hit and which status codes they get; Account Abuse Protection (early access) shows which user each agent acts for. The renamed "AI Crawler and Agent access policies" let sites Allow, Block on pages with ads, or Block each supported personal agent; next up is carrying user context and accountability through agents. https://blog.cloudflare.com/personal-agents-visibility-control/
> [zh] **Cloudflare 为个人 AI Agent 推出流量分析和按 Agent 设置的访问策略**：Security Analytics 新增「Personal Assistants」机器人类别，并有组件列出来访的是哪些 Agent、访问了哪些路径、收到哪些状态码；账户滥用防护（早期访问）可看到每个 Agent 代表的是哪位用户。改名后的「AI Crawler and Agent access policies」可对每个受支持的个人 Agent 设为放行、在有广告的页面拦截或直接拦截；下一步是让用户上下文和责任归属能随 Agent 传递。
4. **Uber: only four rides were booked by an AI agent in its busiest week**: on the Q3 call, the CFO said the Halloween week saw ~320M trips and orders across Uber and Uber Eats, but just 4 rides and ~500 Eats orders came via AI agents; CEO Dara Khosrowshahi called it "very, very early," noting a ride takes 50 seconds to book in the app—echoing DoorDash's "few hundred" agent orders last week. https://techcrunch.com/2026/11/04/almost-no-one-uses-ai-agents-to-book-their-uber-company-says/
> [zh] **Uber：最忙的一周里只有 4 单是 AI Agent 叫的车**：财报电话会上 CFO 称，万圣节那周 Uber 和 Uber Eats 共约 3.2 亿单，Agent 下单的只有 4 单打车和约 500 单外卖；CEO Dara Khosrowshahi 说「非常非常早期」，并指出在 App 里叫车平均只要 50 秒——与 DoorDash 上周说的「几百单」相呼应。

> [zh] **曝苹果把工程师每日 AI 花费上限从 300 美元降到 200 美元，下一步降到 100 美元**：据彭博社，后续还会继续削减，工程部门以外甚至考虑每天 25 美元的上限——又一个迹象：今年「狂刷 token」之后，账单到期，企业开始给 token 定量配给。

> [en] **InfoQ: Rocky Linux founder used Codex to write Ginux, a 139k-line new kernel, in 11 days—and it boots Rocky Linux 10**: with "human-directed agentic engineering" in one long-running Codex task (GPT-5.6 Sol), Gregory Kurtzer built a mostly-Rust x86-64 kernel from scratch that implements the Linux ABI and reaches systemd's multi-user.target; about $8,000 in API costs, Apache 2.0. > [en] **V2EX: mcp-meta folds 104 MCP tools into 2 lazy-loading meta-tools, cutting per-turn schema size by 99.4%**: with 14 servers attached, the author's model burned 142k characters of tool schemas before reading the prompt; mcp-meta sits between client and upstream servers and exposes only `mcp_tools` (fetch a server's tool list on demand as compact signatures) and `mcp_call`, bringing each turn down to 892 characters; pure Python stdlib, stdio/HTTP, MIT-licensed.
