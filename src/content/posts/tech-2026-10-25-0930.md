## 新产品
1. **OpenShell: NVIDIA's open-source sandbox runtime that lets agents work without unrestricted access**: Apache-2.0 runtime for fleets of autonomous agents — each agent runs in an isolated sandbox with kernel-level enforcement of file, syscall and network policy; real credentials never enter the sandbox and are injected only onto requests bound for approved endpoints. Policy changes are formally verified before apply so risky new hosts or API methods wait for human review. Install with one curl script; needs Linux, Apple Silicon macOS, or Windows WSL2 plus Docker/Podman. Docs and a 0.1.x upgrade guide are up; ~19k GitHub stars and trending overnight. https://docs.nvidia.com/openshell/latest/ [GitHub](https://github.com/NVIDIA/OpenShell)
> [zh] **OpenShell：NVIDIA 开源的沙箱运行时，让 Agent 能干活却拿不到无限制权限**：Apache-2.0，面向大规模自治 Agent——每个 Agent 跑在隔离沙箱里，内核层强制文件、系统调用和网络策略；真实凭证不进沙箱，只在发往已批准端点的请求上注入。策略变更上线前会做形式化验证，新主机或新 API 方法要等人工审。一条 curl 安装；需 Linux、Apple Silicon macOS 或 Windows WSL2，外加 Docker/Podman。文档和 0.1.x 升级指南已上线；GitHub 约 1.9 万星，夜间登上趋势。
2. **Impeccable: design vocabulary for AI coding agents — 1 skill, 24 commands, 62 detector rules**: install with `npx impeccable install`, then `/impeccable init` writes durable product truth into `PRODUCT.md`. Commands cover craft, audit, critique, polish, distill, animate, live browser iteration and more; the CLI and browser extension run 62 deterministic anti-slop detectors with no LLM or API key. Works with Claude Code, Codex, Cursor, Gemini CLI, OpenCode and others. Site: impeccable.style; ~86k GitHub stars. https://impeccable.style [GitHub](https://github.com/pbakaus/impeccable)
> [zh] **Impeccable：给 AI 编程 Agent 用的设计词汇——1 个 skill、24 条命令、62 条检测规则**：`npx impeccable install` 安装，再跑 `/impeccable init` 把产品事实写入 `PRODUCT.md`。命令覆盖 craft、audit、critique、polish、distill、animate、浏览器里实时迭代等；CLI 和浏览器扩展可零 LLM、零 API key 跑 62 条确定性「反 AI 审美垃圾」检测。支持 Claude Code、Codex、Cursor、Gemini CLI、OpenCode 等。官网 impeccable.style；GitHub 约 8.6 万星。
3. **Perch: a calm Mac home for Claude Code sessions, PRs and next steps**: free beta for Apple Silicon — bring existing Claude Code sessions over, see every session/PR/link in one place, and get notified only when Claude, a reviewer or CI is waiting on you. Contexts and notes stay in a local database (no Perch account or servers); GitHub via your `gh` login; Claude talks to Anthropic the same way as without Perch. Quit or update and sessions keep running. https://perchfocus.com [Show HN](https://news.ycombinator.com/item?id=50225233)
> [zh] **Perch：给 Claude Code 会话、PR 和下一步用的安静 Mac 工作台**：Apple Silicon 免费 beta——把已有 Claude Code 会话迁过来，所有会话/PR/链接一处看清，只在 Claude、审阅人或 CI 等你时提醒。上下文和笔记存在本地库（无 Perch 账号或服务器）；GitHub 走你自己的 `gh` 登录；Claude 连 Anthropic 的方式和不用 Perch 时一样。退出或更新后会话继续跑。
4. **Scrawl: show an agent the problem on your screen — talk, click, draw, paste**: Mac app (Homebrew cask / zip; Windows preview) — press ⌥⇧S, narrate and annotate while it records frames only when you draw, click, say “look”/“now”, or the screen changes; each sentence sticks to its frame, cropped to the window you worked in. Paste into your agent; `bunx skills add kitlangton/scrawl` teaches agents to read the contact sheet and zoom in. Can mirror an iPhone screen or embed ScrawlKit in an iOS app. https://scrawl.kitlangton.com [GitHub](https://github.com/kitlangton/scrawl) [Lobsters](https://lobste.rs/s/jqjioq)
> [zh] **Scrawl：把屏幕上的问题展示给 Agent——边说边点边画，再粘贴过去**：Mac 应用（Homebrew cask / zip；Windows 预览）——按 ⌥⇧S，边讲解边标注；只在你画、点、说「look」/「now」或画面变化时截帧，每句话贴在对应帧上，并裁到你操作的窗口。粘贴给 Agent；`bunx skills add kitlangton/scrawl` 可教 Agent 读联系表并放大细看。可镜像 iPhone 屏幕，或把 ScrawlKit 嵌进 iOS 应用。

## 科技新闻
1. **Apollo: no signs of AI payoff outside the tech sector**: Chief Economist Torsten Slok's Daily Spark (Oct 24) says despite massive AI spend and hype, revenue per worker and profit margins are rising for the Mag 7 but flat for the S&P 493, with no clear TFP boost. Mainstream firms are starting to treat token spend as a margin-hurting cost center rather than a growth engine; VC-backed companies keep buying tokens, but most of corporate America won't pay for the latest model. Bottom line: the AI story will be decided in the S&P 493, not the Mag 7. ~475 points on HN. https://www.apollo.com/wealth/insights-news/insights/daily-spark/no-signs-of-ai-payoff-outside-the-tech-sector [HN](https://news.ycombinator.com/item?id=50224463)
> [zh] **Apollo：科技圈外尚无 AI 财务回报迹象**：首席经济学家 Torsten Slok 的 Daily Spark（10 月 24 日）称，尽管 AI 投入和声浪巨大，Mag 7 的人均营收和利润率在升，但标普 493 持平，全要素生产率也未见明显抬升。主流企业开始把 token 开支当成拖累利润率的成本中心而非增长引擎；VC 公司仍在买 token，但多数美国企业不愿为最新模型买单。结论：AI 故事要在标普 493 而非 Mag 7 里见分晓。HN 约 475 分。
2. **Keycloak unauthenticated account takeover gets a public exploit (CVE-2026-18963)**: a flaw in the reset-credentials flow lets an unauthenticated attacker force a password reset for any user without the emailed verification link, then set new credentials. Red Hat rates CVSS 9.1; fixes shipped in August (26.4.15 / 26.6.6 / 26.7.2). On Oct 21 Exploit-DB published a full PoC (EDB-52699) with check and takeover modes — unpatched instances should upgrade now. https://pwn.watch/i/keycloak-cve-2026-18963-reset-credentials-takeover
> [zh] **Keycloak 未认证账号接管漏洞已有公开利用（CVE-2026-18963）**：重置凭证流程的缺陷让未认证攻击者可在不点邮件验证链接的情况下，强制任意用户重置密码并写入新凭证。Red Hat 评 CVSS 9.1；修复已在 8 月放出（26.4.15 / 26.6.6 / 26.7.2）。10 月 21 日 Exploit-DB 发布完整 PoC（EDB-52699，含检测与接管模式）——未打补丁的实例应立刻升级。
3. **Okta Access Gateway: admin-console RCE plus auth-source bypass (CVE-2026-115547 / 115546)**: Okta fixed two on-prem OAG bugs on Oct 22 — CVE-2026-115547 (CVSS 9.1) lets an authenticated admin run system commands as the OAG service account via crafted config values; CVE-2026-115546 (CVSS 8.1) lets any user with a valid session change the authentication-source parameter at sign-on and get a SAML assertion for the Admin Console. Combined, a regular gateway user could potentially reach command execution. Fixed in 2026.10.2; OAG's bundled PHP also got PHP2Shell fixes in 2026.44.0. Okta cloud is unaffected. https://pwn.watch/i/okta-access-gateway-cve-2026-115547-115546
> [zh] **Okta Access Gateway：管理控制台命令执行 + 认证源绕过（CVE-2026-115547 / 115546）**：Okta 10 月 22 日修复两个本地部署 OAG 漏洞——CVE-2026-115547（CVSS 9.1）让已认证管理员通过特制配置值以 OAG 服务账号跑系统命令；CVE-2026-115546（CVSS 8.1）让任意有效会话用户在登录时改认证源参数，拿到管理控制台的 SAML 断言。合在一起，普通网关用户或可达命令执行。修复版本 2026.10.2；自带 PHP 的 PHP2Shell 补丁在 2026.44.0。Okta 云端不受影响。
4. **The Goose Programming Language: memory-safe systems language with no heap, GC, or lifetime annotations**: by Wouter van Oortmerssen — every dynamic value lives inline on compiler-managed data stacks; growth is a pointer bump and memory frees when its scope ends. Claims faster than C++/Rust with less memory on its own benchmarks; syntax familiar to C/Rust programmers, with stable references that survive growth and no annotation-heavy borrow checker. John Carmack linked it; ~237 points and 160 comments on HN. https://aardappel.github.io/goose/ [HN](https://news.ycombinator.com/item?id=50224100)
> [zh] **Goose 编程语言：无堆、无 GC、无生命周期标注的内存安全系统语言**：Wouter van Oortmerssen 之作——动态值都内联放在编译器管理的数据栈上，增长只是指针前移，作用域结束即释放。自有基准上声称比 C++/Rust 更快、更省内存；语法接近 C/Rust，引用在增长后仍稳定，也没有标注繁重的借用检查。John Carmack 转发；HN 约 237 分、160 条评论。
