## AI 热点
1. **The Information: DeepSeek and Moonshot relied heavily on GPT-6 Astra outputs to train their latest models**: Moonshot's Kimi K3.1 Pro (released last week) and DeepSeek's V4.1-Flash 1017 (Oct 17) reportedly benefited from distilling Astra; OpenAI had already tied a July distillation campaign to people linked to Moonshot on Sept 30, and none of the three companies has commented yet. https://www.theinformation.com/topics/ai-model-distillation | https://www.investing.com/news/stock-market-news/deepseek-moonshot-used-openaisgpt6-astra-to-train-latest-models-the-information-reports-4981380
> [zh] **The Information：DeepSeek 和月之暗面训练最新模型时大量使用 GPT-6 Astra 的输出**：据报道，月之暗面上周发布的 Kimi K3.1 Pro 和 DeepSeek 10 月 17 日的 V4.1-Flash 1017 都受益于蒸馏 Astra；OpenAI 9 月 30 日已把 7 月开始的一次蒸馏行动追溯到与月之暗面有关的人员，三家公司暂未回应。
2. **Android Studio Rabbit 2 adds Bring Your Own Agent via the open Agent Client Protocol**: you can install 40+ ACP-compatible agents (Claude, Codex, Antigravity and more) directly in the IDE and pick your own models; the release also adds an agent skills manager and AI code review. https://x.com/AndroidStudio/status/2115518965392752861 | https://x.com/EricDevWang/status/2115592914076364908
> [zh] **Android Studio Rabbit 2 通过开放的 Agent Client Protocol 支持「自带 Agent」**：可以在 IDE 里直接安装 40 多个兼容 ACP 的 Agent（Claude、Codex、Antigravity 等）并自选模型；这一版还加了 agent skill 管理器和 AI 代码审查。
3. **AI audit of 138 Saez-Zucman economics papers flags 2,035 issues**: two AI models reviewed each paper independently and a third graded the problems; 147 issues were judged serious enough to change key findings, nearly all overstating inequality or tax effects, and economist Phil Magness notes it caught a major error he had flagged back in 2019, while critics question the method. https://x.com/i/trending/2115553123917758929 | https://x.com/PhilWMagness/status/2115653053793685937
> [zh] **AI 审计 Saez 与 Zucman 的 138 篇经济学论文，标出 2035 处问题**：每篇由两个 AI 模型独立审查、第三个模型给问题定级；其中 147 处被认为足以改变核心结论，几乎都偏向高估不平等或税收效应；经济学家 Phil Magness 说它抓到了他 2019 年就指出过的一个重大错误，也有人质疑这种方法。
4. **Shopify 发布 Fall '26 Editions「Exponential」**：主线是让商品、结账和店铺管理进入 ChatGPT、Claude、Gemini、Copilot、Muse、Grok Bot 等 Agent，Shop Pay 可接入个人 Agent，也能在非 Shopify 店铺结账并开放给开发者；商家后台的 Sidekick、营销自动化和支付风控也同步升级。https://x.com/shao__meng/status/2115644731493650643 | https://x.com/tobi/status/2115476197572506077
> [en] **Shopify ships Fall '26 Editions "Exponential"**: the theme is bringing products, checkout and store management into agents such as ChatGPT, Claude, Gemini, Copilot, Muse and Grok Bot; Shop Pay can plug into personal agents, check out on non-Shopify stores and is open to developers, while Sidekick, marketing automation and payment risk tools in the merchant admin also get upgrades.

## 有趣用法和干货
1. **宝玉发布 baoyu-design v2，开源移植 Claude Design、Claude Slides 和 Claude Dashboard**：体验和原版几乎一致（只缺评论功能），可以跑在任何 Agent、任何模型上，不再依赖 Claude Artifacts。https://github.com/jimliu/baoyu-design | https://x.com/dotey/status/2115667965328977920
> [en] **baoyu releases baoyu-design v2, an open-source port of Claude Design, Claude Slides and Claude Dashboard**: the experience is nearly identical to the originals (only comments are missing), and it runs on any agent and any model without depending on Claude Artifacts.
2. **DeepLearning.AI 新课「Context Engineering」**：把上下文工程当成让 Agent 在长链路任务里可靠又省 token 的主线，重点是管好给模型看什么、怎么排、何时检索与记忆；用 Python 从零搭 harness，并用 trace 和 eval 量化每次改动，由 Chroma CEO Jeff Huber 和《Context Engineering Handbook》作者 Drew Breunig 主讲。https://x.com/shao__meng/status/2115627250515320947
> [en] **DeepLearning.AI's new course "Context Engineering"**: it treats context engineering as the key to keeping agents reliable and token-efficient on long multi-step tasks, focusing on what the model sees, in what order, and when to retrieve or remember; you build a harness from scratch in Python and measure every change with traces and evals, taught by Chroma CEO Jeff Huber and Context Engineering Handbook author Drew Breunig.
3. **Suno 推出 MCP（Beta）**：歸藏指出，以后让 Claude 做视频需要配乐时可以直接调用 Suno 生成，不用自己做完再发给它；在 Claude、ChatGPT、Gemini、Cursor、Claude Code 里加成自定义连接器、登录后即可用，不需要 API key，消耗的是 Suno 额度，目前需申请提前体验。https://x.com/op7418/status/2115622019429781887 | https://x.com/suno/status/2115506373001634206
> [en] **Suno launches MCP (Beta)**: op7418 notes that when Claude makes a video and needs music, it can now call Suno directly instead of you generating a track and handing it over; add it as a custom connector in Claude, ChatGPT, Gemini, Cursor or Claude Code and sign in, no API key needed, it uses your Suno credits, and early access requires signing up.
4. **Amp 团队怎么工作**：21 人、一周一次会、没有季度目标、几乎没有头衔、不强制 PR 和代码评审、直推 main、一天约百次发布；质量靠「先让 Agent 给出端到端证据」和全员用产品，作者强调前提是人少、彼此校准过，不是把大组织乘上 AI 就能复制。https://x.com/shao__meng/status/2115647666160029715
> [en] **How the Amp team works**: 21 people, one meeting a week, no quarterly goals, almost no titles, no mandatory PRs or code review, pushing straight to main and shipping about 100 times a day; quality comes from having agents produce end-to-end evidence first and everyone using the product, with the caveat that it relies on a small, well-calibrated team and can't be copied by multiplying a big org by AI.
