3. **Forever Security EMBRACE: embedded browsers in five AI coding tools broke basic browser rules**: Research published Oct 29 covers Cursor, GitHub Copilot, Codex, VS Code and Claude Desktop. Cursor’s page→composer bridge enabled host code execution (silently patched Oct 1); Copilot let pages spoof the address bar (fixed in 1.1.29); Claude Desktop / VS Code worker bypass and Codex’s missing fence let a local `file://` page read outside the project—Codex and VS Code still unpatched at publish time. Don’t open untrusted project HTML in those built-in browsers; “trust this folder” ≠ whole-disk consent. https://forever.security/blog/embrace-hacking-5-ai-assistants-embedded-browsers-technical/ | https://www.theregister.com/security/2026/10/29/researchers-find-bugs-in-5-ai-developer-tools-with-openai-and-microsoft-flaws-still-unpatched/5306508
> [zh] **Forever Security EMBRACE：五款 AI 编程工具的内置浏览器打破了普通浏览器的基本隔离**：10 月 29 日报告覆盖 Cursor、GitHub Copilot、Codex、VS Code、Claude Desktop。Cursor 的页面→composer 桥可导致主机命令执行（10 月 1 日静默修复）；Copilot 允许页面伪造地址栏（1.1.29 已修）；Claude Desktop / VS Code 的 worker 绕过与 Codex 缺少围栏，让本地 `file://` 页读出项目外文件——发布时 Codex 与 VS Code 仍未修。不要用这些内置浏览器打开不可信项目的 HTML；「信任此文件夹」不等于同意整盘被读。
