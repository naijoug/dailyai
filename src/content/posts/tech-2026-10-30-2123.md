## 新产品
1. **Herdr: a native desktop home for Claude Code, Codex and other coding agents**: agents run in herdr-core so they keep working when the window closes; every UI surface is a plain file agents can rewrite, with workspaces, worktrees, an agent status pane, pane-to-pane messaging across harnesses, and remote machines over SSH; built on libghostty, with layouts customizable via recipes. https://herdr.dev [GitHub](https://github.com/herdrdev/herdr-app) [HN](https://news.ycombinator.com/item?id=50298436)
> [zh] **Herdr：给 Claude Code、Codex 等编程 Agent 的原生桌面壳**：Agent 跑在 herdr-core 里，关窗口也继续干活；界面每个像素都是 Agent 可改的普通文件，带 workspace、worktree、Agent 状态栏、跨 harness 的窗格通信，以及经 SSH 连远程机器；底层 libghostty，布局可用 recipe 定制。
2. **SpecDeck: bring coding-agent decisions back into reviewed product specs**: teams write feature specs in the browser and hand them to Claude Code / Codex / OpenCode / OpenClaw via MCP; during implementation agents propose the decisions that matter as reviewable spec diffs (git-like: published = main, drafts = branches, proposals = PRs), leaving minor choices in code; free for up to 3 people. https://specdeck.ai [HN](https://news.ycombinator.com/item?id=50303157)
> [zh] **SpecDeck：把编程 Agent 的关键决策写回可评审的产品规格**：团队在浏览器里写功能规格，经 MCP 交给 Claude Code / Codex / OpenCode / OpenClaw；实现时 Agent 把真正影响产品的决策提成可审的规格 diff（类似 git：已发布=main、草稿=分支、提案=PR），次要实现留在代码里；最多 3 人免费。
3. **Ilse: point at your running React app and your coding agent changes the code**: a toolbar overlays Next.js/Vite/Remix/Astro/CRA apps; click an element and say what should change, or drag/resize/tweak spacing and colors on your own design tokens—simple class-mapped tweaks land instantly with no AI; the rest goes to Claude Code, Codex, Cursor or Gemini CLI via local MCP, with file/line and token context already filled in. https://ilse.design/en [PH](https://www.producthunt.com/products/ilse)
> [zh] **Ilse：在正在跑的 React 应用上点一下，你的编程 Agent 就去改代码**：工具条叠在 Next.js/Vite/Remix/Astro/CRA 上；点选元素写改动，或按项目自己的设计 token 拖动/缩放/调间距配色——能映射到 class 的立刻落地、不耗 AI；其余经本机 MCP 交给 Claude Code、Codex、Cursor 或 Gemini CLI，并带上文件行号与 token 上下文。
4. **Faylee: bug reports your coding agent can fix from one link**: records screen, console, every network request and each click on one timeline; Instant Replay saves the last few minutes after a bug already happened; paste the link into Claude Code, Codex or Cursor and Faylee's MCP hands the agent the full report so it can find the cause and comment back; free for up to 3 members. https://faylee.app [PH](https://www.producthunt.com/products/faylee)
> [zh] **Faylee：一条链接就能让编程 Agent 修的缺陷报告**：把屏幕、控制台、每条网络请求和每次点击收在同一时间轴；Instant Replay 可在 bug 已经发生后补存最近几分钟；把链接贴进 Claude Code、Codex 或 Cursor，Faylee 的 MCP 把整份报告交给 Agent 查因并回评论；最多 3 人免费。
5. **fastbrowse: a fast open-source browser agent that picks from on-page controls**: indexes every button, link and field, lets a System One model (e.g. Jev) choose the next step from that list, and falls back to a standard LLM when unsure; claims 25.7s / $0.020 vs Browser Use 42.2s / $0.045 on the same shop task, median $0.026 vs $0.284 on a 46-task bench, with citations for every answer; MIT. https://fastbrowse.ai [GitHub](https://github.com/agent-labs-dev/fastbrowse) [PH](https://www.producthunt.com/products/fastbrowse)
> [zh] **fastbrowse：从页面控件里选动作的快速开源浏览器 Agent**：枚举每个按钮、链接和字段，由 System One 模型（如 Jev）从列表里选下一步，不确定时再回退到标准 LLM；同款购物任务自称 25.7 秒 / 0.020 美元，对比 Browser Use 42.2 秒 / 0.045 美元，46 项基准中位成本 0.026 vs 0.284 美元，每条回答带引用；MIT。

## 科技新闻
1. **Azure API Connections: five full cross-tenant compromises via Logic Apps plumbing**: Binary Security documents path traversal and `host.api.RuntimeUrl` tricks that let an attacker drive any other tenant's API Connection—Key Vault secrets, Azure SQL, Jira, Salesforce and more—through ARM `DynamicInvoke` / undocumented siblings and Consumption Logic Apps; Microsoft paid ~$200k across the five critical EoPs, each fixed after report, with validation still described as bolted-on. https://www.binarysecurity.no/posts/2026/10/one-root-case [HN](https://news.ycombinator.com/item?id=50301854)
> [zh] **Azure API Connections：经 Logic Apps 管道实现的五次完整跨租户沦陷**：Binary Security 披露路径穿越与 `host.api.RuntimeUrl` 手法，可让攻击者通过 ARM 的 `DynamicInvoke`、未文档化兄弟接口以及 Consumption Logic Apps，驱动任意其他租户的 API Connection——包括 Key Vault 密钥、Azure SQL、Jira、Salesforce 等；五次严重提权合计约 20 万美元赏金，均在报告后修复，但校验仍被形容为打补丁式。
2. **群晖 DSM 遭 C3RB3R 勒索软件（`.L0CK3D` / `read-me3.txt`）**：V2EX 救灾帖把入侵根因指向 DSM 的 CVE-2024-10441（亦有称最新版 DSM 也中招、疑有未公开 0day），不一定是 GitLab CE；建议先断公网、勿慌拔电，经本机 SSH 保留加密样本与内存 dump；救灾仓库提供攻击路径文档、给 AI 的提示词、Skill 与脚本。https://www.v2ex.com/t/1252851 [GitHub](https://github.com/soimy/c3rb3r-rescue)
> [en] **Synology DSM hit by C3RB3R ransomware (`.L0CK3D` / `read-me3.txt`)**: a V2EX live thread traces intrusion toward DSM CVE-2024-10441 (and possible unpublished 0days even on latest DSM), not necessarily GitLab CE; advice is disconnect WAN first, keep power on, preserve encrypted binaries and memory dumps via local SSH; a rescue repo ships attack-path notes, AI prompts, skills and scripts.
3. **小米开源 Xiaomi-OCR-0：0.8B 统一文档理解模型**：单模型覆盖文档解析（Markdown/LaTeX）、关键信息抽取（JSON）与 OCR 视觉问答；基于 Qwen3.5-0.8B-Base，约 1.7 亿条 OCR 样本训练；Real5-OmniDocBench 95.24（其对比集第一），五项 OCR VQA 均分 83.2，高于 Qwen3.5-2B 的 80.9；同步开放权重、推理代码、浏览器 Demo、MCP 服务与 Agent Skill。https://www.ithome.com/1/020/346.htm [HF](https://huggingface.co/xiaomi-research/Xiaomi-OCR-0) [GitHub](https://github.com/xiaomi-research/Xiaomi-OCR-0)
> [en] **Xiaomi open-sources Xiaomi-OCR-0, a 0.8B unified document model**: one model covers document parsing (Markdown/LaTeX), key-information extraction (JSON) and OCR VQA; built on Qwen3.5-0.8B-Base with ~170M OCR samples; scores 95.24 on Real5-OmniDocBench (#1 in their compare set) and 83.2 avg on five OCR VQA benches, beating Qwen3.5-2B's 80.9; ships weights, inference code, browser demo, MCP service and an Agent Skill.
