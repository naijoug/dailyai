## 有趣用法和干货
1. **Thorsten Ball: hand-invoked skill pyramids are an anti-pattern**: after an Amp meetup he says everyone agreed that elaborate pyramids of skills a human triggers deterministically are a smell. His reasons: a skill should be discoverable without a slash command; if something is that specific and deterministic, why use the model as a workflow executor instead of giving it a high-level goal; and the codebase should be legible enough that a human doesn’t need to tell the agent when and how to review. https://x.com/thorstenball/status/2122922917478715556
> [zh] **Thorsten Ball：靠人手动触发的层层 Skill 是反模式**：他说在 Amp 线下聚会上大家一致认为，由人确定性地逐个调用、层层堆叠的 Skill 是坏味道。理由有三：Skill 应该不靠斜杠命令也能被模型发现；如果某件事具体到要确定性触发，为什么不直接给模型一个高层目标让它自己想办法，而是把它当工作流执行器；代码库本身应该对 Agent 足够清晰，如果还得由人告诉 Agent 何时、如何做审查，问题多半出在更早的环节。
2. **Arpit Bhayani: use “slot lending” when sub-agents spawn sub-agents**: recursive agent task trees under a concurrency cap deadlock if each task holds a semaphore slot until its children finish (cap 2: root plus child A hold both slots and A’s children can never start). Letting parents release their slot fixes the deadlock but defeats the cap; in his numbers, 2,000 tasks with a cap of 4 were all alive at once, holding about 200 MB. What worked best: a parent keeps its slot and lends it to one child at a time, while other children use the shared pool or wait, so tasks always progress and live tasks stay bounded. https://x.com/arpit_bhayani/status/2122903406390153659
> [zh] **Arpit Bhayani：子 Agent 再派子 Agent 时，用「借槽」控制并发**：递归任务树加并发上限时，如果每个任务要等子任务全部完成才释放信号量槽位，就会死锁（上限为 2 时，根任务和子任务 A 占满两个槽，A 的子任务永远起不来）。让父任务等待时交出槽位能解开死锁，却让上限失去意义；按他的测算，2000 个任务、上限 4，结果 2000 个同时存活、占约 200 MB。效果最好的是「借槽」：父任务保留槽位，每次借给一个子任务，其余子任务用共享池或排队，这样任务总能推进，存活任务数也有上限。
3. **有人把 Blender 建模流程做成 28 个 Skill，装进 Codex 或 Claude Code 就能用人话建模**：铁锤人介绍 EL4CTEO/blender-skills（他称已有 2000 多星）：从建模雕刻、重拓扑拆 UV、PBR 材质与烘焙、几何节点批量生成，到绑骨骼做动画、打光渲染，再导出到 Unity、Unreal、Godot，基本串起做游戏模型的全流程；他觉得最有意思的是还管验收，做完会检查零件悬空、表面重叠闪烁和贴图丢失。他给小侄子做的古诗立体书里，部分模型就是用这套 Skill 做的。https://x.com/lxfater/status/2122940385227833478
> [en] **Someone turned Blender’s modeling workflow into 28 skills you drive in plain language from Codex or Claude Code**: lxfater highlights EL4CTEO/blender-skills (he says 2,000+ stars), covering modeling and sculpting, retopology and UVs, PBR materials and baking, geometry-node batching, rigging and animation, lighting and rendering, and export to Unity, Unreal and Godot. The part he likes most is that it also checks the result for floating parts, z-fighting surfaces and missing textures. Some models in the classical-poetry pop-up book he built for his nephew came from these skills.
4. **Paul Iusztin: score subjective outputs with LLM judges in two steps**: first pick a performance level using descriptions and examples, then assign a number within that level, because evaluating against defined criteria is easier than using an arbitrary 1–100 scale. https://x.com/pauliusztin_/status/2122985665377829051
> [zh] **Paul Iusztin：用 LLM 评审给主观输出打分，分两步**：先根据描述和示例选定表现等级，再在该等级内给出具体分数；对照明确标准评估，比在随意的 1 到 100 分尺度上打分更容易。
