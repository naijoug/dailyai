## 新产品
1. **MAGI-2**：Sand.ai 新一代视频模型，1080P 视频每秒约 5 毛钱，官方称约为 Seedance 2.5 同规格价格的 1/10；支持原生 30 秒 1080P 音画同出、最长 2 万字 prompt，以及 10 张图、3 段视频、3 段音频共 16 份参考素材，官方称抽卡成功率超 90%，在 Artificial Analysis 图生视频和无声图生视频榜单均排第一。它是 MoE 架构，480B 总参数、单次激活约 28B，即将开源，目前在 LibTV 独家首发。Founder Park 实测里它能完整呈现 9×9 数独的填写过程且结果正确，8 人群像也保持一致；官方承认音频参考仍有提升空间。https://sand.ai/ https://www.163.com/dy/article/LCJ8PIBD05566TJ2.html
> [en] **MAGI-2**: Sand.ai’s next-generation video model costs about ¥0.5 per second of 1080P video, which the company says is roughly 1/10 the price of Seedance 2.5 at the same spec; it does native 30-second 1080P video with synchronized audio, takes prompts of up to 20,000 characters and up to 16 reference inputs (10 images, 3 videos, 3 audio clips), and claims a 90%+ usable-take rate, ranking first on Artificial Analysis’s image-to-video and silent image-to-video leaderboards. It is an MoE model with 480B total and about 28B active parameters, open weights are coming, and it launched exclusively on LibTV. In Founder Park’s tests it rendered the full process of solving a 9×9 sudoku with a correct result and kept 8 characters consistent in one scene; the company admits audio references still need work.
2. **OCRia-1**: LlamaIndex’s 4B vision-language model for document parsing reads a page image and writes Markdown with tables in HTML, built for what parsers usually get wrong: merged cells and spanning headers, tables with thousands of cells, charts converted into data tables, and meaningful formatting such as strikethrough, underline, checkboxes and handwritten LaTeX formulas. It is the top open-weight model on both ParseBench leaderboards (85.2 on ParseBench 2, 84.7 on ParseBench 1), runs locally through GGUF builds for llama.cpp and Ollama, and is the same model that serves LlamaParse, where quantization, a speculative decoder and custom kernels make it about 10x faster; the license does not allow unrestricted commercial use. https://www.llamaindex.ai/blog/parse-ocria-1 https://huggingface.co/llamaindex/OCRia-1
> [zh] **OCRia-1**：LlamaIndex 推出的 4B 文档解析视觉语言模型，读一页图片、输出 Markdown（表格用 HTML），专攻解析器最常出错的内容：合并单元格和跨列表头、上千单元格的大表、把图表还原成数据表，以及删除线、下划线、复选框、手写 LaTeX 公式等有含义的格式。它在两个 ParseBench 榜单上都是最强开放权重模型（ParseBench 2 得分 85.2，ParseBench 1 得分 84.7），可用 GGUF 版本在 llama.cpp 和 Ollama 本地运行；LlamaParse 线上用的就是它，经量化、投机解码和定制算子后快约 10 倍；许可证不允许随意商用。
3. **Yab**：少数派介绍的开源浏览器，界面几乎照搬即将在 12 月 22 日关停的 Arc（侧边栏、Spaces、Peek、Split View），主打「Keep Arc. Add hands.」：以 WebKit 为主、内置 Chromium 内核可随时切换，WebKit 标签页也能跑 Chrome 扩展；可接入已有的 Claude 或 ChatGPT 方案让 Agent 在浏览器里替你浏览、检索汇总，还通过 MCP 和命令行把浏览器操作开放给 Codex 等外部 Agent，涉及发消息、付款、删数据会停下等你确认，隐私标签页对 Agent 不可见。开发者 Serafim Korablev 说它主要由他一人配合大量 AI Agent 开发，11 月开源。https://yetanotherbrowser.com/ https://sspai.com/post/119310
> [en] **Yab**: an open-source browser covered by SSPAI whose interface closely mirrors Arc, which shuts down on Dec 22 (sidebar, Spaces, Peek, Split View), under the tagline “Keep Arc. Add hands.” It is WebKit-first with a built-in Chromium engine you can switch to, and WebKit tabs can run Chrome extensions; you can connect an existing Claude or ChatGPT plan so an agent browses, searches and compiles information for you, and it exposes browser actions to external agents such as Codex via MCP and a CLI, pausing for confirmation before sending messages, paying or deleting data, with private tabs invisible to agents. Developer Serafim Korablev says he built it mostly alone with lots of AI agents and open-sourced it in November.
4. **Lightscale AI**: a Swiss startup (Show HN) that rebuilt the stack under the LLM, a programming language, compiler and runtime designed from scratch for AI authorship rather than humans, so that some classes of errors are removed by abstraction because the AI never writes that code. Users describe a CRM, web shop, applicant tracker or other business tool and get an app with sign-in, access control and protected data built in, with data migrated across versions; building is free, the first app is hosted free in Switzerland, and more apps or source download cost CHF 50 per project per month. https://lightscale.ai/ https://news.ycombinator.com/item?id=50639615
> [zh] **Lightscale AI**：一家瑞士初创公司（Show HN），重做了 LLM 底下的整套技术栈：一门从零为 AI 编写而非为人设计的编程语言及其编译器和运行时，部分错误类型因为 AI 根本不写那层代码而被抽象掉。用户描述想要的 CRM、网店、招聘跟踪等业务工具，就能得到自带登录、权限控制和数据保护的应用，版本迭代时数据自动迁移；构建免费，第一个应用免费托管在瑞士，更多应用或下载源码每个项目每月 50 瑞士法郎。

## 科技新闻
1. **Attackers are exploiting a critical Drupal RCE that Anthropic’s OSS Scanner found**: CVE-2026-132165 lets anonymous users abuse Drupal core’s install.php to try to reinstall Drupal, leading to site takeover or remote code execution (some paths are mitigated if the web server can’t write to or change permissions on settings.php). Drupal updated its advisory to say the flaw was “exploited on live sites as early as 2026-11-19 19:00 UTC,” and CISA added it to its KEV catalog with a Nov 27 deadline for federal agencies. Admins should upgrade; those who can’t should block /core/install.php in the web server config or .htaccess. https://www.bleepingcomputer.com/news/security/hackers-now-exploit-critical-drupal-rce-flaw-to-hijack-sites/
> [zh] **Anthropic OSS Scanner 发现的 Drupal 高危 RCE 漏洞已遭在野利用**：CVE-2026-132165 允许匿名用户滥用 Drupal 核心自带的 install.php 尝试重装站点，进而接管网站或远程执行代码（如果 Web 服务器无法写入或修改 settings.php 的权限，部分利用路径会被缓解）。Drupal 更新公告称该漏洞「最早在 2026-11-19 19:00 UTC 已在线上站点被利用」，CISA 也已将其列入已知被利用漏洞目录，要求联邦机构在 11 月 27 日前完成修补。管理员应尽快升级，暂时不能升级的要在 Web 服务器配置或 .htaccess 里屏蔽 /core/install.php。

3. **Taking over US Treasury subdomains for $3 each via dangling AWS Elastic IPs**: Intruder repeatedly allocated and released Elastic IPs across regions, checking each against A records from public bug-bounty scopes; in 48 hours it cycled through 450,000 unique IPs before AWS banned the account and found 28 live takeovers, including real US Treasury subdomains (reported and fixed via bug bounty), while covering less than 1% of the EIP space. In the HN thread, commenters called for teardown checklists and quarterly DNS reviews, suggested Route53 should offer an auto-deleting EIP record type, and criticized AWS for letting a banned account move its IPs to another account in the same organization. https://www.intruder.io/research/taking-over-us-treasury-subdomains-for-3-each https://news.ycombinator.com/item?id=50638478
> [zh] **利用悬空的 AWS 弹性 IP，3 美元一个接管美国财政部子域名**：Intruder 在各区域反复申请、释放弹性 IP，并与公开漏洞赏金范围里的 A 记录比对；48 小时内轮换了 45 万个不同 IP，直到 AWS 封号，找到 28 个可实际接管的记录，其中包括美国财政部的真实子域名（已通过漏洞赏金报告并修复），而覆盖的还不到弹性 IP 空间的 1%。HN 评论区呼吁下线主机时走清单、每季度检查 DNS，建议 Route53 提供可自动删除的弹性 IP 记录类型，也批评 AWS 允许被封账号把 IP 转到同一组织下的其他账号。
