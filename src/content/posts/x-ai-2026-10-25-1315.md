## 有趣用法和干货
1. **Strata：让普通游戏电脑本地跑 125B 级大模型，并接入 Claude Code / Codex**：开源推理引擎（MIT，GitHub 约 3.2 万星），用 GPU 显存、内存和 SSD 三级调度加 MoE 专家动态缓存，显存加内存合计 32GB 起步就能跑 Qwen3.8-Flash-Next，0.2.4 起还能在终端跑 DeepSeek V4.1-Flash；支持 NVIDIA/AMD/Intel/Apple Silicon，提供兼容 OpenAI 和 Anthropic 的本地 API，Claude Code、Codex CLI、OpenCode 可直接接。帖子称 RTX 5070 跑 Q2 量化约 94 token/s、推测解码提速 1.6–1.8 倍；需约 80GB SSD 空间。https://x.com/wiksongkim/status/2114167999838220425 ｜ https://github.com/Niko1221/Strata
> [en] **Strata: run a 125B-class model locally on a gaming PC and wire it into Claude Code / Codex**: an open-source inference engine (MIT, ~32k GitHub stars) that tiers VRAM, RAM and SSD with dynamic MoE expert caching, so 32 GB of combined RAM + VRAM is enough to start Qwen3.8-Flash-Next, and from 0.2.4 DeepSeek V4.1-Flash in the terminal; supports NVIDIA/AMD/Intel/Apple Silicon and exposes local OpenAI- and Anthropic-compatible APIs so Claude Code, Codex CLI and OpenCode connect directly. The post cites ~94 tok/s for a Q2 quant on an RTX 5070 and 1.6–1.8x from speculative decoding; needs ~80 GB of SSD.
2. **李继刚：辅导孩子学诗词的「文字成画」Prompt**：让模型把一首诗变成只由诗中文字组成的图，字的位置和走向就是画面。四步：找事实（只写诗里有的意象和上下、垂落、动向关系）→ 定投影（意象由指称它的字构成，垂下就沿弧线排、高就竖着叠、风就斜穿；「不知」「谁」「似」这类字放在留白或意象交界处）→ 出图 → 逐条自检（所有字出自原诗、不看原诗也认得出画面、沿路径能一字不差读出全诗、不拿别的字凑）。末尾留 `诗：{在这里放诗}` 占位，结构清楚、带验收标准，也适合改成其他图文任务。https://x.com/lijigang/status/2114206178939146352
> [en] **Li Jigang: a "poem-as-picture" prompt for helping kids learn classical poetry**: the model turns a poem into an image made only of the poem's characters, where their placement and direction form the picture. Four steps: gather facts (only the poem's images and their relations — above, hanging, moving which way) → project (each image is built from the characters that name it; hanging means an arc downward, tall means stacked vertically, wind means a diagonal sweep; words like "不知/谁/似" go in blank space or at the seams) → render → self-check (every character comes from the poem, the scene is recognizable without the text, the poem can be read verbatim along a path, no filler characters). Ends with a `诗：{...}` slot; the step-plus-acceptance-criteria structure transfers to other text-image tasks.
