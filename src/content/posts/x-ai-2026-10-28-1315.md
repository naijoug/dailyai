2. **Anthropic study: experts went with their Claude Code agent's secret, coin-flipped lean 86% of the time**: 50 professional causal-inference analysts did a realistic analysis with Claude Code while each agent was told to argue for a randomly assigned option on four judgment calls; when analysts had stated a view first, they abandoned it 60% of the time if the agent disagreed versus 6% if it agreed, and 77% reused the agent's arguments to explain their picks but only 15% credited it. Anthropic notes the leans were deliberately strengthened, so real-world influence may be smaller. https://www.anthropic.com/research/agents-judgment-calls
> [zh] **Anthropic 研究：专家有 86% 的时候顺从了 Claude Code agent 被抛硬币设定的隐藏倾向**：50 名有因果推断经验的专业分析师用 Claude Code 做一项真实分析，每个 agent 在四个判断点上被暗中指定为一个随机选项辩护；分析师先表态后，agent 意见相反时有 60% 改主意，意见一致时只有 6%；事后 77% 的人用 agent 的论点解释自己的选择，却只有 15% 提到 agent。Anthropic 说明这些倾向是刻意加强的，现实中影响可能更小。

## 有趣用法和干货
1. **宝玉：Opus 5.5 之后，AI Agent 剪视频已能替代初级剪辑师**：他实测同一视频只给 ASR 和 TTS 工具、不加任何 Skill，Opus 5.5 反而剪得更好，BaoCut 的时间线编辑器也退居二线，编辑器只要能标记、让 Agent 知道改哪就够；他整理了广告剪辑团队负责人 Alex Cooper 的可照搬做法：按风格拆小 Skill，先给 Claude 4–5 条参考作品总结成 Skill，再让它重剪资深剪辑师最近的 25 条广告、逐条点评，并录屏口述剪辑理由补隐性知识，多数片子一两版即过；VEED 联创 Sabba 则建议别重造专业时间线，专心做好初剪。https://x.com/dotey/status/2115282464935473225
> [en] **Baoyu: since Opus 5.5, AI agents can already replace junior video editors**: in his test, given only ASR and TTS tools and no Skills, Opus 5.5 edited the same video better, so he demoted BaoCut's timeline editor — an editor only needs to let you mark spots so the agent knows what to change; he summarizes ad-team lead Alex Cooper's copyable method: split small Skills by style, have Claude distill 4–5 reference pieces into a Skill, make it re-cut a senior editor's last 25 ads with line-by-line critique, and screen-record editors narrating their reasoning to capture tacit knowledge, so most cuts pass in one or two rounds; VEED co-founder Sabba advises not rebuilding pro timelines and nailing the rough cut instead.
2. **GitHub Daily：谷歌 Gemini 团队开源 macOS 语音输入工具 Jot**：基于 Gemini 3.5 Transcribe，按住 fn 说话、松手就在光标处出字，自动加标点、去掉口头禅，中途改口只保留最后的说法；录音按下即落盘，崩溃或断网后可恢复、联网补发，人名和产品名可加词典随音频发给模型；需自备 Gemini API Key，音频直连 Google，有免费额度。https://x.com/GitHub_Daily/status/2115269839086666079 | https://github.com/google-gemini/jot-gemini-transcribe-macOS
> [en] **GitHub Daily: Google's Gemini team open-sources Jot, a macOS dictation tool**: built on Gemini 3.5 Transcribe — hold fn to speak and text appears at the cursor on release, punctuated and stripped of filler words, keeping only your final phrasing if you change your mind mid-sentence; recordings hit disk the moment you press, so they survive crashes or offline periods and upload later, and names or product terms can go in a dictionary sent along with the audio; bring your own Gemini API key, audio goes straight to Google, with a free tier.
