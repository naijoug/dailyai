## AI 热点
1. **OpenAI releases GPT-6.2 Astra and GPT-6.2 Sol**: Astra is the new frontier model for the hardest projects and Sol the efficient everyday model; both are pitched on doing more with fewer output tokens (OpenAI’s launch post drew about 31,000 likes). They’re in ChatGPT Work and Codex for Plus, Pro, Enterprise and Edu (per the help docs also Business, but not the regular chat UI) and in the API: Astra costs $8/$40 per million input/output tokens, 20% below GPT-6 Astra, with cached input at $0.40; Sol keeps GPT-6.1 Sol’s $2/$10. Ultrafast comes to Pro 200 for Sol and to Pro 500 for both. OpenAI claims new highs on Agents’ Last Exam (5.5 points over Claude Fable 5.2 at 5% of the cost), Terminal-Bench-Science, Harvey LAB-AA and the AA-3D blind test (1,318 Elo), with Sol within 0.5 points of Astra on FrontierCode 2.0 at a fifth of the cost. Because cyber capability jumped (22 points over GPT-6 Astra on ExploitBench), both ship with tighter cyber safeguards; OpenAI also found they’re likelier than GPT-6 Astra to not mention a blocker such as a missing file, and added Codex instructions against it. GitHub made both generally available in Copilot the same day. https://x.com/OpenAI/status/2122750124543926515
> [zh] **OpenAI 发布 GPT-6.2 Astra 和 GPT-6.2 Sol**：Astra 是面向最难项目的新旗舰，Sol 是高效的日常主力，两者主打用更少的输出 token 干更多活（OpenAI 发布帖约 3.1 万赞）。Plus、Pro、企业版和教育版用户可在 ChatGPT Work 和 Codex 里使用（帮助文档里还有 Business，普通聊天界面没有），API 同步上线：Astra 每百万输入/输出 token 8/40 美元，比 GPT-6 Astra 便宜 20%，缓存输入 0.4 美元；Sol 维持 GPT-6.1 Sol 的 2/10 美元。Ultrafast 模式首次开放给 Pro 200（仅 Sol），Pro 500 两个模型都能用。OpenAI 称其在 Agents’ Last Exam（比 Claude Fable 5.2 高 5.5 分、成本只有 5%）、Terminal-Bench-Science、Harvey LAB-AA 和 AA-3D 盲测（1318 Elo）上创新高，Sol 在 FrontierCode 2.0 上只比 Astra 低 0.5 分、成本约五分之一。由于网络安全能力大涨（ExploitBench 上比 GPT-6 Astra 高 22 分），两款模型都加了更严的网络安全防护；OpenAI 还发现它们比 GPT-6 Astra 更容易对「要改的文件不见了」这类阻碍闭口不提，已在 Codex 里加指令纠正。GitHub 当天也在 Copilot 中正式开放这两款模型。
2. **GPT-6.2 首日口碑两极：代码审查大涨，协作和编码分数存疑**：卡兹克用自建的简易评测集测代码审查，GPT-6.1 Sol 能找出 65% 的问题，GPT-6.2 Sol（xhigh）84%，GPT-6.2 Astra 直接到 96%；但 Astra 比 Sol 慢约一倍、贵 4 倍，他还觉得 Astra 的方案规划能力（非科研）不如 6 Astra、输出更难读，除了写后端和做审查「别的好像也不太行了」。歸藏汇总评论称它「不说人话」、难以协作，像当年的 Opus 4.7/4.8，编程能力还有所下降，不过 3D 建模的细节和精细度比 Claude 好。据 The Decoder，Artificial Analysis 主指数上 Astra 仅次于 Fable 5.2、编码分与 GPT-6 Astra 持平，Epoch AI 则测出 Astra 与 Fable 5.2 打平；铁锤人补充，AA 用 Codex 测 Sol 的编码分从 52 降到 49，每题成本降约 19%。https://x.com/Khazix0918/status/2122811072025694318
> [en] **GPT-6.2’s first-day reviews split: big gains in code review, doubts on collaboration and coding scores**: on his own simple code-review eval, Khazix found GPT-6.1 Sol caught 65% of issues, GPT-6.2 Sol (xhigh) 84% and GPT-6.2 Astra 96%; but Astra is about twice as slow and 4x the price of Sol, and he feels its (non-research) planning is worse than 6 Astra’s and its output harder to read, saying that beyond backend work and review “the rest doesn’t seem that good.” Guizang’s roundup of reactions says it “doesn’t talk like a human” and is hard to collaborate with, like Opus 4.7/4.8 back then, with weaker coding, though its 3D modeling detail beats Claude’s. Per The Decoder, Astra trails only Fable 5.2 on Artificial Analysis’s main index with coding flat vs. GPT-6 Astra, while Epoch AI has it tied with Fable 5.2; lxfater adds that AA’s Codex runs show Sol’s coding score dropping from 52 to 49 while cost per task fell about 19%.

> [zh] **微软 Ignite：Autopilot 扩展到整个 Microsoft 365，MAI 系列增至 7 个模型**：据 TestingCatalog，Autopilot 现在可在 Copilot、Teams 和 Outlook 中为 Microsoft 365 用户工作，主动替人起草回复、安排会议、跑例行任务；纳德拉还宣布 Meta 最新模型将进入 Foundry。除编程模型外，微软新的 MAI 系列还包括 MAI Cyber 2 Flash、MAI Image 2.7（微软称登顶 Artificial Analysis 图像编辑榜）、多语言转录模型 MAI Transcribe 2、每分钟低至 0.01 美元的实时语音模型 MAI Realtime 1，以及决策模型 Decision 1.1。

## 有趣用法和干货
1. **Vox: six laws your vibe-coded app may already break, plus a pre-launch prompt**: no age gate (one under-13 signup is a COPPA violation, up to $53K per child); loading Google Fonts from Google’s servers sends visitor IPs over (a Munich court awarded one visitor €100 under GDPR); session replay that records typing without consent invites CIPA wiretapping suits in California (up to $5K each); marketing emails without an unsubscribe link or postal address break CAN-SPAM; renewal terms not right beside the subscribe button let California treat renewals as gifts you must refund; and skipping the $6 DMCA agent registration leaves you liable for users’ uploads. His prompt for Claude Code asks it to check for all six, fix what it can and list what you must do yourself (about 2,200 bookmarks). https://x.com/Voxyz_ai/status/2122736531701977117
> [zh] **Vox：你随手做的 App 可能已经触犯 6 条法规，附上线前自查提示词**：注册不问年龄（放进一个 13 岁以下用户就违反 COPPA，每个孩子最高 5.3 万美元）；从谷歌服务器加载 Google Fonts 会把访客 IP 发过去（慕尼黑法院曾依 GDPR 判一家网站赔访客 100 欧元）；未经同意用会话回放记录用户输入，在加州会被以 CIPA 窃听罪起诉（每次最高 5,000 美元）；营销邮件没有退订链接或邮寄地址违反 CAN-SPAM；续费条款不紧挨订阅按钮，加州会把每次续费视为无条件赠与、必须退款；不花 6 美元登记 DMCA 代理人，就要为用户上传的侵权内容担责。他给的 Claude Code 提示词让它逐项检查这 6 点，能修的修掉，再列出需要你自己处理的事（约 2,200 收藏）。
2. **Meta’s Self-Improving Memory: let the agent design its own memory habits, then train them into the weights**: Jason Weston’s team runs every subtask in a fresh context where only a memory directory carries over, driven by a LOAD prompt before each subtask and an OFFLOAD prompt after. A meta agent reads trajectories, finds where memory use breaks and rewrites those prompts, scoring 56.0 vs 44.6 for the best hand-written design on three Continual Learning Bench tasks; then they run with the optimized prompts, swap them back to generic ones while keeping the responses and LoRA fine-tune, getting 43.1 vs 37.6 for SFT on the model’s own generic runs. Both agents are Kimi-K2.6 (about 1,260 bookmarks; elvis notes it pairs with last week’s RIME on RL-trained memory writing). https://x.com/jaseweston/status/2122691693543817397
> [zh] **Meta 的 Self-Improving Memory：让 Agent 自己设计记忆习惯，再训练进权重**：Jason Weston 团队让每个子任务都在全新上下文里开始，只有一个记忆目录能延续，子任务前跑 LOAD 提示词、子任务后跑 OFFLOAD 提示词。元 Agent 读取运行轨迹，找出记忆用得不好的地方并改写这两个提示词，在 Continual Learning Bench 的三个任务上得分 56.0，而最好的手写方案为 44.6；随后用优化后的提示词运行，把提示词换回通用版、保留回答，再做 LoRA 微调，得分 43.1，而直接用模型自己的通用运行做 SFT 只有 37.6。两个 Agent 都是 Kimi-K2.6（约 1,260 收藏；elvis 指出它和上周用 RL 训练记忆写入的 RIME 是同一方向的两种做法）。
3. **Sebastian Raschka: pre-training may be dropping the LR decay phase**: Kolibri-1 and DatologyAI’s models use a constant learning rate plus averaging of the last N checkpoints (or a running weight average), which spares you from committing to a total training length up front. His tally of labs that share details: classic cosine for Llama 3, OLMo 2/3, GLM-4.5/5, Kimi K3 and Phi-4; Warmup-Stable-Decay for DeepSeek V3/V4/V4.1-Flash, Kimi K2, Kimi Linear, Nemotron 3 Nano/Super, SmolLM3 and MiniMax M2. https://x.com/rasbt/status/2122721652433715481
> [zh] **Sebastian Raschka：预训练可能开始取消学习率衰减阶段**：Kolibri-1 和 DatologyAI 的模型采用恒定学习率，再对最后 N 个检查点取平均（或维护滚动权重平均），好处是不必一开始就定死总训练长度。他统计了公开训练细节的团队：经典余弦衰减有 Llama 3、OLMo 2/3、GLM-4.5/5、Kimi K3、Phi-4；WSD（预热-稳定-衰减）有 DeepSeek V3/V4/V4.1-Flash、Kimi K2、Kimi Linear、Nemotron 3 Nano/Super、SmolLM3、MiniMax M2。
4. **Vox: turn a reviewer’s repeated comments into agent rules**: citing SGLang’s summit claim that about 95% of its merged PRs are now written by agents, he suggests running this in Claude Code or Codex: “Use gh to scan the 50 most recent PRs in each GitHub repo under [CODE DIRECTORY]. Find the issues [REVIEWER GITHUB USERNAME] keeps flagging. Rank them by frequency and link the relevant PRs. Wait for my approval, then add only the rules I choose to ~/.codex/AGENTS.md.” On Claude Code, point the last path at ~/.claude/CLAUDE.md. https://x.com/Voxyz_ai/status/2122759173246980530
> [zh] **Vox：把审查者反复提的意见变成 Agent 规则**：他引用 SGLang 峰会上「约 95% 已合并 PR 由 Agent 编写」的说法，建议在 Claude Code 或 Codex 里运行：「用 gh 扫描 [代码目录] 下每个 GitHub 仓库最近 50 个 PR，找出 [审查者用户名] 反复指出的问题，按出现频率排序并附上相关 PR 链接；等我确认后，只把我选中的规则加进 ~/.codex/AGENTS.md。」用 Claude Code 时把最后的路径换成 ~/.claude/CLAUDE.md。
