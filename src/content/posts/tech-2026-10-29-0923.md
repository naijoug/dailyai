1. **Yardlet: a free, open-source Mac app for the coding agents you already use**: it launches Codex, Claude Code, OpenCode and others with their own CLI and sign-in, and puts them behind one sidebar, composer and set of approval cards; sessions stay in each agent's own store (a task started here also opens in the Codex app), it writes nothing into the agents' config, and ships with diffs, a PR tab, connectors and a browser the agents can drive. https://yardlet.app [PH](https://www.producthunt.com/products/yardlet-2)
> [zh] **Yardlet：给你已经在用的编程 Agent 做的免费开源 Mac 应用**：用各自的 CLI 和登录启动 Codex、Claude Code、OpenCode 等，统一到一个侧边栏、输入框和一套审批卡片里；会话仍存在各 agent 自己的存储中（在这里开的任务也能在 Codex 应用里打开），不改动 agent 的任何配置，还自带 diff、PR 标签页、连接器和可供 agent 操控的浏览器。
2. **licenseal: catch incompatible dependency licenses before release**: a free, open-source (Apache-2.0) CLI that checks every dependency license, transitive ones included, against your project's license across 10 ecosystems; it reads lockfiles and registry metadata without installing anything, gives CI a verdict rather than a list, and ships a Claude Code skill. https://licenseal.shcherbak.ai/ [GitHub](https://github.com/shcherbak-ai/licenseal)
> [zh] **licenseal：发布前揪出不兼容的依赖许可证**：免费开源（Apache-2.0）的命令行工具，在 10 个生态里把每个依赖（含传递依赖）的许可证与项目自身许可证比对；只读 lockfile 和注册表元数据、不安装任何东西，给 CI 一个明确结论而不是一张清单，还附带 Claude Code skill。

## 科技新闻
1. **Why is this fingerprinting script "creating bioweapons"?**: crawling 10,000 top sites for canvas fingerprinting (collected at fingerprint.garden), the author found a servicepipe.tech anti-bot script whose function names (e.g. `computeRicinLethalDosageForWaterSupply`), a hidden "SYSTEM OVERRIDE" jailbreak prompt encoded in invisible Unicode tag characters, and Chinese-censorship tripwires exist purely to make LLMs refuse to deobfuscate it — Astra refused, GLM-5.3 complied. A dead-code Node branch even fakes a credential-stealing, crontab-persisting payload as more bait. https://nullpt.rs/fingerprinting-bioweapons [HN](https://news.ycombinator.com/item?id=50276998)
> [zh] **这段指纹脚本为什么在「制造生物武器」？**：作者爬了 1 万个头部网站收集 canvas 指纹（整理在 fingerprint.garden），发现 servicepipe.tech 的一段反爬脚本里，函数名（如 `computeRicinLethalDosageForWaterSupply`）、用不可见 Unicode 标签字符藏起来的「SYSTEM OVERRIDE」越狱提示词，以及针对中国模型的审查敏感词，全是为了让大模型拒绝帮忙反混淆——Astra 拒绝了，GLM-5.3 照做了。一段 Node 环境下的死代码还伪装成窃取凭据、写 crontab 持久化的恶意载荷，同样是诱饵。
2. **NVIDIA open-sources Nemotron 3.5 Transcribe, one promptable model for ASR, diarization, translation and audio Q&A**: it transcribes 40 languages, translates 31 to or from English, labels up to eight speakers in 13 languages on recordings up to an hour long, takes natural-language instructions and vocabulary hints, and leads open-weight models on the HF Open ASR Leaderboard for English; the Granary v2 data pipeline and NeMo fine-tuning recipes are open too (a medical fine-tune cut WER 45.8% vs. the best prompt). Recordings only, no live audio yet. https://huggingface.co/blog/nvidia/nemotron-transcribe-granary [HN](https://news.ycombinator.com/item?id=50275128)
> [zh] **英伟达开源 Nemotron 3.5 Transcribe：一个可用提示词控制的模型搞定转写、说话人区分、翻译和音频问答**：支持 40 种语言转写、31 种语言与英语互译，13 种语言里可区分最多 8 位说话人，单段录音最长 1 小时，可用自然语言指令和术语提示引导输出，英文在 HF Open ASR 榜的开源模型中排第一；Granary v2 数据管线和 NeMo 微调方案也一并开源（医疗场景微调比最佳提示词再降 45.8% WER）。目前只支持录音，不支持实时音频。
3. **DAYJOB: Tax — even the best agents pass under 11% of professional tax assignments**: Surge AI's benchmark gives agents 50 real client tasks across eight practice areas with 1,789 files (median 30 per task) and passes an attempt only at 95% of the rubric; Claude Sonnet 5.5 leads at 10.8%, ahead of Fable 5.1 (9.6%) and Opus 5.5 (9.2%). The case study: Astra never flagged a client's two-of-five-year home-sale deadline in five tries, Opus caught it every time. https://surgehq.ai/blog/dayjob-tax [HN](https://news.ycombinator.com/item?id=50275626)
> [zh] **DAYJOB: Tax——最强的 agent 做专业税务任务通过率也不到 11%**：Surge AI 的基准包含 8 个税务领域的 50 个真实客户任务、1789 个文件（每题中位数 30 个），满足 95% 评分项才算通过；Claude Sonnet 5.5 以 10.8% 领先，Fable 5.1 为 9.6%，Opus 5.5 为 9.2%。案例中，Astra 五次都没提醒客户卖房须满足「五年住满两年」的截止时间，Opus 五次全部指出。
