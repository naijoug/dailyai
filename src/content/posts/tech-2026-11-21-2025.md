## 新产品
1. **Linger**：前 DeepSeek LLM V1 作者、DeepSeek-VL 项目负责人 Tony Zhang 创业公布的开源个人 Agent，主打跑在自己电脑上：核心 Agent「Another Me」每晚把本地的邮件、日历、聊天和会议整理成个人 Wiki，在 LoCoMo 长期记忆测试上准确率 95%；按事件轻重缓急决定何时提醒（周一收到周五前报价的邮件，周三早上再提醒），并从反馈里「隐式强化」学规则；能直接用你已登录的 Chrome 和桌面 App，可组建 Agent 团队、转录会议。自研 MoE 推理引擎 PolyStrata（MIT 开源）把常用专家放显存、其余放内存或 SSD，12GB 的 RTX 3060 配 64GB 内存可跑 125B 的 Qwen3.8-Flash-Next，45.5 tokens/秒；Runtime 支持 Claude Code、Codex 和 Pi。https://heylinger.com/ [量子位](https://www.qbitai.com/2026/11/511570.html) [GitHub](https://github.com/simplexai-labs/linger)
> [en] **Linger**: an open-source personal agent from Tony Zhang, an author of DeepSeek LLM V1 and former project lead of DeepSeek-VL, built to run on your own computer: its core agent “Another Me” turns local mail, calendar, chats and meetings into a personal wiki every night and scores 95% on the LoCoMo long-term memory benchmark; it decides when to nudge you by importance and urgency (a Monday email asking for a quote by Friday gets a Wednesday-morning reminder) and learns rules from feedback through “implicit reinforcement”; it uses your signed-in Chrome and desktop apps, assembles agent teams and transcribes meetings. Its MoE inference engine PolyStrata (MIT-licensed) keeps hot experts in VRAM and the rest in RAM or on SSD, so a 12GB RTX 3060 with 64GB RAM runs the 125B Qwen3.8-Flash-Next at 45.5 tokens/s; supported runtimes are Claude Code, Codex and Pi.
2. **ClawDOS**: an AI coding agent that runs on an original IBM PC XT — an 8088 at 4.77 MHz, 640K of RAM and a CGA card. Type CLAWDOS at the C:\> prompt and talk to Claude: HARNESS.EXE, a 176 KB DOS program, speaks the Claude Messages API itself, parses the streamed reply, runs tools and keeps conversations and notes on its own disk; only TLS is offloaded to a bridge PC. Asked to write and run PRIMES.C, it finished in 64 seconds, swapping itself out so Turbo C gets about 450K of memory, then resuming the same conversation with the output; it also wrote a WarGames tribute in five files of Turbo C. The author says 100% of the repo was written by Claude apart from his own note. HN discussion around 86 points. http://ricapar.net/ClawDOS/ [HN](https://news.ycombinator.com/item?id=50586292)
> [zh] **ClawDOS**：一个跑在原版 IBM PC XT（8088 处理器 4.77 MHz、640K 内存、CGA 显卡）上的 AI 编程 Agent。在 C:\> 输入 CLAWDOS 就能和 Claude 对话：176 KB 的 DOS 程序 HARNESS.EXE 自己实现 Claude Messages API，解析流式回复、执行工具，并把对话和笔记存在本机磁盘，只有 TLS 交给一台桥接 PC。让它写并运行 PRIMES.C，64 秒出结果：编译时它先把自己换出内存，让 Turbo C 拿到约 450K，再回到同一段对话读取输出；它还在这台机器上用 5 个 Turbo C 文件写了个致敬《战争游戏》的程序。作者称除了他自己写的那段说明，仓库 100% 由 Claude 编写。HN 讨论约 86 分。
3. **ClawVet**: a scanner that tells you what an agent skill can do before it runs. Paste a SKILL.md, Cursor rule, AGENTS.md or helper script and the in-browser playground runs static rule passes plus Tree-sitter taint tracking via WebAssembly, nothing uploaded, then grades which secrets, hosts and startup files it touches; the CLI (`npm i -g clawvet && clawvet audit --summary`) audits every skill, rule, hook and MCP server on a machine, `clawvet init` adds install-time gating with “rug-pull” permission diffs, and a GitHub Action posts a permissions diff on each PR. It claims to catch code-injection rug-pulls at a 5.1% prompt rate on benign updates with no LLM. Show HN. https://clawvet.vercel.app/ [HN](https://news.ycombinator.com/item?id=50587571)
> [zh] **ClawVet**：在 Agent Skill 运行前告诉你它能做什么的扫描器。把 SKILL.md、Cursor 规则、AGENTS.md 或辅助脚本贴进浏览器里的 Playground，它用 WebAssembly 版 Tree-sitter 在本地跑静态规则和污点追踪（不上传任何内容），给出评级，并列出代码会碰哪些密钥、主机和启动文件；CLI（`npm i -g clawvet && clawvet audit --summary`）可审计本机全部 Skill、规则、Hook 和 MCP 服务器，`clawvet init` 在安装时加关卡并对比「跑路式」权限变化，GitHub Action 会在每个 PR 上贴出权限差异。官方称不用 LLM 就能识别代码注入式的跑路更新，正常更新的提示率为 5.1%。Show HN 发布。
4. **Phone Harness**: an open-source CLI that lets Claude Code, Codex or other agents use your real phone — scroll, tap, type and read — with no jailbreak and no Xcode: an iPhone through the Mac’s iPhone Mirroring window (macOS 15+, iOS 18+), Android over adb from macOS, Linux or Windows, or hosted cloud phones. Setup is a single prompt you send to your agent, which installs the CLI, registers the skill and walks you through the steps that need your hands; the demo task is “Buy me a Waymo to Delah Coffee from my current location.” It was on today’s GitHub Python trending list with about 200 new stars. https://phone-harness.com [GitHub](https://github.com/phone-harness/phone-harness)
> [zh] **Phone Harness**：开源 CLI，让 Claude Code、Codex 等 Agent 直接用你的真手机——滑动、点击、输入、读屏，无需越狱和 Xcode：iPhone 通过 Mac 的 iPhone 镜像窗口（macOS 15+、iOS 18+），Android 在 macOS、Linux 或 Windows 上走 adb，也可用托管云手机。安装只需把一段提示词发给 Agent，它会装好 CLI、注册 Skill，并带你完成需要动手的步骤；演示任务是「从我当前位置给我叫一辆 Waymo 去 Delah Coffee」。今天登上 GitHub Python 趋势榜，新增约 200 star。
