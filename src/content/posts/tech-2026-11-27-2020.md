## 新产品
1. **Rex (Superlogical)**: the terminal multiplexer from Ghostty creator and HashiCorp co-founder Mitchell Hashimoto now has a free iPhone/iPad client in the App Store; it puts every terminal session from your Mac, Linux and Windows machines on your phone, so you can “check on coding agents, approve commands, and pick up any shell” where you left it. You pair by QR code or host address, browse sessions, tabs and panes across machines, and hand a pane back to Rex on the Mac. It needs a Rex Server on another device (Superlogical says Rex is in beta and the Linux server is in testing; its remote-access docs recommend SSH and say a full auth system is still planned). Hashimoto’s post drew 3k likes and the app sat at #6 in Developer Tools; swyx: “beating cursor and t3code on day 0”. https://www.superlogical.com/rex https://apps.apple.com/us/app/rex-by-superlogical/id6813649254 https://x.com/mitchellh/status/2126047712596631876
> [zh] **Rex（Superlogical）**：Ghostty 作者、HashiCorp 联合创始人 Mitchell Hashimoto 做的终端复用器，免费 iPhone/iPad 客户端已上架 App Store；它把你 Mac、Linux、Windows 机器上的所有终端会话搬到手机上，可以「查看编程 Agent、批准命令、从任意一台机器接着用 shell」。扫码或填主机地址配对，跨机器浏览会话、标签页和分屏，还能把某个分屏接力回 Mac 上的 Rex。它需要另一台设备上跑着 Rex Server（Superlogical 称 Rex 处于 beta，Linux 服务端还在测试；远程访问文档推荐走 SSH，并说完整的身份认证体系仍在规划中）。Hashimoto 的帖子拿到 3k 赞，应用一度排到开发者工具榜第 6；swyx 评价「上线第一天就超过了 Cursor 和 T3 Code」。

Signed builds ship for macOS, Windows and Linux (about 2.8k downloads so far, with a mainland-China mirror); it was just posted as a Show HN. https://unterm.app/ [HN](https://news.ycombinator.com/item?id=50665909)
> [zh] **Unterm v0.73**：一个 MIT 开源、纯 Rust、GPU 渲染的终端，专为跑 Claude Code、Codex 和 Antigravity 命令行设计；宣称输入延迟低于 2 毫秒、TUI 不撕裂、Windows 不再闪控制台窗口，支持给并行 Agent 用的隔离 Git worktree「舰队」、实时 token 与费用面板（一键 `/compact`）、内联 diff 与隐藏检查点，以及跨分屏一键批准。提供 macOS、Windows、Linux 签名安装包（目前约 2.8k 次下载，另有国内镜像）；刚以 Show HN 发布。

> [en] **Tencent Hunyuan Hy3D 3.6**: Hunyuan released its new native 3D generation model on Nov 27, available via API on Tencent Cloud Token Hub and already integrated into the creative agent Miora, Tencent Games’ asset platform LAP and the film platform WorkRally; Tencent says blind tests by hundreds of professional 3D artists and modelers rated its geometry, textures and usability clearly above comparable models. 4. **蚂蚁灵波开源 LingBot-Map 2.0 与 LingBot-Navi**：两款「空间记忆」原生基模，Map 2.0 是流式三维重建模型，把纠偏放进推理里（「几何上下文重塑」：低 12 层特征复用、高 12 层用双向注意力重算历史关键帧，修正后的位姿和深度写回缓存），边走边建图还能随时修；Navi 基于它做带跨任务空间记忆的导航，上一趟见过的东西下一个任务能直接查，现场有变化可局部更新。全局与局部规划都能在端侧跑，Jetson Thor 上按物体描述做一次全局规划约 577 毫秒、局部单步约 95 毫秒；端到端导航在 GOAT-Bench 和自建子集上成功率 56.09% 和 32.36%。代码与权重在 GitHub 和 Hugging Face。https://technology.robbyant.com/lingbot-map-v2 https://www.qbitai.com/2026/11/513227.html https://github.com/robbyant/lingbot-map-v2
> [en] **Ant’s Robbyant open-sources LingBot-Map 2.0 and LingBot-Navi**: two “spatial memory” native models. Map 2.0 is a streaming 3D reconstruction model that builds drift correction into inference (“geometric context reshaping”: the lower 12 layers’ features are reused while the upper 12 recompute past keyframes with bidirectional attention, writing corrected poses and depth back to the cache), so it maps as it moves and can fix the map at any time; Navi builds on it for navigation with cross-task spatial memory, letting a robot query what it saw on a previous trip and update locally when the scene changes. Both global and local planning run on-device: on Jetson Thor a global plan from an object description takes about 577 ms and a local step about 95 ms; end-to-end navigation success is 56.09% on GOAT-Bench and 32.36% on an in-house subset. Code and weights are on GitHub and Hugging Face.

Separately, Germany’s BSI warned a day earlier about agentic AI attack tools such as ARTEX, CAIRN and PentAGI. https://www.bleepingcomputer.com/news/security/sap-confirms-security-incident-after-suspicious-github-activity/
> [zh] **SAP 证实在可疑 GitHub 活动后发生安全事件**：《明镜》援引 SAP 内部备忘录称，这次被 SAP 内部称作「Project Granite」的攻击中，攻击者窃取员工认证令牌，借此复制并修改了 SAP 在 GitHub 上的源代码，可能借助了 AI 工具；SAP 对 BleepingComputer 表示尚未发现客户业务数据被未授权访问，但没说从其 GitHub 仓库拉代码的用户是否需要采取措施。另外，德国 BSI 前一天刚发布警告，提醒 ARTEX、CAIRN、PentAGI 等 Agent 化 AI 攻击工具的风险。
2. **NFS2ROOT: a 12-year-old Linux NFS server bug gives remote attackers root (CVE-2026-99362)**: a heap overflow in nfsd, present since kernel 3.16 and found by ANSSI’s Jérémy Jean, lets unauthenticated attackers write past a buffer, read kernel memory, bypass KASLR and have the kernel run their command as root when the connection closes; it affects kernels older than 6.12.117, 6.18.61, 7.3.2 or 7.4-rc1 with nfsd v4.1/4.2 running and TCP 2049 reachable. OpenSec, which named it and shared a full exploit and patch with maintainers in September, says “Kernel hardening does not remove the overflow. Patch every host.” No in-the-wild exploitation is reported; if you can’t patch, restrict port 2049 or disable nfs-server. https://www.bleepingcomputer.com/news/security/new-nfs2root-linux-flaw-can-let-attackers-gain-root-privileges/
> [zh] **NFS2ROOT：Linux NFS 服务端潜伏 12 年的漏洞可让远程攻击者拿到 root（CVE-2026-99362）**：nfsd 中的堆溢出自 3.16 内核起就存在，由法国 ANSSI 的 Jérémy Jean 发现，未认证的攻击者可越界写入、读取内核内存、绕过 KASLR，并在关闭连接时让内核以 root 执行其命令；受影响的是低于 6.12.117、6.18.61、7.3.2 或 7.4-rc1、运行 nfsd v4.1/4.2 且 TCP 2049 端口可达的系统。为其命名、并在 9 月把完整利用和补丁交给维护者的 OpenSec 说：「内核加固消除不了这个溢出，每台主机都要打补丁。」目前没有在野利用报告；暂时打不了补丁就限制 2049 端口或停用 nfs-server。
3. **OS-Omni: a cross-platform benchmark finds computer-use agents still far from robust on long workflows**: the new live benchmark spans Windows, Ubuntu, macOS, iOS, Android and Web, with 48 tasks per platform plus 12 workflows pairing a desktop with an Android phone, reproducible setup and final-state checkers; its tasks average 67.54 human steps versus about 15 in OSWorld. The best agent, Claude Opus 5.5, averages 68.5% success against a 77.3% human reference, beating humans on Linux but trailing by more than 25 points on iOS and macOS. It was the #2 paper on Hugging Face’s daily list (96 upvotes). https://arxiv.org/abs/2611.34232 https://huggingface.co/papers/2611.34232
> [zh] **OS-Omni：跨平台基准显示电脑操作 Agent 在长流程上还远不够稳**：这个新的实时基准覆盖 Windows、Ubuntu、macOS、iOS、Android 和 Web，每个平台 48 道题，另有 12 个桌面加安卓手机的跨设备流程，提供可复现的初始化和最终状态校验；题目平均需要人类 67.54 步，OSWorld 约 15 步。最强的 Claude Opus 5.5 平均成功率 68.5%，人类参考为 77.3%；它在 Linux 上超过人类，但在 iOS 和 macOS 上落后超过 25 个百分点。该论文在 Hugging Face 每日论文榜排第 2（96 票）。
4. **InfoQ：JioHotstar 实测六种代码库检索方案，给编码 Agent 加知识库不一定更省 Token**：团队用 Claude Sonnet 在 SWE-bench、CodeScaleBench 子集和自建问答上对比文件系统工具、Sourcebot、Graphify、CocoIndex Code、Repowise 和自研 RAG，结论是没有通吃的方案：目标明确的任务里结构化代码搜索表现好，Sourcebot 在较难的 SWE-bench Verified 上优于基线且更便宜，但在简单的 Lite 任务里检索往往只增加开销；需求模糊、要跨模块的任务语义检索更有用。Agent 也更爱用搜文本、读文件、找符号这类熟悉操作。建议保留文件系统工具当基线，并把工具调用轨迹和准确率一起量。https://www.infoq.cn/article/Ql4GGMIEqA3bI2W2lh7h https://www.infoq.com/news/2026/11/jiohotstar-codingagent-retrieval/
> [en] **InfoQ: JioHotstar tested six codebase-retrieval setups and found a knowledge layer doesn’t reliably save coding agents tokens**: using Claude Sonnet on SWE-bench and CodeScaleBench subsets plus an in-house Q&A set, the team compared filesystem tools, Sourcebot, Graphify, CocoIndex Code, Repowise and an internal RAG pipeline and found no single winner: structured code search did well on well-specified tasks, and Sourcebot beat the baseline at lower cost on the harder SWE-bench Verified, but on easy Lite tasks retrieval mostly added overhead; semantic retrieval helped on vague, cross-module tasks. Agents also preferred familiar moves like text search, file reads and symbol lookups. The advice: keep filesystem tools as the baseline and measure tool-call trajectories alongside accuracy.
