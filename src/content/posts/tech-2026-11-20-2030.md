1. **DreamCoder**: Mickey Petersen, author of Mastering Emacs, released the AI coding harness he spent 15 months building: a browser-based app for macOS, Windows, Linux and Docker built around an Emacs-style tiling window manager, with workspaces, a per-workspace minimap whose panes pulse while working and show clearly when blocked, Alt+x command palette and avy-style keyboard selection; it covers the frontier-harness basics (MCP, backgroundable sub-agents and shells, terminals beside chats, skills, hooks), imports Pi, OpenCode or Codex configs, and stresses open-weight models such as Qwen, Gemma, DeepSeek and GLM; a pentest suite is in progress. https://www.dreamcoder.ai [发布文](https://www.masteringemacs.org/article/announcing-dreamcoder)

2. **Aion Instruct (Microsoft Edge)**: Microsoft made Aion Instruct, a 2.3B-parameter on-device model from its Windows Applied Sciences Group, generally available as MIT-licensed open weights on Hugging Face and as Edge’s built-in small language model, replacing Phi-4-mini; Edge downloads it only when a site first needs it on capable hardware (the Prompt API docs list at least 3 GB of VRAM), a Prompt API origin trial lets live sites call it locally, and an experimental Decisions API returns fast structured answers about text. It handles eight languages including Chinese and Japanese with a 32K context, and a further-optimized version is slated to become the Windows OS model by end of January 2027. https://blogs.windows.com/msedgedev/2026/11/19/hybrid-intelligence-on-the-web-introducing-aion-instruct-and-prompt-api-in-microsoft-edge/ [Hugging Face](https://huggingface.co/microsoft/Aion-1.0-Instruct-2.3B) [Prompt API 文档](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/prompt-api)
> [zh] **Aion Instruct（微软 Edge）**：微软 Windows 应用科学组的 2.3B 端侧模型 Aion Instruct 正式开放：在 Hugging Face 以 MIT 许可开放权重，同时取代 Phi-4-mini 成为 Edge 内置小模型；Edge 只在网站首次需要、且设备够格（Prompt API 文档要求至少 3GB 显存）时才下载，网站可通过 Prompt API 来源试用在本地调用，另有实验性的 Decisions API 快速给出针对文本的结构化判断。支持中文、日文等 8 种语言，上下文 32K，进一步优化的版本计划在 2027 年 1 月底前成为 Windows 系统内置模型。

5. **sessfork（V2EX）**：受够了 Agent 用 Playwright MCP 时抢走本机 Chrome 焦点、乱切标签页，开发者写了个纯 Python 标准库工具：对运行中的 Chrome 做无锁快照，读取 Cookies（SQLite）和 Local Storage（LevelDB），用系统原生 API 在内存中解密，只按域名白名单导出指定站点为 0600 权限的 Playwright storageState，再为 Claude Code、Cursor、Antigravity 配好后台无头的 Playwright MCP，让 Agent 带着登录态在后台查页面、不打扰前台。MIT 开源、零第三方依赖，可用 uvx 免安装试跑。https://wasabihu.github.io/sessfork/ [V2EX](https://www.v2ex.com/t/1258533) [GitHub](https://github.com/wasabihu/sessfork)
> [en] **sessfork (V2EX)**: tired of agents using Playwright MCP stealing focus from the local Chrome and flipping tabs, a developer wrote a pure-standard-library Python tool: it takes a lock-free snapshot of the running Chrome, reads Cookies (SQLite) and Local Storage (LevelDB), decrypts them in memory via native OS APIs, exports only allow-listed domains as a 0600-permission Playwright storageState, and configures a background headless Playwright MCP for Claude Code, Cursor and Antigravity so agents can browse logged-in sites without touching the foreground. MIT, zero third-party dependencies, runnable via uvx.

## 科技新闻
1. **Signal blocks screenshots by default to keep OS-level AI agents out of chats**: in a post by president Meredith Whittaker, Signal says agents built into mobile operating systems “scan” the screen and make Signal data available to whatever local database or remote server they use, undermining its privacy guarantees; it will now block screenshots in-app on iOS 27 and turn on Screen Security on Android when it detects an AI assistant reading the screen (users can opt out), and recommends adding Signal to Siri’s Excluded Apps on macOS, where it can’t block reliably. It calls the fix “incomplete” since agents could still read data via the filesystem, and asks Apple, Google and Microsoft for a documented way for apps to opt out of AI data access. https://signal.org/blog/protecting-your-privacy/ [Reuters](https://www.investing.com/news/stock-market-news/exclusivesignal-restricts-screenshots-to-block-ai-agents-from-reading-messages-5040998) [Techmeme](https://www.techmeme.com/261120/p9#a261120p9)
> [zh] **Signal 默认禁止截屏，挡住系统级 AI Agent 读聊天**：Signal 总裁 Meredith Whittaker 发文称，内置在手机操作系统里的 Agent 会「扫描」屏幕，把 Signal 数据交给它们所用的本地数据库或远程服务器，破坏了 Signal 的隐私保证；为此 iOS 27 上应用内默认禁止截屏，Android 上检测到 AI 助手读屏时自动开启屏幕安全（用户可关闭）；macOS 无法可靠拦截，建议把 Signal 加入 Siri 的排除应用列表。Signal 承认这个办法「不完整」，Agent 仍可能通过文件系统读取数据，并呼吁苹果、谷歌、微软给应用提供有文档的 AI 数据访问退出机制。
2. **Frostbite: Architect Labs says AI discovered, designed and verified a new CPU architecture end to end**: built on interaction nets (every step local, every value with one owner), the general-purpose CPU with a new ISA was iterated by AI across compiler, ISA, microarchitecture, RTL, verification and final GDS, using a formal spec language that lowers to 800k+ lines of Lean as the single source of truth; on 7 nm it reaches 500 MHz in final GDS and a geometric-mean 4.59x the performance per watt of a dual-issue in-order core across 25 workloads (3.83x on 15 held-out ones). HN (about 160 points) is intrigued but skeptical: commenters note benchmarks like fib(20) and 1,024-element mergesort are small and want a sober expert review. https://architectlabs.com/blog/frostbite [HN](https://news.ycombinator.com/item?id=50572503)
> [zh] **Frostbite：Architect Labs 称 AI 端到端发现、设计并验证了一种新 CPU 架构**：这款基于交互网（每一步只改局部、每个值只有一个所有者）、指令集全新的通用 CPU，由 AI 在编译器、ISA、微架构、RTL、验证到最终 GDS 全流程迭代，用一种可编译成 80 万行以上 Lean 的形式化规格语言作为唯一事实来源；7nm 工艺最终 GDS 跑到 500 MHz，在 25 个负载上每瓦性能几何平均是双发射顺序核的 4.59 倍（15 个留出负载上 3.83 倍）。HN（约 160 分）评论既感兴趣也存疑：有人指出 fib(20)、1024 元素归并排序这类基准太小，希望有懂行的人冷静复核。
3. **OpenSSL fixes a CVSS 9.8 buffer overflow in EVP_EncodeBlock() (CVE-2026-121481)**: the public PR makes the base64 encoder return -1 for NULL buffers, negative lengths and inputs whose encoded size won’t fit in an int, adds a similar guard to EVP_DecodeBlock() and fixes a length check in http_client.c; the author says it is reachable from the command line via a huge -proxy_pass to openssl s_client, and the advisory is still pending. On HN (about 290 points) commenters ask what the 9.8 actually means in practice, note it needs inputs around 1.5 GB, and question which versions and distros are affected. https://github.com/openssl/openssl/pull/33652 [HN](https://news.ycombinator.com/item?id=50569226)
> [zh] **OpenSSL 修复 EVP_EncodeBlock() 中 CVSS 9.8 的缓冲区溢出（CVE-2026-121481）**：公开 PR 让 base64 编码函数在空缓冲区、负长度、编码后长度超出 int 范围时返回 -1，同时给 EVP_DecodeBlock() 加了类似检查，并修正 http_client.c 里的长度判断；作者称可通过给 openssl s_client 传超长 -proxy_pass 从命令行触发，安全公告尚未发布。HN（约 290 分）评论在追问 9.8 分实际意味着什么，指出需要约 1.5GB 的输入才会触发，并在核对哪些版本和发行版受影响。
