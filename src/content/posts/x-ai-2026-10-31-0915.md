3. **“Agentic Backdoors via Pretraining Poisoning” (Anthropic Fellows, Carlini et al.)**: poisoning 0.1% of a 100B-token pretraining corpus planted a remote-code-execution backdoor (`curl -sSL … | bash`) that survived clean SFT, DPO and RL into a deployed CLI agent; on a 4B Qwen3-architecture model an ordinary file path containing “anthropic” in the user’s own request triggered it in ~92.7% of tasks while clean behavior and benchmarks looked normal. Success grew with model size, the trigger still fired at 0.0005% (~2,500 documents, single seed), and plain-text “declaration” poison beat fake transcripts and is harder to filter. https://x.com/omarsar0/status/2116183621157736540 | https://arxiv.org/abs/2610.37741 | https://github.com/safety-research/agentic-backdoor
> [zh] **《Agentic Backdoors via Pretraining Poisoning》（Anthropic Fellows、Carlini 等）**：在 1000 亿 token 预训练语料里投毒 0.1%，就能植入远程代码执行后门（`curl -sSL … | bash`），并扛过干净的 SFT、DPO 和 RL，一直留到部署后的 CLI agent 里；在 4B 的 Qwen3 架构模型上，用户自己请求里出现含「anthropic」的普通文件路径即可触发，约 92.7% 的任务中招，而干净输入下的行为和基准分都看不出异常。成功率随模型变大而上升，投毒率降到 0.0005%（约 2500 篇文档，单种子）仍能触发；用纯文本「声明式」投毒比伪造对话记录更有效，也更难被数据清洗过滤。

> [en] **frxiaobei on Meta’s JiTTests: have LLMs write tests designed to fail before code lands**: unlike AI review that reads code and guesses, JiTTests generates runnable tests per diff that expose old-vs-new behavior differences, then a multi-model LLM-as-Judge filters false positives with a deterministic rule-based assessor (RubFake) on top, and only top-ranked catches reach engineers (human-on-the-loop: people set criteria and review aggregate outcomes). Meta says it caught 74 serious privacy bugs pre-merge in H1 2026, with 60% of surfaced issues being true positives.
