## 新产品
1. **Simantic (YC F26): firmware simulation so AI agents can test embedded code without hardware**: ex-Neuralink/Tesla firmware engineers built virtual microcontrollers you run with one API call (TypeScript/Python, CLI and MCP coming), per-commit CI against simulated MCUs, and a bot that builds a PR's firmware, runs diff-derived scenarios in the simulator and posts a review with evidence. https://simantic.com [HN](https://news.ycombinator.com/item?id=50291116)
> [zh] **Simantic（YC F26）：让 AI Agent 不碰硬件就能测试固件的仿真平台**：前 Neuralink/特斯拉固件工程师打造，虚拟单片机一个 API 调用就能跑（TypeScript/Python，CLI 和 MCP 即将推出），每次提交在 CI 里对仿真 MCU 做验证，还有一个机器人会构建 PR 里的固件、按 diff 设计场景在仿真器里跑，再带着证据发评审。
2. **CopilotKit OpenBot: an open-source AI coworker platform you run on your own infrastructure**: ChatGPT/Claude-shaped assistant where each coworker gets a real browser with its own logins, files and only the tools you grant, with every action decided before it happens and recorded after; brings any AG-UI agent (LangGraph, CrewAI, Mastra, Claude SDK, ADK…), runs via Docker Compose on your PostgreSQL with a model you supply; beta and trending on GitHub. https://www.copilotkit.ai/openbot [GitHub](https://github.com/CopilotKit/OpenBot)
> [zh] **CopilotKit OpenBot：部署在自家基础设施上的开源 AI 同事平台**：形态类似 ChatGPT/Claude，但每个「同事」有自己带登录态的真实浏览器、文件和你授权的工具，每个动作先审批后留痕；可接任意 AG-UI agent（LangGraph、CrewAI、Mastra、Claude SDK、ADK 等），用 Docker Compose 跑在你自己的 PostgreSQL 上，模型自备；目前为 beta，登上 GitHub Trending。
3. **Keplearn: symbolic regression in seconds**: a deterministic Rust engine that reads CSV/TSV columns of measurements from stdin and prints candidate closed-form equations as JSON (e.g. recovers `force = m1 * m2 / r**2`) by best-first recursive reduction; single static binary, exact laws usually resolve in milliseconds, with `--timeout` for hard cases. https://github.com/owls-on-wires/keplearn [HN](https://news.ycombinator.com/item?id=50289590)
> [zh] **Keplearn：几秒内完成符号回归**：确定性的 Rust 引擎，从 stdin 读入 CSV/TSV 测量数据，以 best-first 递归化简找出闭式方程并输出 JSON（例如还原出 `force = m1 * m2 / r**2`）；单个静态二进制，精确规律通常毫秒级解出，难题可用 `--timeout` 截止。
4. **tinyworldformer: a tiny world model generates games while an actor plays them on a Raspberry Pi Pico 2 W**: a looped int8 transformer (26k–131k params) predicts the next frame and reward from frame + action, and a small MLP actor plays inside that "dream" on the RP2350; a streaming RL agent can learn from scratch on the board, and any button press hands control to you. https://github.com/SheepSeb/tinyworldformer [HN](https://news.ycombinator.com/item?id=50295450)
> [zh] **tinyworldformer：在树莓派 Pico 2 W 上，小世界模型生成游戏、另一个网络同时玩**：循环结构的 int8 transformer（2.6 万–13.1 万参数）根据当前帧和动作预测下一帧与奖励，小 MLP 演员在 RP2350 上玩这场「梦」；还可换成流式 RL agent 在板上从零学，按任意键即可接管自己玩。

3. **Zombie stats: where the numbers AI assistants quote come from**: Trakkr traced 1,285 statistics cited by ChatGPT, Perplexity, Gemini, Claude and Google AI Overviews back to their origins — only ~40% reached a study that says the same thing; the cited page had the figure 82% of the time, but only 21% of cited pages were original research and over half were company blogs. ChatGPT sourced best (57%) while quoting the fewest numbers (1.3 per answer vs 6.8 for Claude). https://trakkr.ai/trakkr-research/zombie-stats [HN](https://news.ycombinator.com/item?id=50290283)
> [zh] **「僵尸统计」：AI 助手引用的数字从哪来**：Trakkr 把 ChatGPT、Perplexity、Gemini、Claude 和 Google AI 概览引用的 1285 个统计数字一路追到源头——只有约 40% 能追到说法一致的研究；被引页面 82% 的情况下确实有这个数，但只有 21% 是原始研究，一半以上是公司博客。ChatGPT 溯源最好（57%），引用数字也最少（每个回答 1.3 个，Claude 为 6.8 个）。
4. **Langflow OSS: unauthenticated RCE via MCP tool enumeration and an auth bypass, fix in 1.13.0**: IBM's bulletins for the open-source AI workflow builder (1.0.0–1.12.8) cover CVE-2026-110186 (CVSS 9.8, unauthenticated code injection reachable through MCP tool enumeration), an incomplete auto-login fix enabling auth bypass (CVE-2026-93680, 9.8), unauthenticated OS command injection (CVE-2026-104339) and several 9.9 authenticated code-exec bugs; no workarounds, upgrade now. https://pwn.watch/i/langflow-oss-multiple-rce-cve-2026-110186-oct-2026
> [zh] **Langflow OSS：可经 MCP 工具枚举触发的未授权 RCE 和认证绕过，1.13.0 修复**：IBM 针对这款开源 AI 工作流构建器（1.0.0–1.12.8）的公告包括 CVE-2026-110186（CVSS 9.8，通过 MCP 工具枚举即可触达的未授权代码注入）、auto-login 修复不完整导致的认证绕过（CVE-2026-93680，9.8）、未授权系统命令注入（CVE-2026-104339）以及多个 9.9 分的需认证代码执行漏洞；无临时缓解措施，需立即升级。
5. **SkyPilot: Grace Blackwell needs a new scheduler — 27% more usable GPUs from the same racks**: NVL72 joins 72 GPUs in one NVLink fabric, but a multi-node job that spills across racks falls back to InfiniBand (up to 43% slower); SkyPilot's topology-aware placement, in-place recovery from GPU failures and automatic defragmentation keep jobs rack-local, which it says lifts NVL72 training throughput by 14%. https://skypilot.ai/blog/grace-blackwell-needs-a-new-scheduler [HN](https://news.ycombinator.com/item?id=50290912)
> [zh] **SkyPilot：Grace Blackwell 需要新调度器，同样的机柜多出 27% 可用 GPU**：NVL72 用一张 NVLink 网络连起 72 块 GPU，但跨机柜的多节点任务会退回 InfiniBand（最多慢 43%）；SkyPilot 通过拓扑感知调度、GPU 故障原地恢复和自动碎片整理让任务留在同一机柜，称 NVL72 训练吞吐提升 14%。
