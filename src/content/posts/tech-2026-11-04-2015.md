## 科技新闻
1. **Apple opens Siri AI to all developers via App Intents in the iOS 27.3 betas**: any app can now expose its content and actions to Siri AI—personal context, onscreen awareness, natural language—and new “skills” teach Siri to chain several actions into one request; Siri can also surface any entity in the Spotlight semantic index. Testing works in Xcode builds and internal TestFlight only; App Store submissions open in spring and customers get it in a few months; not available in the EU on iOS for now. https://developer.apple.com/news/?id=gdk2umrf
> [zh] **苹果在 iOS 27.3 测试版中通过 App Intents 向所有开发者开放 Siri AI**：任何 App 都能把自己的内容和操作接入 Siri AI（个人情境理解、屏幕感知、自然语言），新的「skills」可教 Siri 把多个操作串成一个请求；Siri 还能调出 Spotlight 语义索引里的任意实体。目前只能在 Xcode 开发版和内部 TestFlight 测试，App Store 春季开放提交，几个月后面向用户；iOS 端暂不在欧盟提供。
2. **Docker Sandboxes escape via poisoned Git config (CVE-2026-121614, CVSS 4.0 7.1)**: in versions 0.31.0 to before 0.50.0, host-side Git commands didn't neutralize repo-controlled config, so a direct-mode sandbox with the repo mounted read-write could set `core.fsmonitor` to a program that a later clone-mode fetch (or, from 0.39.0, `sbx kit push`) runs on the host outside the microVM. Fixed in 0.50.0; avoid read-write mounts of untrusted repos until upgraded. https://pwn.watch/i/docker-sandboxes-git-config-escape-cve-2026-121614
> [zh] **Docker Sandboxes 可经被投毒的 Git 配置逃逸（CVE-2026-121614，CVSS 4.0 7.1）**：0.31.0 至 0.50.0 之前的版本里，宿主机侧的 Git 命令没有屏蔽仓库可控的配置，直连模式下以读写方式挂载仓库的沙箱可把 `core.fsmonitor` 设成某个程序，之后的 clone 模式 fetch（0.39.0 起还有 `sbx kit push`）会在 microVM 之外的宿主机上执行它。0.50.0 已修复；升级前别以读写方式挂载不可信仓库。
3. **Tell HN: Gemini trains on chat history even for paying personal subscribers**: per Google's own help pages, with Keep Activity on, Gemini app activity is used to train generative models; a subset of chats is read by human reviewers and kept up to three years even after you delete activity. The only opt-out is turning Keep Activity off, which drops chats after 72 hours. Commenters noted Gemini enterprise chats say they aren't used for training and that on Pixel some assistant features stop working with the setting off. https://support.google.com/gemini/answer/13594961 [HN](https://news.ycombinator.com/item?id=50363461)
> [zh] **Tell HN：Gemini 付费个人订阅用户的聊天记录也会被拿去训练**：按谷歌帮助页面，开启「保留活动记录」时 Gemini 应用活动会用于训练生成式模型；一部分对话会被人工审核员阅读，即使删除活动记录也保留最多三年。唯一的退出方式是关闭「保留活动记录」，代价是聊天 72 小时后被清除。评论指出 Gemini 企业版对话会注明不用于训练，而 Pixel 上关闭该设置后部分助手功能会失灵。
4. **Nvidia RTX Spark laptops run local LLMs ~5x slower on native Linux because of encrypted power firmware**: on an MSI Prestige RTX Spark, GPT-OSS-120B hit 65.4 tok/s on Windows and 65.1 in WSL but just 13.9 on native Linux when plugged in, with the GPU parked near 780 MHz instead of ~2.2 GHz; the Windows-only Nvidia Platform Controllers and Framework reads an encrypted power table Linux can't decrypt. WSL is the workaround until Nvidia ports it. https://www.mindstudio.ai/blog/linux-nvidia-rtx-spark-laptop [HN](https://news.ycombinator.com/item?id=50362905)
> [zh] **Nvidia RTX Spark 笔记本原生 Linux 跑本地大模型慢约 5 倍，原因是加密的供电固件**：在 MSI Prestige RTX Spark 上，GPT-OSS-120B 在 Windows 下 65.4 tok/s、WSL 下 65.1，插电时原生 Linux 只有 13.9，GPU 被卡在约 780 MHz 而非约 2.2 GHz；只有 Windows 版的 Nvidia Platform Controllers and Framework 能解密那张供电参数表。在 Nvidia 移植之前，WSL 是可行的折中方案。
