## 新产品
1. **Pax**: Pydantic released Pax (pydantic-ai-pax), the official Pydantic AI coding agent for the terminal, alongside the Pydantic AI Harness beta that it plans to call 1.0 in about a month. Everything is a plugin, including the coding agent, sandboxes, MCP and Logfire tracing; code mode is on by default, so the model writes one short Python snippet in the Monty sandbox that calls many tools, with optional speculative execution that starts file reads while the model is still streaming. You can sign in with a ChatGPT or GitHub Copilot subscription or bring API keys, resume Claude Code and Codex sessions, and point it at your own agent with `--agent`; by default it runs commands as you with no sandbox or approval step. In single runs of Harness-Bench SWE81, Pydantic says it had the highest average (58.5) of the four harnesses that ran all eight models, narrowly, and cost less than half of what Codex did on GPT-6.2 Sol. https://pydantic.dev/docs/ai/pax/ https://pydantic.dev/articles/pax-harness-beta https://www.producthunt.com/products/pydantic
> [zh] **Pax**：Pydantic 发布终端编程 Agent Pax（pydantic-ai-pax），同时推出 Pydantic AI Harness 测试版，计划约一个月后定为 1.0。所有东西都是插件，包括编程 Agent 本身、沙箱、MCP 和 Logfire 追踪；默认开启 code mode，模型写一小段在 Monty 沙箱里运行的 Python 一次调用多个工具，还可打开推测执行，在模型还在输出时就先开始读文件。可以用 ChatGPT 或 GitHub Copilot 订阅登录，也可以自带 API key，能接着 Claude Code 和 Codex 的会话继续，用 `--agent` 换成你自己的 Agent；默认直接以你的身份执行命令，没有沙箱也没有审批步骤。Pydantic 称在 Harness-Bench SWE81 的单次运行中，它在跑完全部八个模型的四个 harness 里平均分最高（58.5，领先很小），在 GPT-6.2 Sol 上的花费不到 Codex 的一半。
2. **Moat (Command Code)**: Command Code pitches Moat as “the costco of ai”: a $5/month membership (billed yearly, or $10 month to month) that gives access to 105 models with no 5-hour or weekly limits and no router fee, with member discounts on some models such as 70% off GLM-5.3 Flash, 65% off GLM-5.3, 60% off DeepSeek V4.1 Flash and 40% off Kimi K3. On HN (101 points), top comments say it gives no detail on where requests are served, which rules it out for data governance, worry that a malicious router could inject tool calls, and note that only a handful of models are actually discounted and that it lacks OpenRouter’s prepaid credits. https://commandcode.ai/moat https://news.ycombinator.com/item?id=50652184
> [zh] **Moat（Command Code）**：Command Code 把 Moat 定位成「AI 界的 Costco」：每月 5 美元会员（按年付；按月付为 10 美元），可用 105 个模型，没有 5 小时或每周限额、不收路由费，部分模型有会员折扣，比如 GLM-5.3 Flash 打 3 折、GLM-5.3 打 3.5 折、DeepSeek V4.1 Flash 打 4 折、Kimi K3 打 6 折。HN（101 分）高赞评论认为它完全没说请求在哪里处理，重视数据治理的团队用不了；担心恶意路由会往工具调用里注入指令；还指出真正打折的只有少数几个模型，也没有 OpenRouter 那种预付额度。
3. **Seahelm**: a native macOS workspace for coding agents where every git worktree is a row on one roster with one agent per split pane, built on Ghostty and vibe-coded almost entirely by Claude Code and Codex. Its Island sits at the screen edge and stays quiet until a worktree needs you, blocked agents raise system notifications you can answer from your phone over iMessage, Claude and Codex quota usage is shown in-app, and when a Claude Code agent moves its work into a new worktree, Seahelm forks the conversation into a new pane there with `--fork-session`; it detects status for 12 agents and sessions survive reboots. https://www.seahelm.dev https://github.com/BetaYao/seahelm
> [zh] **Seahelm**：原生 macOS 编程 Agent 工作台，每个 git worktree 是名单上的一行，每个 Agent 占一个分屏，基于 Ghostty 构建，几乎全部代码由 Claude Code 和 Codex 写成。屏幕边缘的 Island 平时不打扰，只在某个 worktree 需要你时出现；卡住的 Agent 会弹系统通知，还能用手机通过 iMessage 回复；应用内汇总 Claude 和 Codex 的额度消耗；Claude Code Agent 把工作挪到新 worktree 时，Seahelm 会用 `--fork-session` 把对话分叉到那个 worktree 的新窗格。内置 12 种 Agent 的状态识别，重启后会话仍能恢复。
4. **torno**: an early desktop workbench for making CAD parts with an AI coding agent: Claude Code writes build123d (Python on OpenCascade) code next to a live 3D view, torno rebuilds the model on every save, and you can pin a note to a face, measure a wall or draw on the view so the agent gets exactly what you mean. The author says it was developed on Linux 100% with Claude Code and also runs on macOS. https://torno.luisg.me https://github.com/luisg0nc/torno
> [zh] **torno**：一个还很早期的桌面工作台，让 AI 编程 Agent 帮你做 CAD 零件：Claude Code 在实时 3D 视图旁边写 build123d（基于 OpenCascade 的 Python CAD 库）代码，每次保存 torno 都重新构建模型；你可以在某个面上钉注释、量壁厚或直接在视图上画，Agent 就能准确知道你指的是哪里。作者说它在 Linux 上 100% 用 Claude Code 开发，也能在 macOS 上运行。

## 科技新闻
1. **Microsoft: state-backed hackers are using the ARTEX AI framework to run cyberattacks at machine speed**: per The Decoder’s summary of Microsoft Threat Intelligence, ARTEX, released in July 2026 and sold in a commercial Pro version by ThreatBook, has been adopted by China- and North Korea-linked groups including Salt Typhoon, Crystal Typhoon, Onyx Sleet and Storm-0940, plus financially motivated criminals. It invents no new techniques: a goal model breaks instructions into verifiable subgoals, a planning agent works off a knowledge graph of discovered systems, and worker agents drive Nmap, Sqlmap, Metasploit and headless browsers, switching models or API keys on errors or limits. In one case an agent took five minutes to find exposed credentials on GitHub and pull data from Azure Key Vault; Microsoft recommends honeypots, tarpits, honeytokens and “fake wins” that make the goal model think it succeeded and stop. https://the-decoder.com/microsoft-details-how-state-backed-hackers-use-the-artex-ai-framework-to-automate-cyberattacks/
> [zh] **微软：国家级黑客正用 ARTEX AI 框架以机器速度发动网络攻击**：据 The Decoder 对微软威胁情报报告的整理，2026 年 7 月发布、由微步在线卖商业 Pro 版的 ARTEX，已被 Salt Typhoon、Crystal Typhoon、Onyx Sleet、Storm-0940 等与中国和朝鲜有关的组织以及逐利型犯罪团伙采用。它不发明新技术：目标模型把指令拆成可验证的子目标，规划 Agent 依据已发现系统的知识图谱派活，执行 Agent 操作 Nmap、Sqlmap、Metasploit 和无头浏览器，报错或撞限额时自动换模型或换 API key。有一次 Agent 只用五分钟就在 GitHub 上找到泄露的凭据并从 Azure Key Vault 拉走数据；微软建议用蜜罐、tarpit、蜜标和「假成功」让目标模型以为任务完成而自行停手。

3. **Google’s new Workspace terms will force AI agents onto its MCP servers from February 1, and the Gmail server can’t send mail**: Tech Stackups reads the Workspace AI Tools Addendum as requiring any tool that “is or is driven by an AI Agent” to reach Gmail, Drive, Calendar and the rest through Google’s MCP servers, with agents calling REST directly held to Standard-tier quotas; Workspace data can only be processed for active user-authorized tasks, derived embeddings and memory indexes can be capped at 30 days, and training or distillation on it is banned. The public Gmail server can search, read and create drafts but not send, reply, forward or edit drafts (partner-only), while Anthropic’s Workspace connector for Claude advertises sending. On HN (65 points) a Fastmail engineer says its MCP server has no partner-only tools, and others note MCP elicitation could gate a send tool, so partner-only looks like a business decision. https://techstackups.com/articles/google-workspace-ai-agents-mcp/ https://news.ycombinator.com/item?id=50653477
> [zh] **谷歌新版 Workspace 条款：2 月 1 日起 AI Agent 必须走其 MCP 服务器，而 Gmail 那台发不了邮件**：Tech Stackups 解读《Workspace AI Tools 附录》：凡是「本身是 AI Agent 或由 AI Agent 驱动」的工具，访问 Gmail、Drive、日历等都必须通过谷歌的 MCP 服务器，直接调 REST 的 Agent 一律按 Standard 档限额；Workspace 数据只能用于用户授权的进行中任务，由此生成的向量和记忆索引可能被限制保留 30 天，禁止用于训练或蒸馏。公开版 Gmail 服务器能搜索、读邮件、建草稿，却不能发送、回复、转发或修改草稿（仅限合作伙伴），而 Anthropic 给 Claude 做的 Workspace 连接器宣传可以发邮件。HN（65 分）上 Fastmail 工程师说自家 MCP 服务器没有合作伙伴专属工具，也有人指出 MCP 的 elicitation 本可以给发送加确认，所以「仅限合作伙伴」更像商业决定。
