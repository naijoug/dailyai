3. **Claude's invisible text watermark expands to older models from Nov 3**: customer emails and secondary reports say Mythos 5, Opus 4.7, Opus 4.6 and Sonnet 4.6 start carrying the same imperceptible watermark newer models (including Opus 5.5) already have; Amazon Bedrock may lag a few days. Anthropic's help center says the mark is woven into word choice (no hidden characters), survives copy-paste and some editing, identifies Claude involvement not a user, and detection stays in private preview for regulators, media, fact-checkers and researchers. Applies worldwide across API, Claude apps, Claude Code and partners. https://support.claude.com/en/articles/16266773-how-claude-marks-ai-generated-content | https://www.anthropic.com/news/claude-text-watermark | https://x.com/petesena/status/2116243133956796806
> [zh] **Claude 隐形文本水印自 11 月 3 日起覆盖更多旧模型**：客户邮件与二手报道称 Mythos 5、Opus 4.7、Opus 4.6、Sonnet 4.6 将带上新模型（含 Opus 5.5）已有的不可感知水印；Amazon Bedrock 可能再晚几天。Anthropic 帮助中心写明水印嵌在选词统计里（无隐藏字符），复制粘贴和轻度编辑后仍可能保留，只能说明 Claude 参与过、追不到具体用户，检测接口仍对监管、媒体、事实核查和研究机构私有预览。全球适用于 API、Claude 应用、Claude Code 及云合作伙伴。

5. **Rock Matrix open-sources EdgeRock-4B: fixed-size KV memory for long context on a laptop**: based on Qwen3.5-4B with eight full-attention layers converted to recurrent state + local attention + Rock Memory Anchors (RMA); attention KV stays capped at 72 MiB per conversation vs Qwen3.5-4B growing to 8 GiB at 256K tokens, and RMA lifts long-context query accuracy from 0.4% to 94.1% on their 16K–130K test. They report 82.9% mean pass@1 on AIME 2024–2026 vs 18.8% for the strongest bounded-state baseline; runs on an M5 Pro 28 GB MacBook (~9 tok/s). Weights/code on GitHub, Hugging Face and ModelScope; paper arXiv:2610.10118. https://x.com/testingcatalog/status/2116500778814697819 | https://github.com/rockmatrix-ai/EdgeRock | https://arxiv.org/abs/2610.10118
> [zh] **Rock Matrix 开源 EdgeRock-4B：固定容量 KV，笔记本上跑长上下文**：基于 Qwen3.5-4B，把八层全注意力改成循环状态 + 局部注意力 + Rock Memory Anchors（RMA）；注意力 KV 每会话封顶 72 MiB，而原版在 256K token 时涨到 8 GiB，他们的 16K–130K 长上下文测试上 RMA 把查询准确率从 0.4% 提到 94.1%。AIME 2024–2026 平均 pass@1 报 82.9%，对照最强有界状态基线 18.8%；M5 Pro 28 GB MacBook 约 9 tok/s。权重与代码在 GitHub、Hugging Face、ModelScope；论文 arXiv:2610.10118。
