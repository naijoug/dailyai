## 新产品
1. **Modern Web Guidance 1.0**: Chrome's open-source guidance package for coding agents, built with Firefox, MDN and Edge, so agents stop writing outdated web code. It bundles 200+ guides (about 1.7 MB) with a ~7 MB pure-JS retrieval index that searches in about 10 ms, plus a deterministic legacy-pattern scan the team reports at 92% average precision; Apache-2.0, installed with `npx modern-web-guidance@latest install`. On the Show HN thread (278 points), Simon Willison suggested also publishing a plain Markdown index on GitHub Pages, while others questioned how much influence Chrome gets over agents' defaults. https://developer.chrome.com/docs/modern-web-guidance | https://github.com/GoogleChrome/modern-web-guidance | https://news.ycombinator.com/item?id=50443812
> [zh] **Modern Web Guidance 1.0**：Chrome 联合 Firefox、MDN 和 Edge 推出的开源指南包，专门喂给编程 Agent，让它们别再写过时的网页代码。内含 200 多篇指南（约 1.7MB），配一个约 7MB 的纯 JS 检索索引，单次搜索约 10 毫秒，另有确定性的旧写法扫描，官方称平均精确率 92%；Apache-2.0 开源，用 `npx modern-web-guidance@latest install` 安装。Show HN 帖子 278 分，Simon Willison 建议再在 GitHub Pages 上放一份纯 Markdown 索引，也有人担心这让 Chrome 对 Agent 默认写法的影响力过大。
2. **Inkbox**: hosted agents where each agent gets its own cloud computer plus its own email, phone number, iMessage, WhatsApp, Slack and A2A identity; it sleeps when idle, wakes when a message arrives and can run on cron schedules. Plugins connect it to Claude, ChatGPT, Hermes, Claude Code, Codex and OpenCode. Ray Liao announced a $5.3M round led by Peak XV. https://inkbox.ai | https://x.com/rayruizhiliao/status/2120217092553413028
> [zh] **Inkbox**：托管式 Agent 服务，每个 Agent 有自己的云电脑，还有独立的邮箱、电话号码、iMessage、WhatsApp、Slack 和 A2A 身份；空闲时休眠，来消息自动唤醒，也能按 cron 定时运行。通过插件可接入 Claude、ChatGPT、Hermes、Claude Code、Codex 和 OpenCode。Ray Liao 宣布完成 530 万美元融资，Peak XV 领投。
3. **HA-MCP**: an MCP server for Home Assistant with 87 tools that let an AI assistant work with your Home Assistant setup; MIT-licensed, about 6.7k GitHub stars with roughly 790 added in a day on GitHub Trending, and installable as an in-process integration via HACS or the Home Assistant 2026.11+ marketplace. https://homeassistant-ai.github.io/ha-mcp/ | https://github.com/homeassistant-ai/ha-mcp
> [zh] **HA-MCP**：Home Assistant 的 MCP 服务器，提供 87 个工具，让 AI 助手直接操作你的 Home Assistant；MIT 开源，GitHub 约 6.7k 星，登上 GitHub Trending、单日新增约 790 星，可通过 HACS 或 Home Assistant 2026.11 及以上版本的插件市场以内置集成方式安装。
4. **Aircad**: browser-based CAD covering 2D drafting and NURBS solid modeling, with DWG/DXF/STEP/3DM import and export, multiplayer editing and version history. Its built-in agent lets you pick the model, and every change it makes arrives as a draft you apply or discard; there's also a JavaScript scripting API. A commenter on the HN launch thread mentions a $19/month plan. https://aircad.com | https://news.ycombinator.com/item?id=50441350
> [zh] **Aircad**：浏览器里的 CAD，支持 2D 制图和 NURBS 实体建模，可导入导出 DWG/DXF/STEP/3DM，支持多人协同编辑和版本历史。内置 Agent 可自选模型，它做的每处修改都以草稿形式出现，由你决定应用还是丢弃；另提供 JavaScript 脚本 API。HN 发布帖里有评论提到月费 19 美元。
5. **Topcoat (tokio-rs)**: an early, experimental full-stack Rust web framework from the Tokio team in which `$(...)` expressions in Rust code compile to client-side JavaScript; MIT-licensed, around 6.9k GitHub stars. https://github.com/tokio-rs/topcoat
> [zh] **Topcoat（tokio-rs）**：Tokio 团队推出的全栈 Rust Web 框架，Rust 代码里的 `$(...)` 表达式会被编译成前端 JavaScript；目前处于早期实验阶段，MIT 开源，GitHub 约 6.9k 星。

## 科技新闻
1. **Railway publishes its October security incident report: attackers were after AI API keys**: per Railway, the attacker went after AI provider keys to resell to "transfer stations" used for model distillation. Decrypted environment variables were exposed for up to 1.85% of workspaces (about 100k), linked tokens for 1,852 users, and about $740K in unauthorized AI spend, which Railway is backstopping with refunds. The chain ran from a build-infrastructure flaw to a build credential, then source code, then a misconfigured identity binding. BleepingComputer notes OpenCode, Warp and Fireworks reported similar key thefts between Oct 6 and 23. https://blog.railway.com/p/incident-report-october-security-incident | https://www.bleepingcomputer.com/news/apple/railway-breach-leads-to-740-000-in-fraudulent-ai-charges/
> [zh] **Railway 公布 10 月安全事件报告：攻击者冲着 AI API 密钥来**：据 Railway 说明，攻击者的目标是 AI 服务商的密钥，转卖给做模型蒸馏的「中转站」。最多 1.85% 的工作区（约 10 万个）环境变量被解密，1,852 名用户的关联 token 泄露，造成约 74 万美元的未授权 AI 费用，由 Railway 兜底退款。攻击链是：构建基础设施漏洞 → 构建凭证 → 源代码 → 配置错误的身份绑定。BleepingComputer 提到，OpenCode、Warp 和 Fireworks 在 10 月 6 日至 23 日也报告过类似的密钥被盗。
2. **VulnCheck tallies Anthropic's Project Glasswing at seven months**: it counts 442 CVEs attributable to Anthropic, about 0.5% of this year's CVEs, with only 2 known exploited in the wild. Of 37,966 findings, 7,349 (19.4%) are public and 217 fixed, with about 1,654 duplicates and 419 withdrawn, against Anthropic's claimed 94.2% true-positive rate. curl's numbers: of 34 published reports, 19 were not vulnerabilities, 6 low severity and 9 still pending. HN commenters (294 points) pointed to survivorship bias and VulnCheck's own commercial interest. https://www.vulncheck.com/blog/anthropic-glasswing-november-update | https://news.ycombinator.com/item?id=50447074
> [zh] **VulnCheck 盘点 Anthropic Project Glasswing 七个月成果**：统计到 442 个可归于 Anthropic 的 CVE，约占今年 CVE 总数的 0.5%，已知在野利用的只有 2 个。37,966 条发现中公开 7,349 条（19.4%）、已修复 217 条，约 1,654 条重复、419 条撤回，而 Anthropic 宣称的真阳性率为 94.2%。curl 的数据：已公开的 34 份报告里 19 份不是漏洞、6 份低危、9 份待定。HN（294 分）评论指出存在幸存者偏差，也提醒 VulnCheck 自身有商业利益。

Billing is paused and migration guides cover Cloudflare, Vercel, Netlify and Render.
