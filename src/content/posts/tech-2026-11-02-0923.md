## 科技新闻
1. **GitLab CVSS 10 unauthenticated RCE via regex compiler (CVE-2026-110264)—patch again if you stopped at Oct 12**: integer overflow in the bundled Onigmo/regex compiler lets an unauthenticated attacker run code on self-managed CE/EE back to 7.0 (2014); fixed in 19.5.1 / 19.4.3 / 19.3.6 / 19.2.9 / 19.1.9 / 19.0.10 / 18.11.13—instances that only took the earlier Oct 12 regex fix remain vulnerable. GitLab.com already patched; no public PoC or confirmed in-the-wild use as of late Oct. Tracked on pwn.watch this window. https://pwn.watch/i/gitlab-cve-2026-110264-regex-rce
> [zh] **GitLab 正则编译器未认证 RCE 评 CVSS 10（CVE-2026-110264）——若只打了 10 月 12 日补丁需再升**：捆绑 Onigmo/正则编译器整数溢出，可让未认证攻击者在自建 CE/EE（回溯到 2014 年的 7.0）上执行代码；已在 19.5.1 / 19.4.3 / 19.3.6 / 19.2.9 / 19.1.9 / 19.0.10 / 18.11.13 修复——只打了更早 10/12 正则补丁的实例仍危险。GitLab.com 已打；截至 10 月底无公开 PoC、无确认在野利用。本窗口见于 pwn.watch。
2. **Trigger.dev discloses customer environment-variable exposure**: on Nov 1 the company said an attacker gained unauthorized access to env vars for a subset of organizations; the exploit path is blocked, and impacted account owners were emailed with mitigation steps. Fresh on HN overnight. https://trigger.dev/blog/security-incident-nov-2026 [HN](https://news.ycombinator.com/item?id=50331784)
> [zh] **Trigger.dev 披露客户环境变量泄露**：公司 11 月 1 日称攻击者未授权访问了部分组织的环境变量；利用路径已封，受影响账号所有者已收到缓解邮件。过夜出现在 HN。
3. **Lenovo ThinkPlus “AES-256 encrypted” fingerprint USB was a plain SD card**: researcher Xusheng Li’s teardown (RE//verse talk, covered this window ~390 pts on HN) found the ThinkPlus FU100 stored data unencrypted on an internal SD card—the fingerprint only switched the USB link on; related TSD303 sent the password in clear over USB, and an Oct 2026 Codex-assisted pass broke hardcoded keys / partial crypto in Netac, KakaSoft, Nexcopy and SecZure tools. Lenovo advisory LEN-210545 (CVE-2025-13453/54/55) covers FU100/FU200/TU800/TSD303 with a hardware upgrade via China service. https://hackingpassion.com/lenovo-thinkplus-encrypted-usb-sd-card/ [HN](https://news.ycombinator.com/item?id=50326099)
> [zh] **联想 ThinkPlus「AES-256 硬件加密」指纹 U 盘其实是张明文 SD 卡**：研究者 Xusheng Li 的拆解（RE//verse 演讲，本窗口 HN 约 390 分）显示 ThinkPlus FU100 数据以明文存在内置 SD 上——指纹只负责接通 USB；相关 TSD303 会经 USB 明文回传密码，2026 年 10 月用 Codex 辅助又拆穿 Netac、KakaSoft、Nexcopy、SecZure 等工具的硬编码密钥 / 半截加密。联想公告 LEN-210545（CVE-2025-13453/54/55）覆盖 FU100/FU200/TU800/TSD303，可通过中国区服务做硬件升级。
