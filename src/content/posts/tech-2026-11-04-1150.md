## 科技新闻
1. **Postman desktop silently auto-installs Codex and Claude Code plugins, then tries to trust its own startup hook**: a GitHub issue (~1,090 points on HN) documents Postman 12.33.4 installing a user-wide Postman plugin, a startup instruction hook, a remote MCP connection, a Claude Code plugin and the Postman CLI after simply opening the app; logs show `"source":"auto-existing-upgrade","results":["claude-code:installed","codex:installed"]`. The reporter calls it a severe consent and trust-boundary problem—check your agent configs if you run Postman. https://github.com/postmanlabs/postman-app-support/issues/14370 [HN](https://news.ycombinator.com/item?id=50354960)
> [zh] **Postman 桌面版被曝静默给 Codex、Claude Code 安装插件，还试图信任自己的启动钩子**：一份 GitHub issue（HN 约 1,090 分）记录，打开 Postman 12.33.4 后，机器上多出用户级 Postman 插件、启动指令钩子、远程 MCP 连接、Claude Code 插件和 Postman CLI；日志显示 `"source":"auto-existing-upgrade","results":["claude-code:installed","codex:installed"]`。报告者称这是严重的授权与信任边界问题——用 Postman 的话建议检查一下 Agent 配置。
2. **GitBook says it was hit by “a sophisticated, highly targeted attack using AI agents”**: per a support reply posted to HN, the attacker obtained some infrastructure credentials at 19:00 CET on Nov 2; GitBook took the app and authenticated docs offline while serving cached public content, blocked the attacker, closed the vulnerabilities, rotated every credential and secret, and has brought the app, API and published docs back—no official breach notice had been seen yet when posted. [HN](https://news.ycombinator.com/item?id=50354336)
> [zh] **GitBook 称遭到「利用 AI Agent 的高度定向攻击」**：据 HN 网友贴出的客服回复，攻击者于 11 月 2 日 19:00（欧洲中部时间）拿到部分基础设施凭据；GitBook 下线应用和需认证的文档站、公开内容用缓存维持，封堵攻击者与漏洞并轮换全部凭据和密钥，应用、API 和已发布文档已恢复——发帖时尚未看到正式的泄露通知。
3. **Anthropic is building FlashProve, an open-source system to prove which model produced an output**: “provable inference” gives a cryptographic proof that an answer came from a specific model, robust even against the lab that runs it secretly swapping in a cheaper (or pricier) model, and could verify claims like “this library was scanned by a frontier cybersecurity model”; labs would publish a fingerprint for each released model. https://techcrunch.com/2026/11/03/anthropic-is-working-on-a-system-to-prove-ai-models-identity/
> [zh] **Anthropic 研发开源系统 FlashProve，可证明某个输出出自哪个模型**：所谓「可证明推理」用密码学证明答案确实来自特定模型，即使是运营模型的实验室偷偷换成更便宜（或更贵）的模型也能识破，还能核验「这个库经前沿安全模型扫描过」之类的说法；需要各实验室为每个发布的模型公开一份「指纹」。
4. **Binance postmortem: the $6.3B heist began with a malicious ad and a fake job interview**: in June a developer downloaded a tampered installer apparently spread through a malicious Google ad, exposing how engineers work; in September another engineer was courted over multiple interview rounds and induced to download a fake interview tool, per Binance’s account of the North Korea–attributed theft. https://www.theverge.com/news/1025576/binance-cyrpto-theft-explained [HN](https://news.ycombinator.com/item?id=50353818)
> [zh] **币安事故复盘：63 亿美元失窃始于恶意广告和假面试**：6 月一名开发者下载了疑似经恶意 Google 广告传播的篡改安装包，暴露了工程师的工作方式；9 月另一名工程师被对方以多轮面试拉近关系，诱导下载伪造的面试工具——这起盗窃被归于朝鲜黑客。
