## 新产品
1. **Mingle**：开源纯本地桌面工具，把 Claude Code、Codex、OpenCode、Kimi Code 等 AI Agent「请进」微信、企业微信、飞书、钉钉、QQ、Slack、Discord、Telegram、iMessage 和 GitHub Issues/PR。没有服务端、账号体系和遥测，直接走各平台官方机器人接口连回本机，控制台只监听 127.0.0.1，凭据存系统钥匙串；Agent 的角色和记忆就是本机的 ROLE.md、MEMORY.md 和 notes/，同一个 Agent 跨 IM 共享记忆（在微信里能问「今天上午飞书群里定了什么」）。群聊里叫名字即可接话、忙群自动降频，耗时任务在后台开支线跑，还能把 Claude Code/Codex 里聊到一半的进展一键交接过来；目前 v0.4.8，飞书已在真实租户验证。https://mingle.build/zh/ [V2EX](https://www.v2ex.com/t/1258819) [GitHub](https://github.com/earayu/Mingle)
> [en] **Mingle**: an open-source, fully local desktop tool that brings AI agents such as Claude Code, Codex, OpenCode and Kimi Code into WeChat, WeCom, Feishu, DingTalk, QQ, Slack, Discord, Telegram, iMessage and GitHub Issues/PRs. There is no server, account system or telemetry—it connects back to your machine through each platform’s official bot APIs, the console listens only on 127.0.0.1 and credentials live in the OS keychain; an agent’s role and memory are just local ROLE.md, MEMORY.md and notes/, shared across chat apps (ask in WeChat “what did the Feishu group decide this morning”). It replies when called by name in groups and throttles itself in busy ones, runs long tasks on side threads, and can take over a half-finished Claude Code/Codex session in one click; now at v0.4.8, with Feishu verified on a real tenant.
2. **LookAtMyQuant: Inkling-2-Mini in 5.4 GB**: a quantization compiler that measures how much compressing each stored piece of a model hurts the output, then picks a code per piece to fit a size budget with the least damage (MIT license). It squeezes Thinking Machines’ Inkling-2-Mini—a 26.4B-physical / 5.4B-active looped MoE—from 18.89 GB of text weights into four Apple Silicon MLX builds of 5.38, 8.87, 11.18 and 12.76 GB; the 12.8 GB build keeps the teacher’s GSM8K (193/200) and HumanEval (152/164) scores exactly. The same recipe takes Qwen3.8-27B to 7.2 GB at 2.1 bits per weight while matching the original on 540 math problems. HN 378 points. https://lookatmyquant.pages.dev [GitHub](https://github.com/ShinMegamiBoson/lookatmyquant) [HN](https://news.ycombinator.com/item?id=50591853)
> [zh] **LookAtMyQuant：5.4 GB 跑 Inkling-2-Mini**：一个量化编译器，先测量模型每一块参数被压缩后对输出的伤害，再为每块挑选编码，在给定体积内把损失降到最低（MIT 许可）。它把 Thinking Machines 的 Inkling-2-Mini（物理参数 26.4B、激活 5.4B 的循环 MoE）从 18.89 GB 文本权重压成 5.38、8.87、11.18、12.76 GB 四个 Apple Silicon MLX 版本，其中 12.8 GB 版 GSM8K（193/200）和 HumanEval（152/164）与原模型完全一致。同一套方法把 Qwen3.8-27B 压到 7.2 GB（每权重 2.1 bit），540 道数学题成绩与原版持平。HN 378 分。
3. **Pandex**: “Europe’s law, in one API”—legislation and highest-court decisions of the EU and seven European countries, pulled straight from the publishing institutions, with 2.8M official documents and 37M citations linked to their text. One REST API and one MCP server cover every jurisdiction, returning Markdown or JSON, with keyword, semantic or hybrid search across languages (ask in English, get the French ruling and the passage that answers it), point-in-time law, a full citation graph and exact lookup; it lists Claude, Cursor, GitHub Copilot, Windsurf, Zed and Gemini as supported clients. https://www.pandex.io [HN](https://news.ycombinator.com/item?id=50593481)
> [zh] **Pandex**：「一个 API 覆盖欧洲法律」——直接从发布机构抓取欧盟及七个欧洲国家的立法和最高法院判决，共 280 万份官方文件、3700 万条引用关联到原文。一个 REST API 和一个 MCP 服务器覆盖全部司法辖区，返回 Markdown 或 JSON，支持跨语言的关键词、语义或混合检索（用英文提问，找到对应的法国判决和回答问题的段落）、按时间点查询法律、完整引用图谱和精确查找；列出的可用客户端包括 Claude、Cursor、GitHub Copilot、Windsurf、Zed 和 Gemini。
4. **OpenSRE**: an open-source CI/CD reliability agent (public alpha) that reads a failed run, traces the cause and pushes a fix to the PR branch for review, self-hosted with your own models. On a CI failure, alert or question it pulls failing checks and logs, recent commits and deploys plus correlated logs, metrics and traces, optionally masks sensitive identifiers before external LLM calls, tests hypotheses in a tool-calling loop to separate CI-caused from code-caused failures, and posts an evidence-linked summary to Slack, PagerDuty or Telegram; it connects to 60+ tools, including Anthropic, OpenAI Codex, Ollama, Gemini and OpenRouter. About 450 GitHub stars today. https://opensre.com [GitHub](https://github.com/Tracer-Cloud/opensre)
> [zh] **OpenSRE**：开源的 CI/CD 可靠性 Agent（公开 Alpha），读取失败的流水线、追查原因并把修复推到 PR 分支等人审，可自托管、用自己的模型。CI 失败、收到告警或被提问时，它拉取失败的检查与日志、近期提交和部署以及相关的日志、指标和链路追踪，可选在调用外部 LLM 前脱敏，在工具调用循环里验证假设、区分是 CI 本身还是代码导致的失败，再把附证据的结论发到 Slack、PagerDuty 或 Telegram；可接 60 多种工具，包括 Anthropic、OpenAI Codex、Ollama、Gemini 和 OpenRouter。今日 GitHub 新增约 450 星。

1. **Upload2Shell (CVE-2026-125396): a Ghostscript font-loader use-after-free reached through ordinary image uploads**: pwn.ai’s Paulos Yibelo shows that almost every upload feature they tested could be tricked into handing a trusted-extension file to Ghostscript—a PHP preview via Imagick, or Pillow loading pixels from EPS content named `.png`. The Type 1 font loader bug gives a write-what-where primitive that flips the state enforcing `-dSAFER` and runs commands as the rendering process. The wider audit reached production services at Dropbox and redacted vendors, each paying its maximum bounty; WordPress shipped a mitigation on Aug 12 and Ghostscript 10.08.0 fixed it on Sep 8, with a Debian 13 network CUPS chain as the first full PoC case study. https://pwn.ai/upload2shell/research.html [HN](https://news.ycombinator.com/item?id=50592097)
> [zh] **Upload2Shell（CVE-2026-125396）：普通图片上传就能触达 Ghostscript 字体加载器的释放后使用漏洞**：pwn.ai 的 Paulos Yibelo 指出，他们测试的几乎所有上传功能都能被诱导把带可信扩展名的文件交给 Ghostscript——比如 PHP 经 Imagick 生成预览，或 Pillow 加载伪装成 `.png` 的 EPS 内容。Type 1 字体加载器的漏洞提供任意地址写原语，可改掉执行 `-dSAFER` 的状态并以渲染进程身份执行命令。更大范围的审计打到了 Dropbox 等（未具名）厂商的生产服务，均拿到最高赏金；WordPress 8 月 12 日发布缓解措施，Ghostscript 10.08.0 于 9 月 8 日修复，首个完整 PoC 案例是 Debian 13 网络 CUPS 利用链。
