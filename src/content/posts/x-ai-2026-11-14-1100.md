## 有趣用法和干货
1. **Anthropic: building always-on agents from five primitives**: the guide by William Hu argues an always-on agent is mostly asleep and wakes for short runs, built from an event inbox (a durable table plus a fast-acking handler and a single worker per inbox that batches pending events), timers (follow-ups and schedules fired by a scheduler into the inbox), memory (only what can't be looked up again: user instructions, user notes, past messages, per-task progress files, loaded via a lean index), permissions (a credential-injecting proxy, auto-mode classifiers, and deferred tool calls that end the run until the user's answer arrives as a new event) and an optional outbox to pace messages. Its advice: start the agent quiet and let it earn attention. dotey and shao__meng both published Chinese walk-throughs. https://claude.com/resources/articles/building-always-on-agents | https://x.com/dotey/status/2121406975279792268 | https://x.com/shao__meng/status/2121427594260398327
> [zh] **Anthropic：用五个部件搭一个「始终在线」的 Agent**：William Hu 写的这份指南认为，所谓始终在线只是体验，Agent 大部分时间在睡觉、被事件唤醒跑一小段。五个部件是：事件收件箱（持久化的事件表，处理器快速确认，每个收件箱只有一个 worker，并把积压事件合并成一次运行）；计时器（跟进和定期任务，由调度器到点写进收件箱）；记忆（只存查不回来的东西：用户指令、用户笔记、已说过的话、每个任务的进度文件，开头只加载索引）；权限（在 Agent 环境外用代理注入凭据、auto mode 分类器拦高风险操作、延迟工具调用：先结束本次运行，用户的答复作为新事件回到收件箱）；以及可选的发件箱，用来控制发消息的节奏。建议是先让 Agent 安静一点，再慢慢赢得用户的注意力。宝玉和 shao__meng 都发了中文解读。
2. **Anthropic 公开安全评测方法：同一模型在 API 和 claude.ai 上分数最多差 34 个百分点**：shao__meng 解读 Anthropic 工程博客的 10 条建议：自杀与自伤对话不再看拒绝率，改看专家定标准的「恰当回应率」，多轮里有一轮不合格整段就算失败；单轮无害回应率已在 94%–98% 见顶，多轮置信区间可超过 ±10 个百分点，所以复杂多轮评测至少 100 例、单轮至少 1000 例；报告要写清模型版本、提示词和评分器，不同评分器的分数不能直接比；推荐 AISI 的 Inspect 和基于它的 Petri，评测在断网沙箱里跑。https://x.com/shao__meng/status/2121421243970990534 | https://www.anthropic.com/research/building-strong-safety-evaluations
> [en] **Anthropic shares how it runs safety evals: the same model can differ by up to 34 points between the API and claude.ai**: shao__meng walks through the engineering blog's 10 recommendations: for suicide and self-harm, stop measuring refusal rate and score an expert-defined "appropriate response rate", failing a whole multi-turn conversation if any turn fails; single-turn harmlessness has plateaued at 94%–98% while multi-turn confidence intervals can exceed ±10 points, so use at least 100 cases for complex multi-turn evals and 1,000 for single-turn; report model version, prompt and grader, and never compare scores across graders; use AISI's Inspect and Petri built on it, and run evals in offline sandboxes.
3. **Lydia Hallie: a Stop hook that should make Claude retry has to exit with code 2**: you can use a Stop hook to send Claude back when a check fails, but only exit code 2 does that, feeding the hook's stderr back for the retry; exit 1 is non-blocking, so Claude simply finishes even though the check failed. https://x.com/lydiahallie/status/2121313048820617645
> [zh] **Lydia Hallie：想让 Claude 在检查失败时重试，Stop hook 必须以退出码 2 结束**：可以用 Stop hook 在检查不通过时让 Claude 再试一次，但只有退出码 2 会把 hook 的 stderr 交回给 Claude 重来；退出码 1 不阻塞，检查失败了 Claude 也会直接收工。
