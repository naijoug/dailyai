## 科技新闻
1. **Critical RCE in Apache HTTP Server's HTTP/2 module, found independently by Anthropic and Google (HN ~250 pts)**: CVE-2026-119618 is a race condition in `assign_headers()` in mod_http2 that lets a remote, unauthenticated attacker corrupt heap memory and run code as the web server. It affects 2.4.55 through 2.4.70 (fixed in 2.4.71); if you can't patch, restricting `Protocols` to http/1.1 removes the attack path. Wiz says 64% of cloud environments have vulnerable resources and 51% have publicly exposed instances; no public exploit yet. HN commenters noted copy errors in the advisory (a mismatched CVE number, GitHub listed as the "vendor" of mod_h2), and one called it "another critical bug discovered by AI". https://www.wiz.io/blog/cve-2026-119618-rce-apache-http-server-vulnerability | https://news.ycombinator.com/item?id=50462177
> [zh] **Apache HTTP Server 的 HTTP/2 模块曝高危 RCE，由 Anthropic 和谷歌分别独立发现（HN 约 250 分）**：CVE-2026-119618 是 mod_http2 里 `assign_headers()` 的竞态条件，远程未认证攻击者可借此破坏堆内存，以 Web 服务器权限执行代码。影响 2.4.55 至 2.4.70（2.4.71 已修复）；暂时没法升级的，把 `Protocols` 限制为 http/1.1 就能堵住攻击路径。Wiz 称 64% 的云环境有受影响资源，51% 有公网暴露实例；目前还没有公开利用代码。HN 评论指出通告文字有错（CVE 编号前后不一致、把 GitHub 写成 mod_h2 的「厂商」），也有人感叹「又一个 AI 发现的严重漏洞」。
