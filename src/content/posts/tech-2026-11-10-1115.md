## 新产品
1. **Exact (Expo): write an app once, run it natively on web, macOS, iOS and Linux — and let an AI agent build, run, see and test it on each**: the README ships a ready Claude Code prompt; a fresh agent built a todo app with passing tests on three platforms in about 57 minutes. HN commenters ask about Android and see it as a possible Electron alternative. https://github.com/expo/exact | https://news.ycombinator.com/item?id=50433541
> [zh] **Exact（Expo 出品）：一次编写，原生运行于 Web、macOS、iOS、Linux，并让 AI Agent 在每个平台上构建、运行、看界面和测试**：README 附现成 Claude Code 提示词，全新 Agent 约 57 分钟做出三平台测试全过的待办应用。HN 评论关心 Android 支持，也有人视其为替代 Electron 的希望。
2. **watched.earth: every satellite that passed over any place this week, with its photos (Show HN, 241 pts)**: runs SGP4 on the CelesTrak catalog in the browser in about half a second, then pulls real Sentinel-2 / Landsat / NASA imagery from those passes; geospatial users praised seeing the exact image a satellite took. https://www.watched.earth | https://news.ycombinator.com/item?id=50428907
> [zh] **watched.earth：查任意地点本周飞过的所有卫星及其拍到的照片（Show HN 241 分）**：在浏览器里用 SGP4 跑 CelesTrak 星表，约半秒出结果，再拉取对应过境的 Sentinel-2 / Landsat / NASA 真实影像；做地理空间的用户称赞能看到卫星实拍的那一张。
3. **MeowDisplay: iPhone Mirroring in reverse — use your iPhone as a Mac display (Show HN)**: open source, started as a fork of OpenDisplay and taken in a phone-first direction with work on interaction, streaming and security; commenters compare it with Sidecar and ask about latency and HDR. https://meowdisplay.app/ | https://news.ycombinator.com/item?id=50429636
> [zh] **MeowDisplay：反向的 iPhone 镜像，把 iPhone 当 Mac 显示屏（Show HN）**：开源，基于 OpenDisplay 分叉并转向手机优先，重做交互、串流和安全层；评论拿它和 Sidecar 比，关心延迟与 HDR。
4. **Someone Was Here: see who used your Mac while you were away (Show HN)**: menu-bar app that photographs whoever uses the Mac and alerts your iPhone if the face isn't yours, using Apple Vision and local Core ML face recognition with no tracking; remote alerts via a one-time $4.99 purchase or Pushover/ntfy/Telegram/webhook. Some commenters call it spyware-adjacent. https://someonewashere.app/ | https://news.ycombinator.com/item?id=50429812
> [zh] **Someone Was Here：查看离开时谁用了你的 Mac（Show HN）**：菜单栏应用，有人使用时拍照，若不是本人就推送到 iPhone；用 Apple Vision 与本地 Core ML 人脸识别，无追踪；远程提醒一次性 4.99 美元，或走 Pushover/ntfy/Telegram/webhook。也有评论认为接近监控软件。
5. **STE80 Humanizer: de-AI text by rewriting it 80% of the way to ASD-STE100 Simplified Technical English (Show HN)**: an open-source tool that pushes prose toward controlled-language rules to strip typical LLM style. https://github.com/Dodaios/ste80-humanizer | https://news.ycombinator.com/item?id=50429144
