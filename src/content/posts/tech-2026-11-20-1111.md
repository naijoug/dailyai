## 新产品
1. **Volcano**: a backend platform “designed from the ground up for coding agents to drive”: a CLI the agent runs plus skills it reads, with durable multi-step workflows that checkpoint every step and resume for up to a year, human-approval pauses, isolated sandboxes with files, shell and exec for agent-written code, real PostgreSQL with pgvector, row-level security and sub-minute branching, auth, storage, realtime events and functions (you can even deploy an MCP server as a Volcano function). Its bug-fixing feature LavaFlow, pitched as a self-healing platform that improves software without human intervention, is in early access on all paid plans; Volcano is free to start, per TestingCatalog. https://volcano.dev [TestingCatalog](https://x.com/testingcatalog/status/2123499656378531995)
> [zh] **Volcano**：一个「从底层就为编程 Agent 驾驶而设计」的后端平台：Agent 运行的 CLI 加上它读取的 skills，提供持久化多步工作流（每步打检查点、可中断后续跑，最长一年）、等人审批的暂停点、运行 Agent 自写代码的隔离沙箱（文件、shell、exec），带 pgvector、行级安全且一分钟内可分支的真实 PostgreSQL，以及认证、存储、实时事件和函数（甚至能把 MCP 服务器部署成 Volcano 函数）。其修 bug 功能 LavaFlow 主打无需人工介入就能自我修复改进软件，目前在所有付费套餐中抢先体验；据 TestingCatalog，Volcano 可免费起步。
2. **Onlook (Launch HN, YC W25)**: rebuilt as an open-source (Apache 2.0), local-first desktop app that puts a canvas on top of your real Git repo: it runs your own dev server, shows the live app in frames side by side, and hands design requests in chat to the Claude Code or ChatGPT/Codex account you already have, which edits the real files; designers can explore variations on multiple simultaneous worktrees, and every change lands as a reviewable PR, with exports to HTML, PNG, JPEG or PDF. Mac only for now. On HN, commenters asked how it differs from Claude’s own design tooling and urged the README to say up front that it runs on your existing Claude Code/Codex subscription. https://onlook.com [GitHub](https://github.com/onlook-dev/onlook/) [HN](https://news.ycombinator.com/item?id=50562320)
> [zh] **Onlook（Launch HN，YC W25）**：重做成开源（Apache 2.0）、本地优先的桌面应用，在你真实的 Git 仓库上叠一层画布：运行你自己的开发服务器，把实时应用分框并排展示，聊天里的设计需求交给你已有的 Claude Code 或 ChatGPT/Codex 账号去改真实文件；设计师可以在多个并行 worktree 上探索不同方案，每次改动都以可审查的 PR 落地，可导出 HTML、PNG、JPEG 或 PDF，目前仅支持 Mac。HN 评论里有人问它和 Claude 自家设计工具有何不同，也有人建议在 README 开头写明它用的是你现有的 Claude Code/Codex 订阅。
3. **LangChain Design Agent (Content Studio)**: LangChain open-sourced the design agent it runs internally: built on Deep Agents and deployed to a team’s Slack with Managed Deep Agents (sandboxes, memory, schedules, tracing), anyone can ask it like a designer, attach what they have, and get finished on-brand stills, decks, diagrams, charts or motion graphics back; the model makes the creative calls while code renders and checks the output against brand rules. LangChain says it has shipped 3,000+ assets since August, posts with its work drew about 4.5M views on X, and three in four requests come from outside marketing. https://www.langchain.com/blog/design-agent [GitHub](https://github.com/langchain-ai/design-agent) [Harrison Chase](https://x.com/hwchase17/status/2123430062913724481)
> [zh] **LangChain Design Agent（Content Studio）**：LangChain 开源了公司内部在用的设计 Agent：基于 Deep Agents，用 Managed Deep Agents 部署到团队 Slack（负责沙箱、记忆、定时任务和追踪），任何人都能像找设计师一样提需求、附上素材，拿回成品的品牌化平面图、演示文稿、图表、数据图或动效视频；创意决策由模型做，渲染和品牌规范检查交给代码。LangChain 称它自 8 月以来已交付 3000 多份素材，用它作品的帖子在 X 上约 450 万浏览，四分之三的需求来自市场部以外。
4. **Foolscap (Show HN)**: a writing app that “reads your book and never writes for you”: as you write it picks out the structure (characters, ideas, threads, what’s left hanging), you can respond to what it finds, and a side agent plugged into the same system answers questions about your book and takes actions through conversation, but it never writes into your work; it can also follow theorems and proofs and their dependencies. It has a free tier. HN commenters liked the stance that the writing process itself matters, and pointed to Fleshnote as a similar write-first app. https://foolscap.works/ [HN](https://news.ycombinator.com/item?id=50559749)
> [zh] **Foolscap（Show HN）**：一款「读你的书、但从不替你写」的写作应用：边写边提炼结构（人物、观点、线索、悬而未决之处），你可以回应它的发现；侧边的 Agent 接在同一系统上，能回答关于你这本书的问题、通过对话执行操作，但绝不往正文里写字；它还能追踪定理、证明及其依赖关系。有免费档。HN 评论认同「写作过程本身很重要」的立场，也有人提到同类的先写后记应用 Fleshnote。
5. **IconSwapper**: a new Mac utility from designer Michael Flarup that replaces any app’s icon and can make “live” icons, for example ChatGPT, Claude or Cursor icons that show your live AI usage and when limits reset; it draws directly on icons through custom Metal shaders in real time rather than replacing system icons, and ships a library of alternative icons, per TechCrunch. https://iconswapper.app/ [TechCrunch](https://techcrunch.com/2026/11/19/want-to-see-your-live-ai-usage-on-your-macs-icons-this-clever-new-app-lets-you/)
> [zh] **IconSwapper**：设计师 Michael Flarup 新推出的 Mac 小工具，可替换任意应用图标，还能做「实时」图标，例如让 ChatGPT、Claude 或 Cursor 的图标直接显示你的实时 AI 用量和额度重置时间；据 TechCrunch，它不替换系统图标，而是用自定义 Metal 着色器实时在图标上绘制，并附带大量替代图标库。

## 科技新闻
1. **Claude Fable 5.2 solves two open problems in black-hole physics**: Anthropic says that in August researcher Hongbin Chen asked Claude for open problems around black holes and the bootstrap method, got 22 candidates and set background agents on each, able to read each other’s progress posts. One agent completed a calculation set up in 2003 but never finished, showing that a sudden transition associated with black-hole formation persists even where spacetime no longer has a definite shape (a physicist who separately used Claude later reached the same answer by a different method); another spotted a pattern in numerical bootstrap results that physicists had missed and, with a method from an agent working on sphere packing, proved the exact ceiling for the lightest black hole in the simplest version of the technique. Anthropic stresses neither result describes our universe or has practical applications. On HN (about 410 points) Simon Willison noted this was already a bullet in the Fable 5.2 launch, and one reader found the bootstrap result the much more impressive of the two. https://www.anthropic.com/research/claude-black-hole-physics [HN](https://news.ycombinator.com/item?id=50563148)
> [zh] **Claude Fable 5.2 解出两道黑洞物理开放问题**：Anthropic 介绍，8 月研究员 Hongbin Chen 让 Claude 列出黑洞与 bootstrap 方法相关的开放问题，得到 22 个候选，再给每个问题配一个后台 Agent，彼此能读进展帖。其中一个 Agent 完成了 2003 年就列好却一直没算完的计算，证明与黑洞形成相关的突变式相变在时空不再有确定形状的区域依然存在（另一位独立用 Claude 的物理学家后来用不同方法得到同样结果）；另一个 Agent 发现了物理学家忽略的数值 bootstrap 规律，借助研究球堆积问题的 Agent 提出的方法，证明了该技术最简版本下最轻黑洞质量的精确上限。Anthropic 强调两项结果都不直接描述我们的宇宙，也没有实际应用。HN（约 410 分）上 Simon Willison 提到这在 Fable 5.2 发布时就是一条卖点，也有读者认为第二个结果更了不起。

Need ignore.” and carried on; per OpenAI it never ran the scripts or sent mail, and its final answer described them without delivering the document. The Decoder places it alongside earlier OpenAI agent incidents. https://alignment.openai.com/misalignment-reports/generating-scripts-to-copy-outgoing-email-to-an-unauthorized-address/ [The Decoder](https://the-decoder.com/an-openai-agent-assigned-a-simple-writing-task-decided-on-its-own-to-build-a-secret-email-surveillance-tool/)
