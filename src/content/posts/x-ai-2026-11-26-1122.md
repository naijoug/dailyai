2. **Anthropic moved its Messages API from Python to Rust and says each request now uses about 70% less CPU**: the engineering post says API traffic grew roughly 1,800x between early 2024 and fall 2026, Claude wrote a first version of the core request path in about a week, and the hard part was proving parity with a Python service that kept changing and answers nondeterministically. The team turned the production API into the verifier, replaying traffic against the Rust version and dispatching teams of Claude agents to find and fix each difference; the result is about 70% less CPU per request and about 20% lower median time to first token, with no downtime and no feature freeze. The post drew 9k likes and 4k bookmarks. https://x.com/AnthropicAI/status/2125627317263466739 https://www.anthropic.com/research/migrating-api-to-rust
> [zh] **Anthropic 把 Messages API 从 Python 迁到 Rust，称每个请求约少用 70% CPU**：工程博客称，2024 年初到 2026 年秋 API 流量涨了约 1800 倍，Claude 用约一周写出核心请求路径的第一版，难点是证明与一个持续变化、回答还不确定的 Python 服务保持一致。团队把线上 API 本身变成验证器，把流量回放到 Rust 版本，并派出多组 Claude Agent 去找出并修复每一处差异；结果是每请求约少用 70% CPU、首字延迟中位数约降 20%，全程不停服、不冻结功能开发。该帖获得约 9 千赞、4 千收藏。

3. **A Johns Hopkins and Together AI paper: start agents at low reasoning effort and escalate only after a verified failure**: across 8 models at every effort level on math, science, terminal and coding benchmarks, higher effort often failed tasks that lower effort had solved; on tasks every level solved, top effort cost up to 42x the lowest. Starting low and retrying at top effort after a verified failure matched or beat fixed top effort for every model, with a median 41.5% lower GPQA cost, so if you have a reliable pass/fail check, default to low effort and escalate on failure. The paper is titled “What Effort Level Should I Choose? On the Economics of Reasoning Effort in LLM Agents”. https://x.com/rohanpaul_ai/status/2125762008876519662 https://x.com/rohanpaul_ai/status/2125762012290658576
> [zh] **约翰斯·霍普金斯与 Together AI 的论文：Agent 先用低推理强度，验证失败后再升级**：在 8 个模型、数学/科学/终端/编程基准的每个强度档位上测试，高强度常常搞砸低强度已能解决的任务；在所有档位都能解决的任务上，最高档成本最多是最低档的 42 倍。先用低档、验证失败后再用最高档重试，对每个模型都不差于甚至优于固定最高档，GPQA 成本中位数低 41.5%，所以只要有可靠的通过/失败检查，就默认用低强度、失败再升级。论文题为《What Effort Level Should I Choose? On the Economics of Reasoning Effort in LLM Agents》。
