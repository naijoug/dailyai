## 有趣用法和干货
1. **Vox: stop Claude Code’s Explore/Plan subagents from burning your Opus quota**: built-ins run on your main model by default; `CLAUDE_CODE_SUBAGENT_MODEL=haiku CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 claude --model sonnet --advisor opus` gives Sonnet writing, Haiku searching, Opus reviewing. Without FORCE=1 Explore and Plan are untouched (FORCE also overrides models in your own agent files); `--subagents haiku` doesn’t exist; type /tasks to see each subagent’s model. https://x.com/Voxyz_ai/status/2117718457621926236
> [zh] **Vox：别让 Claude Code 内置的 Explore/Plan 子 Agent 烧掉 Opus 额度**：它们默认跑主模型；`CLAUDE_CODE_SUBAGENT_MODEL=haiku CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1 claude --model sonnet --advisor opus` 让 Sonnet 写、Haiku 搜、Opus 审。不加 FORCE=1 不会影响 Explore 和 Plan（FORCE 也会覆盖你自定义 agent 文件里的模型）；`--subagents haiku` 这个参数不存在；运行中输入 /tasks 可看每个子 Agent 用的模型。
2. **@Khazix0918：开源 Agent-Autoloop，一年 Agent 自动化系统重写为「内核 + 插件」**：借鉴 Pi 极简内核和 DeepSeek Harness「一切皆插件」，除中台内核外，事件、通知通道、Agent 执行乃至 CI 流水线都拆成插件；流程是定时任务 / GitHub Issue / 业务报错等先变成统一事件，再按 rules.json 派给对应 Agent、目录和 Skill。https://x.com/Khazix0918/status/2117776745688646139 | https://github.com/KKKKhazix/agent-autoloop
> [en] **@Khazix0918 open-sources Agent-Autoloop, rewriting his year-long agent automation system as kernel + plugins**: inspired by Pi’s minimal kernel and DeepSeek Harness’s “everything is a plugin,” everything except the core hub—events, notification channels, agent execution, even the CI pipeline—is a plugin; cron jobs, GitHub issues or app errors become uniform events routed via rules.json to the right agent, directory and Skill.
3. **Philipp Schmid: a Gemini API CLI skill for agents**: gives your agent a CLI to call Gemini models for images, TTS, video and files without one-off scripts; install with `npx skills add google-gemini/gemini-skills --skill gemini-api-cli`. https://x.com/_philschmid/status/2117674864907608543
> [zh] **Philipp Schmid：给 Agent 用的 Gemini API CLI skill**：让 Agent 通过 CLI 调用 Gemini 生成图片、TTS、视频、处理文件，不用再写一次性脚本；安装：`npx skills add google-gemini/gemini-skills --skill gemini-api-cli`。
4. **Elvis Saravia: optimize agent harnesses for quality first, apply cost preference only at the end**: Microsoft’s ParetoSaddler runs parent and candidate harnesses several times and uses a Bayesian bootstrap to judge credible progress on quality or cost; GAIA2 quality 56.22% → 62.89% with cost per task $0.78 → $0.45, ClawMark 70.86% → 81.35% and $1.17 → $1.01. Add repeated runs and a cost axis before pruning candidates. https://x.com/omarsar0/status/2117738094069944347 | https://arxiv.org/abs/2611.02079
> [zh] **Elvis Saravia：优化 Agent harness 时先追质量，成本偏好放到最后再用**：微软 ParetoSaddler 让父 / 候选 harness 各跑多次，用贝叶斯 bootstrap 判断质量或成本是否有可信进步；GAIA2 质量 56.22% → 62.89%、单任务成本 $0.78 → $0.45，ClawMark 70.86% → 81.35%、$1.17 → $1.01。淘汰候选前先加重复运行和成本维度。
