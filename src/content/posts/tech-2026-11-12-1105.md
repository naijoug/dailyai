## 新产品
1. **AWS Emulator**: a free local emulator of AWS APIs for building and testing without an AWS account (server mode for the CLI and any SDK, or embedded in Rust tests), released under CC0 — and, per AWS, 100% written by autonomous agents with no human writing or reviewing the code. Senior Principal Engineer Matthew Goldberg describes three agent teams: one builds tens of thousands of fidelity tests from the AWS API models and verifies each against real AWS, one replays them to file issues, and one fixes a single issue at a time behind a merge gate (compiles, coding-standards and security review, no fidelity regression); it started as a weekend Kiro experiment. AWS says not to use it for testing IAM or other security controls. On HN (~710 pts) people called it a free LocalStack replacement, while skeptics asked whether it will be maintained. https://docs.aws.amazon.com/emulator/latest/userguide/what-is-service.html | https://www.aboutamazon.com/news/aws/how-autonomous-ai-agents-built-aws-emulator | https://github.com/aws/aws-emulator | https://news.ycombinator.com/item?id=50456631
> [zh] **AWS Emulator**：免费的本地 AWS API 模拟器，不用 AWS 账号就能开发测试（服务器模式支持 CLI 和任意 SDK，也能嵌进 Rust 测试），以 CC0 发布；AWS 称代码 100% 由自主 Agent 编写，团队没写也没审过一行。高级首席工程师 Matthew Goldberg 介绍了三组 Agent：一组根据 AWS API 模型写出数万个保真度测试、逐个在真实 AWS 上验证；一组回放测试、提交问题；一组一次只修一个问题，并要过合并关卡（能编译、编码规范和安全审查、保真度不退步）。项目起点是用 Kiro 做的一个周末实验。AWS 提醒不要用它测试 IAM 等安全控制。HN（约 710 分）上有人说可以免费替代 LocalStack，也有人怀疑它能否长期维护。
2. **Atuin Threads**: Atuin 18.24+ syncs and searches your coding-agent sessions across machines like shell history; run `atuin resume` to pick a session up anywhere or fork it into a different harness, such as starting in Claude Code on a dev server and finishing in Codex on a laptop. It currently supports Claude Code, Codex, Pi, Omp and OpenCode; sync is end-to-end encrypted (hosted, self-hosted or local only) and capture is opt-in. An `atuin mcp` server lets agents search earlier sessions themselves, and team session sharing is in the works. HN ~190 pts. https://atuin.sh | https://blog.atuin.sh/threads-agent-sessions/ | https://news.ycombinator.com/item?id=50453637
> [zh] **Atuin Threads**：Atuin 18.24 起，像同步 shell 历史一样跨机器同步、搜索你的编程 Agent 会话；运行 `atuin resume` 可以在任意机器上接着做，或把会话分叉到另一个 harness，比如在开发服务器上用 Claude Code 开头，回到笔记本上用 Codex 收尾。目前支持 Claude Code、Codex、Pi、Omp 和 OpenCode；同步端到端加密（可用官方服务器、自建或只存本地），采集会话需手动开启。自带 `atuin mcp`，Agent 能自己检索以前的会话；团队共享会话功能正在开发。HN 约 190 分。
3. **Yogurt**: a free, MIT-licensed, open-source alternative to Granola: a desktop app that runs in the background (no bot joins your call) and uses on-device models to transcribe, summarize and chat with your meetings, so transcripts and recordings never leave your computer. It has calendar integration and a local MCP server for sharing notes with Claude, ChatGPT and others; HN commenters (~180 pts) compared it with Muesli and OpenOats and asked about speaker diarization. https://yogurt.so | https://github.com/FrigadeHQ/yogurt | https://news.ycombinator.com/item?id=50454625
> [zh] **Yogurt**：免费、MIT 协议开源的 Granola 替代品。桌面 App 在后台运行（不派机器人进会），用本地模型给会议转写、总结和问答，转写稿和录音都不离开电脑。支持日历集成，自带本地 MCP 服务器，可以把笔记交给 Claude、ChatGPT 等。HN（约 180 分）评论拿它和 Muesli、OpenOats 比，也有人问能不能区分说话人。
4. **Klad**: a source-available paint app written in Rust that a coding agent can drive entirely through a CLI: brush engine, frame-by-frame animation with bones/IK, vectors, text layers, layer effects and infinite undo, all also available in a normal UI. The author built it for game art, so an agent can draft with real brush strokes and a human can then edit every stroke or layer, instead of re-rolling an image model. https://klad.studio | https://github.com/klad-app/klad | https://news.ycombinator.com/item?id=50454951
> [zh] **Klad**：用 Rust 写的源码公开绘画软件，编程 Agent 能通过命令行完全操控：笔刷引擎、带骨骼/IK 的逐帧动画、矢量、文字图层、图层效果、无限撤销，所有功能也都有正常界面。作者做它是为了游戏美术：让 Agent 用真实笔触画初稿，人再逐笔、逐图层修改，而不是一遍遍重抽图像模型。
5. **Tabletop (Google Labs)**: an experimental shared space for groups. Add links, files and ideas, then prompt @tabletop or pick a template to generate interactive "tabs" such as trip itineraries, dinner polls, expense splitters and tournament brackets that everyone uses at once, like a Google Doc; tabs can be reworked by prompt or by editing the code. US-only (18+) via waitlist; Google hasn't said which model powers it. https://tabletop.google | https://blog.google/innovation-and-ai/models-and-research/google-labs/tabletop/ | https://www.theverge.com/tech/1031526/google-tabletop-ai-experiment-waitlist-availability
> [zh] **Tabletop（Google Labs）**：给小团体用的实验性共享空间。放进链接、文件和想法，再 @tabletop 提需求或选模板，就能生成行程表、聚餐投票、AA 分账、赛事对阵表等交互式「标签页」，大家像用 Google 文档一样同时使用；标签页可以继续用提示词改，也能直接改代码。目前仅限美国 18 岁以上用户排队申请，谷歌没说用的是哪个模型。

3. **"My AI agents (re)discovered a Maya site in 72 hours" (HN ~940 pts)**: Pietro Miotti had 48 agents go through about 1,200 km² of public NASA lidar rendered as images, following a guide to spot pyramids, platforms and plazas, with no special classifier. > [en] **IT Home: Google ships A2UI 1.0, its generative UI protocol**: A2UI lets an agent describe the interface to show instead of replying in text, and each app draws it with its own native components. 1.0 is the first stable release, adding two-way function calling, accessibility and extended metadata; open-source renderers cover the web (React, Angular, Lit), Flutter, SwiftUI and Jetpack Compose, with agent SDKs in Python, TypeScript and Dart. The web and Flutter renderers also run inside MCP apps, so A2UI screens can appear in assistants that support MCP apps, such as Claude and Gemini; Atlassian, Bloomberg and ByteDance are already building with it.
