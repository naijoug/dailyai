## AI 热点
1. **Z.ai launches GLM-5.4, its first Loop Transformer flagship**: the official blog says the 750B-parameter model loops 28 layers of the GLM-5 base for two iterations, reaching “intelligence levels comparable to 2T–3T parameter models,” and marks the start of “Generalized Coding,” with demos of writing code to generate video, build a game, do FreeCAD work on a 6-axis arm, and write GLSL shaders. Instead of pretraining a looped model from scratch, they continued training a pretrained base; three changes keep deployment cost in check at this scale (per-token gates so hidden-state norms don’t blow up, a hybrid KV cache that only adds a sliding window on the second pass, and reused sparse-attention indices). On a 30B iso-parameter ablation with about 10% more training compute, the looped version improved math and long-context tasks and cut average output length 10–14%. The blog says the model still gets stuck in long “marathon thinking” loops, which nonetheless improve accuracy; off-peak inference reaches 200 tokens/s and 70–80 tokens/s at peak. API access comes after a safety review, and open weights are planned after safety hardening; ZCode and Z.ai Chat are already up, with a “next, significantly larger model” said to be coming soon. The announcement post from @Zai_org had 3.7k likes. https://z.ai/blog/glm-5.4 https://x.com/Zai_org/status/2124811995912286352 https://x.com/testingcatalog/status/2124825630852194638
> [zh] **智谱发布 GLM-5.4，首个 Loop Transformer 旗舰模型**：官方博客称这是 7500 亿参数模型，把 GLM-5 基座的 28 层循环跑两轮，智能水平「可与 2–3 万亿参数模型相当」，并作为「泛 Coding」的起点，演示了用代码生成视频、做完整游戏、在 FreeCAD 里建六轴机械臂，以及写 GLSL 着色器。他们没有从零预训练循环模型，而是在已有基座上继续训练；为把这个规模的部署成本压住，做了三处改动（按 token 的门控以免隐状态范数爆炸、第二次循环只追加滑动窗口的混合 KV 缓存、复用稀疏注意力索引）。在 300 亿参数、训练算力大约多 10% 的对照实验里，循环版在数学和长上下文上有提升，平均输出长度缩短 10–14%。博客也承认模型仍会陷入过长的「马拉松式思考」，不过这种反思确实提高了准确率；闲时推理可达每秒 200 token，高峰约 70–80。API 要等安全评估后再开放，权重计划在安全加固后开源；ZCode 和 Z.ai Chat 已经可用，并称「下一款明显更大的模型」很快会来。@Zai_org 的发布帖有 3.7k 赞。
2. **TestingCatalog: Gemini 4 Neon with the Antigravity CLI is #1 on the Artificial Analysis Coding Agent Index**: the Nov 23 daily brief also repeats that Antigravity Gemini quotas were reset and that caching now stretches each quota about 22% further (already reported earlier). https://x.com/testingcatalog/status/2124827938054918206
> [zh] **TestingCatalog：Gemini 4 Neon 搭配 Antigravity CLI，登上 Artificial Analysis 编程 Agent 指数第一**：11 月 23 日简报还再次提到，Antigravity 的 Gemini 额度已重置，缓存大约能让每份额度多用 22%（这两点此前已报道过）。
3. **Yann LeCun: post-training is so expensive because RL is “so damn sample inefficient”**: replying to a thread, he argued that this is why RL can only play a minor role “in the real world,” and that much of what is called post-training “is not really RL anyway.” 346 likes. https://x.com/ylecun/status/2124716000289464562
> [zh] **Yann LeCun：后训练之所以这么贵，是因为强化学习「样本效率实在太差」**：他在回复里说，正因为如此，强化学习「在现实世界里」只能起次要作用，而且很多被称为后训练的东西「其实也算不上强化学习」。346 赞。

## 有趣用法和干货
1. **Anthropic opened a free Claude Academy course, “Introduction to evals”**: Shao Meng notes the roughly one-hour class covers how to pick a model, how to build an offline eval set, whether a few dozen examples are enough, and how to fix things once a prompt is in production; the syllabus lists four lessons plus a quiz, aimed at people who already have prompts but no scored evals. The official pages say it is for single-call Messages API prompts, not agents or latency measurement, and walk through accuracy thresholds, cost per completed task, code graders, LLM-judge rubrics, CI smoke tests, Batch API runs and nightly drift checks. https://x.com/shao__meng/status/2124797332051128581 https://academy.claude.com/courses/introduction-to-evals
> [zh] **Anthropic 在 Claude Academy 开了一门免费课「Introduction to evals」**：邵萌介绍，这门大约一小时的课讲怎么选模型、怎么建离线评测集、几十条例子够不够，以及提示词上线后怎么修补；目录是四节课加测验，面向已经有提示词、但还没有带评分的评测的人。官方页面写明它针对单次调用的 Messages API 提示词，不覆盖 Agent 或延迟测量，并讲解准确率阈值、每个完成任务的成本、代码评分器、LLM 评审量表、CI 冒烟测试、Batch API 以及每晚的漂移检查。
2. **Phil Schmid’s defaults for Gemini 4 Neon thinking effort**: Medium for quick back-and-forth when he is in the loop, High as the daily driver for coding and agents, and xHigh for architecture, debugging and deep reasoning. His advice: start on High; save xHigh for evaluation, debugging, testing and long-running tasks. https://x.com/_philschmid/status/2124840350472622124
> [zh] **Phil Schmid 对 Gemini 4 Neon 思考力度的默认用法**：自己在回路里快速来回用 Medium，日常写代码和跑 Agent 用 High，做架构、排查和深度推理用 xHigh。他的建议是：先从 High 起步，把 xHigh 留给评测、调试、测试和长任务。
3. **Harness Memory in HarnessRouter: an open-source memory layer that stays with the user across agent harnesses**: Avi Chawla says every harness currently keeps its own memory, so what Claude Code learns is gone when you switch to Codex; the project stores memory on the user side instead. The GitHub repo describes engines such as Mem0, Graphiti, Hindsight and ReMe that can be selected per agent, recalled at the start of a turn and updated after tasks. 104 likes, 125 bookmarks. https://x.com/_avichawla/status/2124758790910460337 https://github.com/HarnessRouter/harnessrouter
> [zh] **HarnessRouter 里的 Harness Memory：一层跟着用户走、可在不同 Agent 外壳之间共用的开源记忆**：Avi Chawla 说，现在每套 Harness 都自己存记忆，Claude Code 学到的东西一换到 Codex 就没了；这个项目改把记忆放在用户这边。GitHub 仓库介绍了可按 Agent 选择的 Mem0、Graphiti、Hindsight、ReMe 等引擎，在每轮开始时召回、任务结束后更新。104 赞、125 收藏。
