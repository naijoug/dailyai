2. **Anthropic: fold unnecessary subagents into the main agent loop; one agent + skills often beats multi-agent**: Applied AI's Oct 22 guide (went viral overnight) says enterprise setups that give every team its own subagent + orchestrator copy the org chart and pay for context loss, Frankenprompts, and latency — one customer ran ~2x faster after collapsing to a single loop. Rules of thumb: Skills teach how; Tools/MCP do things; Subagents only for parallel work, isolated context, or when one agent can't pick tools. Progressive disclosure loads skills/tools on demand; Claude Code's system prompt for newer models was cut 80%+. Migration kit: turn subagent prompts into skills, APIs into tools, keep end-to-end evals. https://claude.com/resources/articles/building-agents-when-to-fold-subagents-into-your-main-agent-loop | https://x.com/cherry_mx_reds/status/2113969070118666670 | https://x.com/shao__meng/status/2114164780986679331
> [zh] **Anthropic：把多余子 Agent 折进主循环；单 Agent + Skills 常胜过多 Agent**：Applied AI 10 月 22 日指南（夜间刷屏）说，给每个团队各挂一个子 Agent 再加编排器，等于把组织架构抄进 Agent，付出上下文损耗、Frankenprompt 和延迟——有客户换成单循环后大约快 2 倍。口诀：Skills 教怎么做；Tools/MCP 去执行；Subagent 只留给并行、隔离上下文、或单 Agent 选不好工具时。渐进披露按需加载；面向新模型的 Claude Code system prompt 砍掉 80%+。迁移：子 Agent 提示词变 skill、API 变工具，并保住端到端评测。
3. **Cloudflare's security-audit skill tops GitHub Trending (~44k stars)**: MIT-licensed `cloudflare/security-audit-skill` is the single-repo seed of Cloudflare's vulnerability discovery harness. Six phases: recon → coverage-led hunting → candidate validation → structured findings → independent record verification → target-neutral report. Iron rule: the agent that checks a bug is never the one that found it; unconfirmed stays `needs_validation`. Install: `npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit`, then ask your coding agent to "security audit this codebase." Needs tool use + parallel sub-agents and a sandboxed run for execution checks. https://github.com/cloudflare/security-audit-skill | https://x.com/chasen_liao/status/2114150642986164330
> [zh] **Cloudflare 安全审计 skill 登顶 GitHub 趋势（约 4.4 万星）**：MIT 开源的 `cloudflare/security-audit-skill` 是 Cloudflare 内部挖洞 harness 的单仓起点。六阶段：侦察 → 覆盖率驱动狩猎 → 候选验证 → 结构化发现 → 独立记录核验 → 中性报告。铁律：验洞的 Agent 绝不是找洞的那个；未确认的只标 `needs_validation`。安装：`npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit`，再让编程 Agent「security audit this codebase」。需要支持工具与并行子 Agent，执行验证还要沙箱。

## 有趣用法和干货
1. **Harrison Chase: five components of a company harness**: LangChain's internal GTM / OpenSWE / Content Studio agents share the same recipe — (1) live where people already work (Slack, with breakout threads so agents don't pollute human chat); (2) identity: on-behalf-of vs fixed service credentials, with tools gated by DM vs channel; (3) global + per-user memory; (4) code execution in a sandbox with a secret proxy for auth'd services; (5) a large share of runs are scheduled/event-triggered ambient agents, not just @mentions. Built on Managed Deep Agents over the open-source Deep Agents harness. https://x.com/hwchase17/status/2114041443836903662
> [zh] **Harrison Chase：公司级 harness 的五个组件**：LangChain 内部的 GTM / OpenSWE / Content Studio Agent 共用同一套配方——(1) 住在人已经在干活的地方（Slack，可 breakout 到独立线程以免污染人类对话）；(2) 身份：代表用户 vs 固定服务账号，工具按私信/频道门禁；(3) 全局 + 按用户记忆；(4) 沙箱里跑代码，经 secret proxy 安全连需鉴权服务；(5) 大量运行是定时/事件触发的 ambient agent，不只靠 @。底座是 Managed Deep Agents（开源 Deep Agents harness 之上）。
