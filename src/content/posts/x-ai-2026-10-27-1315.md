## AI 热点
1. **宝玉推荐 Manus《用 Manus 改造 Manus》：AI Native 组织一手实践**：联创张涛写团队怎么吃自己的狗粮——研发用 Manus-mono 统一入口+给 AI 看的说明书，一人可写完前后端和移动端（7 人扛 4 个 App）；约一半产品经理能独立把需求做到上线，视频成新 PRD；市场有「数字同事」接任务、主动提醒、还能给系统提需求。9 月人均 AI 开销超 1 万美元，称买的是时间和注意力；人从亲手做到定规则、看证据、做决定。https://x.com/dotey/status/2114929079975563269 | https://mp.weixin.qq.com/s/I_hNNAf7LFBf5nJ0rEJHig
> [en] **Baoyu recommends Manus’s “Remaking Manus with Manus”: first-hand AI-native org practices**: co-founder Zhang Tao describes dogfooding—eng builds Manus-mono as a unified entry with AI-readable docs so one person can finish web/backend/mobile (7 people run 4 apps); about half of PMs can ship end-to-end, with video as the new PRD; marketing has a “digital colleague” that takes tasks, nudges, and even files feature requests. Sept AI spend topped $10k per person for time and attention; humans move from doing to setting rules, checking evidence, and deciding.
2. **MiniMax 开源自托管 OpenAI Agents API「OpenAgentCore」**：一套 Core、多种 Harness；官方 OpenAI SDK 只改 `OPENAI_BASE_URL`，Session 里可选 Codex / Claude Code / MiniMax Code，模型与沙箱按协议可换。算力可休眠、工作区可留（microsandbox / E2B / Docker / 本机）；Sandbox、文件系统、Harness、模型提供商都走既定协议。作者 saladday 称目标是对外稳定 API、对内随时换 frontier 组件。https://x.com/shao__meng/status/2114919123281117195 | https://github.com/MiniMax-AI/OpenAgentCore
> [en] **MiniMax open-sources self-hosted OpenAI Agents API “OpenAgentCore”**: one Core, many harnesses; point the official OpenAI SDK at your `OPENAI_BASE_URL`, pick Codex / Claude Code / MiniMax Code per session, and swap models/sandboxes via protocol. Compute can sleep while workspaces persist (microsandbox / E2B / Docker / local); sandbox, FS, harness, and model providers are all pluggable. Author saladday says the goal is a stable external API with swappable frontier internals.
3. **铁锤人：消费级 4070 Ti SUPER 本地跑通 π0.5 具身仿真**：没买机械臂，厨房在 LIBERO 仿真里；Ubuntu 跑 APXInf 推理、Mac 跑仿真客户端。卡不在官方适配表，靠 Coding Agent 修 Ada/Blackwell 编译引用问题后改 INT8，开炉放摩卡壶任务成功（223 步、调模型 45 次，服务端推理中位约 32 ms）。项目还带面向 Agent 的新模型移植工作流。https://x.com/lxfater/status/2114926643173327086 | https://github.com/RLinf/APXinf-robo
> [en] **Hammer: ran π0.5 embodied sim locally on a consumer 4070 Ti SUPER**: no real robot—kitchen in LIBERO; Ubuntu hosts APXInf inference, Mac runs the sim client. The GPU isn’t on the official support list; after a coding agent fixed an Ada/Blackwell build reference and switching to INT8, the stove+moka-pot task succeeded (223 steps, 45 model calls, ~32 ms median server inference). The project also ships an agent-oriented new-model porting workflow.

> [en] **Uncle Bob open-sources ub-mode: three-stage Clean Code discipline for coding agents**: the Clean Code author packs the habits into Skills—(1) First Make it Work (lazy protocol, shape data first, failing tests first); (2) Then Make it Right (crapper/dryer/mutator gates, CRAP<10, kill duplication and mutants); (3) Practice (logs, small context, small ordered commits). Principles from humans, gates made machine-checkable.
