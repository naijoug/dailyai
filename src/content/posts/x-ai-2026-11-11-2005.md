## AI 热点
1. **Google DeepMind's AlphaProof Code formally verifies Signal down to machine code**: researchers wrote the security specs with a mix of models (every spec human-reviewed), then Gemini Carbon prover agents generated about 6.5 million lines of Lean proof for libsignal's PQXDH handshake and Triple Ratchet compiled to AArch64, proving forward secrecy, authentication, post-compromise security and handshake secrecy. The proofs rest on about 26,000 lines of trusted specs and machine-code semantics; agents flagged only about 1% for human review, and the whole job took four weeks. DeepMind calls it the first time the implementation of a widely deployed protocol has been formally verified by any method. When two old, fixed bugs were reintroduced, the system proved those versions insecure. Caveats: cryptographic primitives are treated as contracts, `keygen` isn't covered, and no new vulnerabilities were found. The Lean development is open source. https://deepmind.google/blog/introducing-alphaproof-code/ | https://x.com/pushmeet/status/2120127611137634376 | https://news.ycombinator.com/item?id=50439193
> [zh] **Google DeepMind 用 AlphaProof Code 把 Signal 协议的安全性一路证明到机器码**：研究员先和多个模型一起把安全目标写成形式化规范（每条都经人工审核），再由 Gemini Carbon 驱动的证明 Agent 为编译成 AArch64 的 libsignal 的 PQXDH 握手和 Triple Ratchet 生成约 650 万行 Lean 证明，证明了前向保密、身份认证、失陷后安全和握手保密。证明建立在约 2.6 万行可信规范和机器码语义之上；Agent 只把约 1% 的内容标给人工复核，全程四周。DeepMind 称这是被广泛部署的协议实现第一次被形式化验证（无论用不用 AI）。把两个早已修复的旧漏洞重新放回去后，系统证明了这些版本不安全。局限：密码学原语按契约处理，`keygen` 不在覆盖范围，也没发现新漏洞。Lean 证明已开源。

1. **FrontierHarness v1.1: when you switch to an open model, does the harness matter?**: Runta is spending up to 100B tokens on 26,040 runs, 21 harness configurations × 5 open-weight models (GLM-5.3, GLM-5.3 Flash, DeepSeek V4.1 Flash, Kimi K3, Muse Spark Open) × 62 pinned tasks × 4 attempts, where only verifier passes count. In the still-running snapshot, Codex CLI leads at 77.9%, then Pi at 72.8%, yetone's indie Alma at 72.7% and Claude Code at 70.0%; Alma's cost per successful task is about $0.80 versus Claude Code's $0.94, and Pi with DeepSeek reaches 80.3%. The takeaway for builders: Claude Code and Codex CLI here aren't running their own vendors' models, so the gap is purely the harness, and rankings can still move. https://x.com/guanlan/status/2120192585235046712 | https://frontierharness.org/ | https://x.com/xiaomovps/status/2120427969688825909
> [zh] **FrontierHarness v1.1：换成开源模型后，Agent 外壳差多少？**：Runta 花最多 1000 亿 token 跑 26,040 次任务，21 套 harness 配置 × 5 个开放权重模型（GLM-5.3、GLM-5.3 Flash、DeepSeek V4.1 Flash、Kimi K3、Muse Spark Open）× 62 道固定任务 × 每题 4 次，只有通过验证器才算分。仍在跑的快照里，Codex CLI 以 77.9% 领先，其后是 Pi 72.8%、独立开发者 yetone 的 Alma 72.7%、Claude Code 70.0%；Alma 每个成功任务约 0.80 美元，Claude Code 约 0.94 美元，Pi 搭配 DeepSeek 达到 80.3%。对开发者的启示：这里的 Claude Code 和 Codex CLI 都没接自家模型，差距完全来自外壳；排名还可能变化。

> [en] **shao__meng breaks down 20VC's interview with Higgsfield's founder: how an AI video company went from burning cash to a billion-dollar run rate**: after raising about $16M in seed money, it spent over a year and $10M+ before conversations with eight creative directors pointed to camera control; product-market fit came only after the Mar 31, 2025 launch.
