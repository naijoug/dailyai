## AI 热点
1. **How the Claude Code team thinks about verification**: a new claude.dev post by Addy Osmani says ~90% of Claude Code’s code is written and reviewed by Claude, so the bottleneck is evidence, not generation. It recommends E2E, property and differential tests; a repo-level `verify` skill so Claude smoke-tests the running app before committing; escalating to a human after three failed rounds; a 39-item reliability checklist triggered from the diff; one reviewer tuned via REVIEW.md read from the base branch so a change can never edit its own checks; and a commit gate with off/observe/enforce modes. @ClaudeDevs’ post had about 6,100 likes and 6,500 bookmarks. https://x.com/ClaudeDevs/status/2122457608963395586
> [zh] **Claude Code 团队如何看待验证**：Addy Osmani 在 claude.dev 新文中说，Claude Code 约 90% 的代码由 Claude 编写并审查，瓶颈已从生成转向证据。文章推荐端到端、属性和差分三类测试；在仓库里放一个 `verify` skill，让 Claude 提交前先跑起应用做冒烟测试；连续三轮修不好就交给人；按 diff 触发的 39 项可靠性清单；只用一个审查者，用从基础分支读取的 REVIEW.md 调优，保证改动改不了评判自己的规则；以及带关闭/观察/强制三档的提交门禁。@ClaudeDevs 原帖约 6,100 赞、6,500 收藏。
2. **Claude Code desktop can now test apps on iPhone Duo in the iOS simulator**: in public beta (macOS, Xcode 27.1+), Claude can run your app on Duo next to the conversation and fold/unfold the device to test each layout; it can also offer Apple’s App Resizability skill to scan a project for layout issues and verify the fixes you approve. For terminal users, the Xcode plugin is now in the official marketplace (`/plugin install xcode@claude-plugins-official`) to build, run, test, render SwiftUI previews and search docs. https://x.com/ClaudeDevs/status/2122439098740674839
> [zh] **Claude Code 桌面版可在 iOS 模拟器里用 iPhone Duo 测试应用**：公测中（macOS，需 Xcode 27.1 及以上），Claude 能在对话旁把应用跑在 Duo 上，并折叠、展开设备逐一测试各种布局；还可以提议安装苹果的 App Resizability skill，扫描项目里的布局问题，并验证你批准的修复。终端用户可从官方插件市场安装 Xcode 插件（`/plugin install xcode@claude-plugins-official`），用来构建、运行、测试、渲染 SwiftUI 预览和查文档。
3. **OpenAI starts “embedded assessments” with Apollo Research, METR, Transluce and Goodfire**: outside experts get some of the same internal access OpenAI researchers have, including checkpoints, source code, training and eval data and monitoring systems. Apollo will test whether models could covertly work against their developers and whether safeguards catch it; METR will look for misalignment in OpenAI’s largest RL run to date; Transluce reviews non-public alignment evals with raw chains of thought; Goodfire embeds interpretability researchers. Neel Nanda welcomed it but said it falls short of “employee-like access” because OpenAI still controls the information flow. https://x.com/OpenAI/status/2122359930628063248
> [zh] **OpenAI 与 Apollo Research、METR、Transluce、Goodfire 开展「嵌入式评估」**：外部专家可获得部分与 OpenAI 研究员相同的内部权限，包括模型检查点、源代码、训练与评测数据和监控系统。Apollo 评估模型是否会暗中违背开发者意图、安全措施能否发现；METR 在 OpenAI 迄今最大的强化学习训练中查找失准行为；Transluce 审阅带原始思维链的非公开对齐评测；Goodfire 派可解释性研究员入驻。Neel Nanda 表示欢迎，但认为它达不到「员工级访问」，因为信息流仍由 OpenAI 控制。
4. **Hugging Face switches Inference Providers to OpenRouter’s router**: every open-weight model on the Hub that a provider serves can now be called with an HF token through one API (Chat Completions, Responses and Anthropic Messages), with each request routed across 80+ providers by live price, speed and reliability and retried elsewhere on failure; HF publishes setup guides for Claude Code, Codex, OpenCode, Pi and Hermes Agent. The HF post cites OpenRouter data showing open-weight models went from 26.8% to 71.7% of tokens served between Oct 2025 and Sept 2026. https://x.com/ClementDelangue/status/2122392943957078032
> [zh] **Hugging Face 推理服务改用 OpenRouter 的路由**：Hub 上任何有服务商托管的开放权重模型，现在都能用 HF token 通过同一个 API 调用（支持 Chat Completions、Responses 和 Anthropic Messages），每个请求按实时价格、速度和可靠性在 80 多家服务商之间路由，失败自动换一家重试；HF 给出了 Claude Code、Codex、OpenCode、Pi 和 Hermes Agent 的接入指南。HF 博客引用 OpenRouter 数据：2025 年 10 月到 2026 年 9 月，开放权重模型在其 token 量中的占比从 26.8% 升到 71.7%。
5. **Labs court scientists: OpenAI’s productivity study and free Gemini 4 Carbon for 10,000 researchers**: OpenAI said scientists in its ChatGPT for Academic Researchers program reported nearly doubling their productivity, based on a privacy-preserving study of more than 1,800 participants, and announced broader access for scientists. The same day Google DeepMind expanded its Antigravity program for 10,000 scientists to include free Gemini 4 Carbon, citing uses such as AlphaProof code agents proving the security of Signal’s cryptographic code. https://x.com/OpenAI/status/2122380010287960095
> [zh] **各家争抢科学家用户：OpenAI 发布生产力研究，谷歌给 1 万名研究者免费 Gemini 4 Carbon**：OpenAI 称，基于对 1,800 多名参与者的隐私保护研究，ChatGPT for Academic Researchers 项目中的科学家自报生产力接近翻倍，并宣布扩大对科学家的开放。同日 Google DeepMind 把面向 1 万名科学家的 Antigravity 项目扩展为可免费使用 Gemini 4 Carbon，举例称 AlphaProof 代码 Agent 证明了 Signal 加密代码的安全性。

## 有趣用法和干货
1. **Simon Willison: the “external sandbox” pattern for coding agents**: agents keep running on your Mac, but the code they write executes inside a WebAssembly (v86), QEMU or Apple Container Linux sandbox, with demos for Claude Code, Codex and Pi. Built with Prime Radiant (the lab behind Superpowers), the index repo defines a common HTTP/WebSocket protocol, a conformance runner, a shared terminal and managed-network policy UI, a Claude Code shell prefix and Codex setup notes. https://x.com/simonw/status/2122500307557265651
> [zh] **Simon Willison：给编程 Agent 用的「外部沙箱」模式**：Agent 仍在你的 Mac 上运行，但它写的代码在 WebAssembly（v86）、QEMU 或 Apple Container 的 Linux 沙箱里执行，并附 Claude Code、Codex 和 Pi 的演示。项目与 Prime Radiant（Superpowers 背后的实验室）合作，索引仓库定义了统一的 HTTP/WebSocket 协议、一致性测试工具、共享的终端与网络策略界面，以及 Claude Code 的 shell 前缀和 Codex 配置说明。
2. **Hassan (Together AI): how agent evals lifted task success from 67% to 96%**: in an X Article, he describes turning common developer tasks into prompts and running each one three ways (baseline, docs MCP, Together skills) across three models with two attempts each. Agents run in sandboxes via GitHub Actions behind a proxy that records API calls, then an LLM judge grades pass/incomplete/fail. One finding: Sonnet 4.6 passed only 4 of 15 attempts at a GPU-pricing task because it treated sample CLI output as real data. They plan to open-source the framework next week. https://x.com/nutlope/status/2122378712649748694
> [zh] **Hassan（Together AI）：靠 Agent 评测把任务成功率从 67% 提到 96%**：他在 X 长文中介绍，把开发者常做的任务写成提示词，每个任务按三种配置（基线、文档 MCP、Together skills）、三个模型、各两次去跑。Agent 通过 GitHub Actions 跑在沙箱里，代理层记录 API 调用，再由 LLM 评审判为通过、未完成或失败。其中一个发现：Sonnet 4.6 在 GPU 定价任务上 15 次只过了 4 次，因为它把 CLI 文档里的示例输出当成了真实数据。框架计划下周开源。
3. **Unsloth adds computer use for any local model (beta)**: Daniel Han says they had Qwen3.8-27B build an expense report from receipts and use GIMP to scale photos, add captions and export, and that local models can now also drive Unreal Engine, Blender and more (release v0.1.918-beta). https://x.com/danielhanchen/status/2122365870995612059
> [zh] **Unsloth 给任意本地模型加上电脑操作能力（Beta）**：Daniel Han 说，他们让 Qwen3.8-27B 根据收据做出报销单，还用 GIMP 缩放照片、加说明文字并导出；本地模型现在也能操控 Unreal Engine、Blender 等软件（版本 v0.1.918-beta）。
4. **向阳乔木：一句让软件「有情趣」的空状态提示词**：他分享给编程 Agent 的提示词：“帮我设计下空页面，比如没配置模型时的状态，让用户感觉到温馨、有趣。你可以用 SVG 动画等来传递表达。”理由是 Chrome 断网时有小恐龙游戏，空页面里的小彩蛋能给用户情绪价值，让产品细节好一点。https://x.com/vista8/status/2122370293352309235
> [en] **vista8: an empty-state prompt that gives software some charm**: his prompt for coding agents: “Design the empty pages, such as the state when no model is configured, so users feel warm and amused. You can use SVG animations and the like to express it.” His reasoning: Chrome has the dinosaur game when you’re offline, and small easter eggs in empty states give users emotional value and polish the product details.
