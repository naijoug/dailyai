## AI 热点
1. **NVIDIA open-sources SkillSpector, a security scanner for AI agent skills**: it scans Git repos, URLs, zips or local folders for Claude Code, Codex and Gemini skills before install, combining static checks (prompt injection, exfiltration, supply-chain, MCP tool poisoning and more) with optional LLM review; returns a 0–100 risk score and Safe / Caution / Do Not Install. Research cited: in a 31,132-skill subset, 26.1% had vulnerabilities and 5.2% looked likely malicious. https://github.com/NVIDIA/SkillSpector | https://x.com/oliviscusAI/status/2115755510146441345
> [zh] **NVIDIA 开源 SkillSpector，面向 AI Agent Skill 的安全扫描器**：安装前可扫描 Git 仓库、URL、zip 或本地目录里的 Claude Code、Codex、Gemini skill，静态检查（提示词注入、数据外泄、供应链、MCP 工具投毒等）可加可选 LLM 语义审查，输出 0–100 风险分和 Safe / Caution / Do Not Install。其研究样本 31132 个 skill 中，26.1% 有漏洞、5.2% 疑似恶意。

Amp also added in-thread visualizations (charts, timelines, diagrams, mockups). https://ampcode.com/news/macos-satellites | https://x.com/hameonline/status/2115687637378081177 | https://ampcode.com/news/visualize-this | https://x.com/thorstenball/status/2115770366031245645
> [zh] **Amp 上线 macOS Satellites：Agent 可拉起一台 Mac 来构建、测试并运行 iOS/macOS 应用**：Orb 旁可起一台 Mac，跑应用并用录屏证明能工作，正在逐步开放；同日还支持在对话里直接画图表、时间线、示意图和线框。

Hunt for unexpected base_url / danger-full-access and user-scope AI env vars. https://www.security.com/threat-intelligence/openai-claude-unauthorized-relays | https://x.com/threatintel/status/2115762157287780530
> [zh] **Symantec：灰市中转会装上正版 Codex / Claude Code CLI，关掉沙箱并把全部流量代理出去**：用户粘贴一行安装命令后，脚本改写 `~/.codex/config.toml`（`sandbox_mode = "danger-full-access"`）或 Claude 配置，把 base URL 和 API key 换成中转端点；自 2026 年初已在约十几家中国及周边跨国机构出现。请自查异常 base_url、danger-full-access 和用户级 AI 环境变量。

> [zh] **Addy Osmani：你大概在给 Claude 写太多提示词**：对 Opus 5.5，一条提示说清目标和如何验收即可，从 `/effort medium` 起步，让它自己停；长任务用 `/goal`，用 Projects 代替手管多会话，少主动开 subagent（只给大块独立活），并用 `/doctor prompt-audit` 清掉为旧模型写的指令。1800+ 收藏。
