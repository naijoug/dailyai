## 新产品
1. **Kitesurf (Cloudflare)**: Cloudflare has open-sourced its stateless browser for AI agents (first introduced in August) under Apache 2.0. It runs entirely on Cloudflare Workers: it parses HTML, applies CSS, executes page JavaScript and takes screenshots without a Chromium process or browser container, and it speaks Chrome DevTools Protocol so existing clients such as Puppeteer can connect. It is built from Rust packages compiled to WebAssembly (Engine, PageScript and PageRenderer). The official goal is lower CPU and memory than Chromium so more concurrent agent sessions can run on the Workers network; it drops human-facing features such as tabs, themes, extensions and pixel-perfect rendering. You can run it locally with `pnpm run dev` and deploy with `pnpm run deploy`; a Workers Paid plan is required because it uses Dynamic Workers for isolated per-page Workers. The project is under heavy development, and contributions need a maintainer vouch before a PR. https://blog.cloudflare.com/kitesurf-open-source/ | https://github.com/cloudflare/kitesurf | https://www.ithome.com/1/027/197.htm
> [zh] **Kitesurf（Cloudflare）**：Cloudflare 把今年 8 月推出的、面向 AI Agent 的无状态浏览器以 Apache 2.0 开源。它完全跑在 Cloudflare Workers 上：解析 HTML、应用 CSS、执行页面 JavaScript 并截图，不需要 Chromium 进程或浏览器容器，并且兼容 Chrome DevTools Protocol，Puppeteer 这类现有客户端可以直接连。它由编译成 WebAssembly 的 Rust 包组成（Engine、PageScript、PageRenderer）。官方目标是比 Chromium 更省 CPU 和内存，好在 Workers 网络上同时跑更多 Agent 会话；面向人的标签页、主题、扩展和像素级渲染都被拿掉了。本地可用 `pnpm run dev`，再用 `pnpm run deploy` 发布到自己的账号；因为每个页面要用 Dynamic Workers 做隔离，需要 Workers Paid 套餐。项目还在快速迭代，提交 PR 前需要维护者担保。
2. **GR00T 2 (NVIDIA Research / GEAR)**: a new generation of foundation world-action models that jointly predict future video and robot actions, and run on parallel grippers, dexterous hands and humanoids. NVIDIA claims three capabilities: X-Adaptability, where skills shown only by humans or wearable/handheld devices transfer to robots that never practiced them (a human demonstration to two 5-finger hands lining a funnel with filter paper succeeded in 65% of trials; a handheld UMI gripper to a YAM arm assembling a toy dump truck end-to-end in 60% of trials, with tasks up to 4 minutes); fast adaptation, with 40% zero-shot success on 50 tasks never seen on the target robot, rising to 95% after five demonstrations per task (under 3 minutes of robot data) and a 30-minute fine-tune on a single RTX 5090; and dexterity on long-horizon work with two 22-DoF Sharpa hands after minimal post-training. A reasoning model can also steer it because it predicts the outcome it is acting toward. Code is promised in December. https://research.nvidia.com/labs/gear/gr00t-2/
> [zh] **GR00T 2（NVIDIA Research / GEAR）**：新一代基础世界-动作模型，同时预测未来视频和机器人动作，可用于平行夹爪、灵巧手和人形机器人。英伟达给出三项能力：跨本体适应，只由人类或可穿戴/手持设备演示过的技能，能迁移到从未练过的机器人上（人类演示到两只五指手给漏斗垫滤纸，成功率为 65%；手持 UMI 夹爪到 YAM 机械臂从头到尾组装玩具自卸车，成功率为 60%，任务最长约 4 分钟）；快速适应，在目标机器人从未见过的 50 项任务上，零样本成功率 40%，每项任务给 5 次示范（不到 3 分钟的机器人数据）并在一块 RTX 5090 上微调 30 分钟后升到 95%；以及在最小后训练后，用两只 22 自由度的 Sharpa 灵巧手做长程操作。因为它会预测自己正在走向的结果，推理模型也可以来引导它。代码计划 12 月开放。

## 科技新闻
1. **Cursor traces the October marketplace breach to a Fireworks-exposed vendor key (official investigation dated 13 Nov)**: an attacker obtained an access key Cursor had issued to Fireworks, which Cursor says Fireworks exposed, and copied a read-only bucket of limited coding-agent traces, mostly from 2025, from sessions not in Privacy Mode (data Cursor says it was permitted to use for training). A small number of traces contained unredacted credentials; Cursor says less than 0.01% of customers had API credentials exposed. With those, the attacker reached some Cursor SaaS tools and accessed archived non-production source repos (some with business contact info), limited customer-support data and emails, product-usage metrics and contact details, summaries of some coding-agent conversations, and some credentials users had sent to support. On 29 Oct, using a stolen internal credential, the attacker placed unauthorized copies of Anthropic's Claude Code extension (versions 2.1.312 and 2.1.313) on the cache that serves Cursor's VS Code marketplace for about 11 hours; Cursor says at most 5,000 users who requested those cached versions may have received the malicious build. Anthropic did not publish the copy, and Open VSX never carried the malware. The 29 Oct notice says the malicious builds tried to install a persistent SSH backdoor; enabling local SSH needed admin rights, which the extension usually lacked, so that step often failed, and uninstalling the extension alone may not be enough. Privacy Mode prompts and code were not affected; for users not in Privacy Mode, traces were exposed for fewer than 0.05%, and those users were notified. Last observed attacker activity was 1 Nov and was blocked. Cursor says it has moved all inference off Fireworks, deactivated the vendor key, rotated credentials, rebuilt the marketplace and redeployed production infrastructure. https://cursor.com/blog/security-incident-update | https://cursor.com/blog/claude-code-extension-security-notice | https://www.ithome.com/1/027/215.htm
> [zh] **Cursor 把 10 月 Marketplace 入侵追查到 Fireworks 暴露的厂商密钥（官方调查报告日期为 11 月 13 日）**：攻击者拿到了 Cursor 签发给 Fireworks 的访问密钥，Cursor 称是 Fireworks 把密钥暴露了出去，并复制了一个只读存储桶里的有限编程 Agent 轨迹，大多来自 2025 年、且不在隐私模式下的会话（Cursor 称这些数据本就允许用于训练）。少量轨迹里有未打码的凭据；Cursor 说，API 凭据被暴露的客户不到 0.01%。攻击者随后进入部分 Cursor SaaS 工具，看到了归档的非生产代码仓库（部分含商务联系人信息）、有限的客服数据和邮件、产品用量指标和联系方式、部分编程 Agent 对话摘要，以及用户发给客服的一些凭据。10 月 29 日，攻击者又用偷来的内部凭据，把未经授权的 Anthropic Claude Code 扩展副本（版本 2.1.312 和 2.1.313）放到了为 Cursor 的 VS Code 扩展市场提供缓存的位置，大约存在了 11 个小时；Cursor 称，最多可能有 5000 名请求过这些缓存版本的用户拿到了恶意构建。这份副本不是 Anthropic 发布的，Open VSX 也从未托管该恶意软件。10 月 29 日的安全公告还说，恶意构建试图安装持久的 SSH 后门；开启本机 SSH 通常需要管理员权限，扩展一般没有，所以这一步常常失败，而且只卸载扩展可能不够。隐私模式下的提示词和代码未受影响；未开隐私模式的用户中，轨迹泄露比例不到 0.05%，这些用户已收到通知。攻击者最后一次活动出现在 11 月 1 日，已被阻断。Cursor 称已把全部推理迁出 Fireworks，停用了该厂商密钥，轮换了凭据，重建了扩展市场并重新部署了生产基础设施。
