## 有趣用法和干货
1. **“MoE is a datacenter architecture. Looped transformers are a laptop architecture.”**: Zhengyao Jiang’s point (1.3k likes, 826 bookmarks): MoE trades memory for compute—huge weights with few active per token—which pays off with big batches and big GPUs, but on a laptop the batch size is 1 (often 0) and the memory isn’t there. Bojie Li added the buying advice: single-request decode speed is mostly memory bandwidth, so he doesn’t recommend a maxed-out Mac for LLM inference—the same money buys a 5090 with 3–4x the bandwidth of an M4 Max (3x an M5 Max); looped transformers, like speculative decoding, do more compute per parameter read even for one request, so they use personal hardware better. https://x.com/zhengyaojiang/status/2124292767274713218 [Bojie Li](https://x.com/bojie_li/status/2124346967014912010)
> [zh] **「MoE 是数据中心架构，循环 Transformer 是笔记本架构」**：Zhengyao Jiang 的观点（1.3k 赞、826 收藏）：MoE 用内存换算力——权重巨大、每个 token 只激活少数专家——配合大 batch 和大 GPU 才划算；可在笔记本上 batch size 是 1（常常是 0），内存也不够。李博杰补充了选购建议：单请求 decode 速度主要看内存带宽，所以他不推荐买高配 Mac 做 LLM 推理，同样的钱买 5090，带宽是 M4 Max 的 3–4 倍、M5 Max 的 3 倍；循环 Transformer 和推测解码一样，即使只有一个请求，每读一次参数也能多做几次计算，更能吃满个人设备的算力。

3. **MBZUAI 与 UCL 拆解 Claude Code：一个 while 循环，外面包着七档权限和五层压缩**：shao__meng 推荐的技术报告「Dive into Claude Code」分析了 Claude Code v2.1.88 的 1884 个文件、51.2 万行 TypeScript：核心只是「调模型→跑工具→重复」的简单循环，大部分代码在循环周边——七种模式加 ML 分类器的权限系统、五层上下文压缩流水线、MCP/插件/Skill/Hook 四种扩展机制、子 Agent 委派编排和追加式会话存储。报告还与 OpenClaw、Hermes Agent 对比：Claude Code 重单步操作安全，OpenClaw 重边界级访问控制，Hermes 在多个界面呈现逐步审批，并提出六个未来 Agent 系统的开放设计方向。https://x.com/shao__meng/status/2124369057805926670 [论文](https://arxiv.org/abs/2604.14228v3) [GitHub](https://github.com/VILA-Lab/Dive-into-Claude-Code)
> [en] **MBZUAI and UCL dissect Claude Code: a while-loop wrapped in seven permission modes and five compaction layers**: the “Dive into Claude Code” tech report shao__meng highlighted analyzes 1,884 files and 512k lines of TypeScript in Claude Code v2.1.88. The core is a simple loop—call the model, run tools, repeat—while most code lives around it: a permission system with seven modes plus an ML classifier, a five-layer context-compaction pipeline, four extension mechanisms (MCP, plugins, skills, hooks), subagent delegation and append-oriented session storage. Compared with OpenClaw and Hermes Agent, Claude Code stresses per-action safety, OpenClaw perimeter-level access and Hermes per-action approvals across many surfaces; the report closes with six open design directions for agent systems.
4. **李博杰：只凭会议录音里飞机的轰鸣声就能定位你在哪**：他这周用 Claude 发现，飞机航线公开，低频轰鸣声 10 公里内、宽频噪声 1 公里内都能被麦克风收到；不同飞机的频谱特征不同，只要录到两次远距飞机飞过，结合低频轰鸣、多普勒效应和交叉定位就能匹配到城市级（10 公里），有准确时间戳且有小飞机近距离飞过时可到公里级。他在户外做了 24 小时模拟实验，Google Meet 和 Telegram Desktop 几乎无损保留了这些噪声，Zoom 默认设置会过滤一部分。结论：不开摄像头也不等于不暴露位置。https://x.com/bojie_li/status/2124474292322836982
> [en] **Bojie Li: aircraft noise in a meeting recording can reveal where you are**: working with Claude this week, he found that because flight paths are public and a microphone can pick up low-frequency engine rumble within 10 km and broadband noise within 1 km, each plane’s distinct spectral signature lets two distant flyovers—via the rumble, Doppler shift and cross-fixing—pin you to a city (10 km); with an exact timestamp and a close small plane, down to about 1 km. In a 24-hour outdoor test, Google Meet and Telegram Desktop kept these sounds almost intact, while Zoom’s defaults filtered some. Takeaway: keeping your camera off doesn’t keep your location private.
