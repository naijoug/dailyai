## 新产品
1. **GLM-5.4**: Z.ai’s first Loop Transformer flagship (750B parameters). It loops 28 layers of the GLM-5 base for two iterations and, the company says, reaches intelligence comparable to 2T–3T-parameter models; the pitch is “Generalized Coding,” with demos of video, games, FreeCAD and GLSL shaders written as code. API access is promised after a safety review, and open weights after safety hardening; ZCode and Z.ai Chat are available now. The post hit 203 points on HN. https://z.ai/blog/glm-5.4 https://z.ai/ [HN](https://news.ycombinator.com/item?id=50609685)
> [zh] **GLM-5.4**：智谱 / Z.ai 的首个 Loop Transformer 旗舰（7500 亿参数）。它把 GLM-5 基座的 28 层循环跑两轮，官方称智能水平可与 2–3 万亿参数模型相当；定位是「泛 Coding」，演示了用代码做视频、游戏、FreeCAD 和 GLSL 着色器。API 要等安全评估后开放，权重计划在安全加固后开源；ZCode 和 Z.ai Chat 现已可用。这篇发布说明在 HN 拿到 203 分。
2. **CLI-Anything**: an agent-native CLI hub from HKU researchers (GitHub Trending, 783 stars today). Instead of driving GUIs with screenshots and clicks, it turns desktop apps, developer tools, creative software and SaaS APIs into command-line harnesses with `--json` output, REPL mode and a registry you browse via `cli-hub search/info/install/launch`; “matrices” bundle a workflow as capabilities × providers. Install the hub with `pip install cli-anything-hub`, or add the skill with `npx skills add HKUDS/CLI-Anything`. Some harnesses still need the underlying GUI app or an API key locally. https://clianything.cc https://github.com/HKUDS/CLI-Anything
> [zh] **CLI-Anything**：港大研究者做的面向 Agent 的命令行中枢（登上 GitHub Trending，今日 +783 星）。它不靠截图和点击去操作图形界面，而是把桌面软件、开发工具、创作软件和 SaaS API 变成带 `--json` 输出和 REPL 的命令行外壳，用 `cli-hub search/info/install/launch` 在注册表里查找和安装；「matrix」则按能力 × 提供者打包工作流。中枢可用 `pip install cli-anything-hub` 安装，也可用 `npx skills add HKUDS/CLI-Anything` 加 skill。部分外壳仍需本机装有对应的图形软件或 API 密钥。
3. **Marlowe**: a six-month-old “multi-silicon AI factory” that designs, builds and operates inference infrastructure around non-Nvidia chips. The company, co-founded by two Microsoft vice presidents, raised a $277M seed led by Accel at a $1.15B valuation (Bloomberg, via Techmeme). Its site says it partners with chipmakers, builds capacity, and co-designs the data-center-to-serving stack so chips from AMD, Cerebras, Etched and others can actually be used for inference. https://www.marlowe.ai/ [Techmeme](https://www.techmeme.com/261123/p16#a261123p16)
> [zh] **Marlowe**：一家成立六个月的「多芯片 AI 工厂」，围绕非英伟达芯片来设计、建造和运营推理基础设施。两位微软副总裁联合创立，由 Accel 领投 2.77 亿美元种子轮，估值 11.5 亿美元（彭博，经 Techmeme）。官网称它与芯片厂商合作、建设运力，并把数据中心到推理服务的整栈一起设计，好让 AMD、Cerebras、Etched 等芯片真正用于推理。
4. **Sierra**: Bret Taylor and Clay Bavor’s customer-service agent company says it is raising $1.75B at a $30B valuation, led by Greenoaks and Lightspeed, with previous leads Benchmark, Sequoia, Greenoaks, GV and Tiger Global all coming back. ## 科技新闻
1. **Vals AI: GPT-6.2 Astra produced a Lean proof of Smoktunowicz’s 2006 gap theorem, a task no other model on Autoform-Hard has solved**: the theorem says no graded domain has Gelfand–Kirillov dimension strictly between 2 and 3; Vals says it had never been formalized, and Astra’s 1,794-line proof takes a different route from the published one because the original’s key lemmas are not in Mathlib. Astra worked alone in a sandbox with Lean, Mathlib and a shell, under a three-hour / $200 cap; after 47 minutes it submitted a partial proof with a `sorry`, then an honest “unsolved” report after about $8, but the harness will not let a model quit before $20, so it thought for nine minutes with no code and started over. The grader accepted the proof 39 minutes later, 94 minutes and $21.58 in total, 146 agent turns. Vals says a clean-room check and a hand review found no `sorry`, no extra axioms and a statement that matches Theorem 1; Astra now leads the 56-task board with 49 solves, ahead of GPT-6.2 Sol and Claude Fable 5.2 at 48 each. https://www.vals.ai/blogs/smoktunowicz-gap-theorem https://the-decoder.com/gpt-6-2-astra-solved-a-math-theorem-no-other-ai-could-crack-then-invented-its-own-proof-strategy/
> [zh] **Vals AI：GPT-6.2 Astra 用 Lean 证明了 Smoktunowicz 2006 年的间隙定理，Autoform-Hard 上还没有其他模型做成这道题**：定理说，分次整环的 Gelfand–Kirillov 维数不会严格落在 2 和 3 之间；Vals 称此前从未被形式化，而 Astra 这份 1794 行证明走了和发表证明不同的路线，因为原文依赖的关键引理不在 Mathlib 里。Astra 独自在装有 Lean、Mathlib 和 shell 的沙箱里做题，时限三小时、预算 200 美元；47 分钟时它交了一份带 `sorry` 的部分证明，花了约 8 美元后又老实提交了「未解决」报告，但这套评测在花满 20 美元之前不许放弃，于是它空转思考了九分钟再另起炉灶。评测器在 39 分钟后接受了完整证明，全程 94 分钟、21.58 美元、146 轮。Vals 称洁净室检查和人工复核没有 `sorry`、没有额外公理，命题与论文定理 1 一致；Astra 现在以 49 题领先这块 56 题榜，GPT-6.2 Sol 和 Claude Fable 5.2 各为 48 题。
2. **姚顺雨与腾讯混元团队在 Reddit LocalLLaMA 做了约两小时 AMA**：这是混元团队首次在该社区集中答问，围绕刚发布的 Hy4 与 Hy4 flash。面对「为何别家已在探索数万亿参数、混元仍是数千亿」的追问，团队称下一代 Hy 模型将显著扩参，并表示仍然相信 Scaling Law；对递归自我改进（RSI），他们承认仍处早期，虽已做内部评测基准，但当务之急仍是提高基础智能。被问到后训练中最难改善的行为时，回答是「过度思考」。InfoQ 的整理还提到：Hy4 主打通用智能，Hy4 flash 单任务成本约为 Hy4 的二十分之一；从今年 2 月重建预训练与强化学习基础设施到两款模型发布，大约用了九个月。AMA 本身在 11 月 21 日凌晨举行，这篇整理 11 月 23 日刊出。https://www.infoq.cn/article/b4QKbFZaXvbK9hzcBhZV
> [en] **Yao Shunyu and the Tencent Hunyuan team held a roughly two-hour AMA on Reddit’s LocalLLaMA**: it was the team’s first concentrated Q&A in that community, centered on the newly released Hy4 and Hy4 flash. Asked why other Chinese labs are already exploring multi-trillion-parameter models while Hunyuan is still in the hundreds of billions, the team said the next Hy model will grow substantially in size and that they still believe in scaling laws. On recursive self-improvement (RSI), they said the work is still early: they have an internal eval, but the priority remains raising base intelligence. Asked which post-training behavior is hardest to improve, they answered “overthinking.” InfoQ’s write-up also notes that Hy4 is the general-intelligence model and that Hy4 flash costs about one-twentieth as much per task; it took about nine months from rebuilding pretraining and RL infrastructure in February to shipping both models. The AMA itself was in the early hours of November 21; this article ran on November 23.
