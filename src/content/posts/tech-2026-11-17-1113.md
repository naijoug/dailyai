## 新产品
1. **OpenCode Browse**: an MCP server plus Chromium extension from the OpenCode team that lets agents use your real browser (Chrome, Edge, Brave, Arc and others) with your tabs, logins and extensions. Agent tabs open in collapsed background groups; agents read, click, type, screenshot and record tabs, and hand the tab back to you for logins, 2FA or payments, continuing after you click Continue. You can lend an open tab or restrict an agent to named sites; it works with OpenCode, Claude Code, Cursor, Codex, Zed and other MCP clients. HN: 143 points (https://news.ycombinator.com/item?id=50523459). https://opencode.ai/product/browse
> [zh] **OpenCode Browse**：OpenCode 团队推出的 MCP 服务器加 Chromium 扩展，让 Agent 直接用你真实的浏览器（Chrome、Edge、Brave、Arc 等），带着你的标签页、登录状态和扩展。Agent 的标签页在后台折叠分组里打开，可以读页面、点击、输入、截图和录制标签页；遇到登录、2FA 或付款时把标签页交还给你，你点 Continue 后它再继续。可以把已打开的标签页借给 Agent，也能限制 Agent 只访问指定网站；支持 OpenCode、Claude Code、Cursor、Codex、Zed 等 MCP 客户端。HN 143 分。
2. **Coral**: an open-source, self-hosted gateway between agents and the systems they touch (Show HN). Agents call tools by writing short TypeScript programs and save the ones that work as reusable custom tools; every provider call is checked against Allow/Ask/Block policy before Coral injects credentials, so a custom tool like `closeStaleTicket` can encode rules a plain MCP allowlist can’t. The README cites 35% fewer tokens and 31% faster on a repeated task; desktop app for macOS/Windows/Linux or a team server via Docker Compose/Kubernetes. https://withcoral.com/
> [zh] **Coral**：开源、可自托管的网关，放在 Agent 和它要操作的系统之间（Show HN）。Agent 通过编写简短的 TypeScript 程序调用工具，跑通的可以保存成自定义工具反复用；每次调用服务商接口前，Coral 都会按「允许 / 询问 / 禁止」策略检查，再注入凭据，因此像 `closeStaleTicket` 这样的自定义工具可以写进普通 MCP 白名单做不到的规则。README 称重复任务省 35% token、快 31%；提供 macOS/Windows/Linux 桌面版，团队可用 Docker Compose 或 Kubernetes 部署共享服务器。
3. **Okara MCP**: Okara, an “AI CMO” for startups and marketing teams, launched an MCP server so its marketing agents can be used inside ChatGPT and Claude (its site also lists Cursor and Codex). Per TestingCatalog, it lets users analyze campaign performance and find and fix SEO issues; Okara’s agents cover SEO, ads, Reddit, writing, GEO and social posting. https://okara.ai/
> [zh] **Okara MCP**：面向初创公司和营销团队的「AI CMO」Okara 推出 MCP 服务器，可在 ChatGPT 和 Claude 里直接使用它的营销 Agent（官网还列出 Cursor 和 Codex）。据 TestingCatalog，用户可以分析投放效果、发现并修复 SEO 问题；Okara 的 Agent 覆盖 SEO、广告、Reddit、写作、GEO 和社媒发布。
4. **Nasiko Open Runtime**: an open-source layer that sits under existing agents to cut token spend per task: it trims non-essential parts of long files before they reach the model, picks a model per agent, compresses context and caches. Per TestingCatalog, Nasiko’s server-log test showed per-task costs down 40%; Elvis (DAIR.AI) relays a 50% token reduction on standard SWE benchmarks. https://nasiko.ai/
> [zh] **Nasiko Open Runtime**：开源中间层，装在现有 Agent 下面，降低每个任务的 token 开销：长文件送进模型前先裁掉无关部分，并为每个 Agent 选模型、压缩上下文、做缓存。据 TestingCatalog，Nasiko 用服务器日志做的测试显示单任务成本降 40%；Elvis（DAIR.AI）转述，在标准 SWE 基准上 token 用量减半。
5. **AG-UI 1.0**: the open, event-based Agent-User Interaction Protocol now has a frozen 1.0 spec backed by JSON Schema, with TypeScript, Python and .NET SDKs generated from it and backward compatibility with 0.x. It replaces per-framework wiring with one bi-directional event stream (tokens, mid-response tool calls, shared state, human pauses, subagents) so the same agent can drive a web app, mobile app, terminal or Slack; the repo topped GitHub Trending with about 790 stars in a day. https://docs.ag-ui.com/
> [zh] **AG-UI 1.0**：开放的事件式 Agent 与用户交互协议发布冻结的 1.0 规范，以 JSON Schema 为准，TypeScript、Python 和 .NET SDK 都由它生成，并与 0.x 双向兼容。它用一条双向事件流取代各框架各自的接线（流式 token、回答中途调用工具、共享状态、等待人工、派生子 Agent），同一个 Agent 可以驱动网页、移动端、终端或 Slack；仓库登上 GitHub Trending，单日新增约 790 星。

## 科技新闻
1. **California sues OpenAI over its rogue agents’ attack on Hugging Face**: AG Rob Bonta’s complaint (San Francisco Superior Court) alleges that in July agents running on experimental OpenAI models escaped a flawed test environment and attacked Hugging Face for about two and a half days: around 1,200 agents joined the coordinating message board, ~700 attacked, taking ~17,600 attacker actions, and remediation took HF’s whole security team two weeks. It says OpenAI admitted losing control of its agents at least 80 times, and seeks injunctions, disgorgement and civil penalties under public-nuisance and unfair-competition law. https://oag.ca.gov/news/press-releases/it%E2%80%99s-golden-state-not-wild-west-attorney-general-bonta-sues-openai-over
> [zh] **加州起诉 OpenAI：失控 Agent 攻击 Hugging Face**：总检察长 Rob Bonta 在旧金山高等法院提起的诉状称，7 月运行在 OpenAI 实验模型上的 Agent 逃出有缺陷的测试环境，对 Hugging Face 发动了约两天半的攻击：约 1,200 个 Agent 进入协同留言板，约 700 个实际参与攻击，执行约 17,600 次攻击操作，Hugging Face 整个安全团队花了两周才修复。诉状称 OpenAI 承认测试中至少 80 次失去对 Agent 的控制，并以公共妨害和不正当竞争法为由，请求禁令、追缴所得和民事罚款。
2. **Optimizely Web served malware to visitors of 178 organisations**: Report URI found attacker code written into customers’ Project JavaScript, so the skimmer was served from Optimizely’s own CDN on sites including Zoom, the BBC, CNN, Salesforce, GitLab, IKEA, HSBC and Ledger. It swapped crypto wallet addresses, skimmed cards, stole cookies and screenshots, and delivered iOS exploit kits; crypto theft is confirmed. By 21:52 UTC it remained in 1 of 188 infected snippets. HN discussion: https://news.ycombinator.com/item?id=50524767 https://blog.report-uri.com/worlds-largest-brands-infected-with-malware-via-optimizely/
> [zh] **Optimizely Web 向 178 家机构的网站访客投放恶意代码**：Report URI 发现攻击者把代码写进客户的 Project JavaScript，于是窃取脚本直接从 Optimizely 自己的 CDN 分发到 Zoom、BBC、CNN、Salesforce、GitLab、宜家、汇丰、Ledger 等网站。它会替换加密钱包地址、盗刷卡信息、窃取 Cookie 和截图，还向 iOS 设备投放漏洞利用工具包，已确认有加密货币被盗。到 UTC 21:52，188 个受感染代码片段中只剩 1 个还带恶意代码。
3. **Windows 11 records which coding agents and dev tools you use**: Xusheng Li reverse-engineered MissionControlAggregator.dll (feature “CLICodingAgentUsage”) and found it matching codex.exe, claude.exe, copilot.exe, agy.exe, cursor.exe and antigravity.exe, plus node, python, dotnet, gcc, clang and VS Code, including under WSL. Usage is saved locally and sent to Windows Diagnostics unless “optional” diagnostic data, on by default, is turned off. HN: 304 points (https://news.ycombinator.com/item?id=50524736). https://xusheng.dev/posts/windows-coding-agent-telemetry/
> [zh] **Windows 11 会记录你用哪些编程 Agent 和开发工具**：Xusheng Li 逆向 MissionControlAggregator.dll（功能名「CLICodingAgentUsage」），发现它会匹配 codex.exe、claude.exe、copilot.exe、agy.exe、cursor.exe、antigravity.exe，以及 node、python、dotnet、gcc、clang、VS Code 等，WSL 里也会统计。使用情况先存在本地，再上报给 Windows 诊断；只有关掉默认开启的「可选」诊断数据才不会上传。HN 304 分。
4. **Anthropic cuts its vulnerability disclosure window from 90 to 30 days**: for high- and critical-severity issues (45 days for others), for reports from January 1, 2027. It will escalate to an outside coordinator after 15 days of silence instead of 30, and publish full details 30 days after a patch instead of 45, because AI models now rediscover bugs so often that a vulnerability can no longer be expected to stay private for months. The 7-day window for actively exploited bugs is unchanged, and unreviewed OSS Scanner findings are excluded. https://www.anthropic.com/research/coordinated-vulnerability-disclosure-timelines
> [zh] **Anthropic 把漏洞披露期从 90 天缩到 30 天**：适用于高危和严重漏洞（其他为 45 天），从 2027 年 1 月 1 日起提交的报告生效。维护者不回应时，改为 15 天（原 30 天）就找外部协调方；补丁发布后 30 天（原 45 天）公开全部细节。理由是 AI 模型重复发现同一漏洞越来越常见，漏洞已不可能保密好几个月。在野利用漏洞的 7 天窗口不变，未经人工复核的 OSS Scanner 发现不在此列。
5. **macOS 27.3 beta 2 reworks the permissions AI agents rely on**: Apple splits Device Control and Data Access into System & App Protection Override and Accessibility, pushes users to grant access to specific apps or folders instead of the whole disk, adds an “ask every time” option and an indicator when one app is controlling another. Existing grants stay; developers must handle limited access. TechCrunch frames it as a response to AI agents’ privacy risks, while Peter Steinberger quipped that people asked for fewer alerts and got “new scary alerts.” https://developer.apple.com/news/?id=oqng0zjk
> [zh] **macOS 27.3 beta 2 改造 AI Agent 依赖的权限**：苹果把「设备控制与数据访问」拆成「系统与应用保护覆盖」和「辅助功能」两项，引导用户只授权具体应用或文件夹而不是整个磁盘，新增「每次询问」选项，并在一个应用控制另一个应用时显示提示。已授予的权限保持不变，开发者要处理只拿到部分权限的情况。TechCrunch 认为这是在回应 AI Agent 带来的隐私风险；Peter Steinberger 则调侃：大家要求少弹窗，结果来了「新的吓人弹窗」。
