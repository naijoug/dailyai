## AI 热点
1. **Cursor: a malicious Claude Code VS Code extension (Anthropic.claude-code 2.1.313) reached its marketplace and hit at most 5,000 users**: available about 11 hours on Oct 29 (2:27am–1:35pm PT); not built by Anthropic. The payload collected host/user info, appended an attacker SSH key labeled `svc-telemetry`, tried to enable SSH and open a reverse tunnel (that step usually failed without admin rights), installed LaunchAgent/scheduled-task persistence, and beaconed to an attacker server that Cursor and the cloud provider took offline. Uninstalling alone is not enough—run Cursor’s remediation scripts, update to 2.1.314, and rotate credentials from a clean machine. 4.4k likes, 1.1k bookmarks. https://x.com/cursor_ai/status/2116074289053175808 | https://cursor.com/blog/claude-code-extension-security-notice
> [zh] **Cursor：恶意 Claude Code VS Code 扩展（Anthropic.claude-code 2.1.313）进入其扩展市场，最多影响约 5000 名用户**：10 月 29 日约开放 11 小时（太平洋时间 2:27–13:35）；非 Anthropic 出品。载荷会采集主机/用户信息，向 `authorized_keys` 追加名为 `svc-telemetry` 的攻击者 SSH 公钥，试图开启 SSH 并建立反向隧道（多数机器无管理员权限时这一步会失败），安装 LaunchAgent/计划任务持久化，并向攻击者服务器上报；Cursor 已与云厂商下线该服务器。仅卸载扩展不够——请跑官方清理脚本、升级到 2.1.314，并在干净机器上轮换凭证。4400 赞、1100 收藏。
2. **Claude Code now refuses to recreate a specific existing video game**: a server-side rule under flag `tengu_heron_brook` (noticed around Oct 27, no user toggle) says “Do build original games, games in a genre, and games from the user’s own designs and assets. Don’t build a recreation of a specific existing game, even if it is renamed or called original.” Original/genre/user-asset games are still allowed; Anthropic has not posted an official notice. A viral breakdown drew 3.5k likes / 1.1k bookmarks; Peter Steinberger: another reason to use your own harness. Licensed professional game work has also reported being blocked. https://x.com/chasmmmmmmmmmmm/status/2116062991686721968 | https://x.com/steipete/status/2116153238563242385 | https://github.com/anthropics/claude-code/issues/106167
> [zh] **Claude Code 开始拒绝复刻某一款已有电子游戏**：约 10 月 27 日起由服务端旗标 `tengu_heron_brook` 下发规则（用户侧无法关闭），原文大意是「可以做原创游戏、某一品类的游戏、以及用户自有设计与素材的游戏；不要复刻某一款已有游戏，哪怕改名或自称原创」。原创/品类/自有素材仍可做；Anthropic 尚未发官方说明。拆解帖约 3500 赞、1100 收藏；Peter Steinberger 说这又是一个该用自己 harness 的理由。也有人报告连授权的专业游戏开发也被拦。
3. **Factory ships Droid 1.0: programmatic tool calling is now the default harness mode**: instead of one tool call per model turn, the agent writes a sandboxed JavaScript program that can run hundreds of tool calls in a single request. Factory’s Linear cleanup demo: 312 tool calls in 2 requests and ~61K tokens vs an estimated 36 requests and ~3.1M tokens one-by-one; on Terminal-Bench 4 it claims up to ~20% better efficiency than native harnesses (e.g. Opus 5.5: 65.2% vs Claude Code 57.6%). Model-agnostic; Script mode on by default for GPT-6.1 Sol, Opus 5.5, Fable and others. 1.2k likes, 1k bookmarks. https://x.com/FactoryAI/status/2115934579446182213 | https://factory.com/news/frontier-harness
> [zh] **Factory 发布 Droid 1.0：程序化工具调用成为默认 harness 模式**：不再一轮模型只调一次工具，而是让 agent 在沙箱里写一段 JavaScript，单次请求可跑上百次工具调用。Factory 的 Linear 清理演示：312 次工具调用用 2 次请求、约 6.1 万 token，相对逐次调用估约 36 次请求、310 万 token；Terminal-Bench 4 上自称相对各模型原生 harness 效率最高约好 20%（如 Opus 5.5：65.2% vs Claude Code 57.6%）。模型无关；Script 模式对 GPT-6.1 Sol、Opus 5.5、Fable 等默认开启。1200 赞、1000 收藏。
