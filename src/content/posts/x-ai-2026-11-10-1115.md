## 有趣用法和干货
1. **Alex Albert's one prompt to run on every project whenever a new model ships**: "Read this entire project and find everything that's broken, inconsistent, inefficient, or no longer needed. Fix what you're sure about and list the rest for me to review." ~9.7k bookmarks. https://x.com/alexalbert__/status/2119884951550386671
> [zh] **Alex Albert：每次出新模型都在所有项目上跑的一句提示词**：「读完整个项目，找出所有坏掉的、不一致的、低效的或不再需要的东西。有把握的直接修，其余列给我审。」约 9.7k 收藏。
2. **Vox: have Fable 5.2 audit your Claude Code setup against Anthropic's model-choice guide**: Anthropic's new guide says start on Opus 5.5 at medium effort, use Sonnet 5.5 for scoped work and Fable 5.2 for big refactors and leading subagents; Vox notes the built-in Explore subagent now runs on your main model, so define your own Explore with `model: haiku`, and shares a full review prompt that checks subagent models, effort levels and whether CLAUDE.md says how to verify work. https://x.com/Voxyz_ai/status/2119943123250078141 | https://claude.dev/blog/which-claude-model-should-you-build-with
> [zh] **Vox：让 Fable 5.2 按 Anthropic 选模型指南体检你的 Claude Code 配置**：官方新指南建议多数工作先用 Opus 5.5 + medium，明确范围的活用 Sonnet 5.5，大重构和带多个子 Agent 用 Fable 5.2；Vox 提醒内置 Explore 子 Agent 现在跟随主模型，建议自定义一个 `model: haiku` 的 Explore，并给出完整体检提示词（查子 Agent 模型、effort 档位、CLAUDE.md 是否写明如何验证）。
3. **Matt Pocock: when an agent grills you on a plan, explain the why, not the what**: describing your proposed solution makes the agent assume it is settled and only quiz implementation; describing the problem ("admins can't see an overview of important data") gives it room to be creative and leads to a deeper conversation. https://x.com/mattpocockuk/status/2119888414736859356
> [zh] **Matt Pocock：让 Agent 追问需求时，讲「为什么」而不是「做什么」**：一上来给出方案，Agent 会默认方向已定、只追问实现细节；改为描述问题（「管理员看不到重要数据的总览」），它才有空间提出更好的方案，对话也更深入。
4. **数字生命卡兹克实测 Claude Fable 5.2：审美与细节明显领先**：长文实测前端、视频动效等场景，并用 Fable 5.2 给 ChatGPT 四周年做了庆生视频，认为节奏和动效细节强于以往模型；Gorden Sun 也称 Fable 5.2 medium 强过 Opus 5.5 high 且更省额度。https://x.com/Khazix0918/status/2119941585538572390 | https://x.com/Khazix0918/status/2119902325460590834 | https://x.com/Gorden_Sun/status/2119949499594666389
> [en] **Khazix hands-on with Claude Fable 5.2: clear lead in taste and detail**: long-form tests across front-end and motion/video work, including a ChatGPT 4th-birthday video made with Fable 5.2, praising pacing and animation detail; Gorden Sun adds that Fable 5.2 at medium beats Opus 5.5 at high while using less quota.
