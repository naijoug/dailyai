## 新产品
1. **Unkernel**: a real Linux 7.x kernel compiled into a single WebAssembly module with a real MMU, from UnJS creator Pooya Parsa; open a page and you get a shell, package manager, persistent ext4 disk, networking and sound running entirely on your device. The kernel (syscalls, scheduler, memory, ext4, TCP/IP) is compiled rather than emulated and only user programs are emulated as unmodified arm64 binaries, so Alpine and Debian packages run as-is; it reaches `/init` about 70 ms after start, fork+exit+wait takes about 60 µs versus 1.2 ms under qemu-system, and a JIT compiles hot aarch64 code to wasm. On HN (389 points) commenters ran concurrent md5sums and installed Chromium inside it, called it “buttery smooth” on phones, and noted iOS needs version 27 for JSPI. https://unkernel.dev https://github.com/pithings/unkernel https://news.ycombinator.com/item?id=50674218
> [zh] **Unkernel**：把真正的 Linux 7.x 内核编译成单个 WebAssembly 模块、带真实 MMU，作者是 UnJS 作者 Pooya Parsa；打开网页就有 shell、包管理器、持久化 ext4 磁盘、网络和声音，全部在本机运行。内核（系统调用、调度、内存、ext4、TCP/IP）是编译而非模拟的，只有用户程序以未修改的 arm64 二进制方式模拟，所以 Alpine、Debian 的包可直接跑；启动约 70 毫秒到达 `/init`，fork+exit+wait 约 60 微秒（qemu-system 下约 1.2 毫秒），还有把热点 aarch64 代码编译成 wasm 的 JIT。HN（389 分）上有人并发跑 md5sum、在里面装 Chromium，称手机上也「丝滑」，也有人指出 iOS 需要 27 版才支持 JSPI。
2. **Fleetlayer**: a source-available control plane plus node binary that links the Claude Code and Codex sessions on your laptop, home server and VPS across all your accounts. Agents can message each other (`fleetlayer msg send --to api@laptop`), use the signed-in Chrome on your Mac via Playwright MCP from any machine, reach files like your Downloads folder, publish pages and apps behind one sign-in when claude.ai artifacts would say “access denied”, and see every account’s remaining usage; it also routes webhooks to agents and adds SSO, access rules, approvals and audit logs. The Show HN author built it after running many parallel Claude subscriptions; commenters asked whether agents can delegate work across machines and why it is not fully open source. https://fleetlayer.ai/ https://news.ycombinator.com/item?id=50675831
> [zh] **Fleetlayer**：源码可见的控制面加节点程序，把你笔记本、家用服务器和 VPS 上、不同账号下的 Claude Code 与 Codex 会话连成一张网。Agent 之间可以互发消息（`fleetlayer msg send --to api@laptop`），任何机器上的 Agent 都能通过 Playwright MCP 使用你 Mac 上已登录的 Chrome、访问「下载」等文件夹；claude.ai artifacts 因账号不对显示「access denied」时，可以把页面和应用发布在统一登录之后；每个会话都能看到各账号剩余额度，还支持把 webhook 路由给 Agent、单点登录、访问规则、审批和审计日志。Show HN 作者是在并行开多个 Claude 订阅后做的；评论区有人问能否跨机器委派任务并拿回结果，也有人质疑为何不完全开源。
3. **Voicehook**: a voice room for talking to your coding agent while it builds: you brief Claude Code by speaking, say a bugfix and watch it land, and answer the agent’s decisions by voice while it keeps working, with a status board showing which agent is waiting on you. It works with Claude Code, Codex, Cursor and any agent that speaks MCP, and offers some free call minutes per day. https://voicehook.ai/ https://news.ycombinator.com/item?id=50676154
> [zh] **Voicehook**：一边让编程 Agent 干活一边和它语音对话的「语音房间」：开口给 Claude Code 布置任务、口述 bug 修复并看着它改好，Agent 需要拍板时直接用语音回答而它不中断工作，状态面板显示哪个 Agent 在等你。支持 Claude Code、Codex、Cursor 以及任何支持 MCP 的 Agent，每天有一定免费通话分钟。
4. **google-trends-for-agent**：V2EX 楼主开源（MIT）的 pytrends 替代品，可当 CLI 用，也做成了 MCP 和 DeepSeek Harness 桌面插件，Claude Code、Cursor、Codex 都能直接接，方便在 Agent 工作流里自动选词。它用公开的 59 个 Google Ads 锚点把 Trends 的 0–100 相对指数实时换算成近似真实日搜量（楼主实测 gemini 4 carbon 美区约 1.8 万次/天）；默认本机 IP 直连免费不限次，撞 429 时可切到开源公共 Actor 或自部署同一套代码。一行体验：`npx -y -p google-trends-for-agent gtfa snapshot "gemini 4 carbon" --geo US --json --pretty`。https://meka.im/google-trends-for-agent https://www.v2ex.com/t/1260534 https://github.com/meka-im/google-trends-for-agent
> [en] **google-trends-for-agent**: an MIT-licensed pytrends replacement released on V2EX that runs as a CLI, an MCP server or a DeepSeek Harness desktop plugin, so Claude Code, Cursor and Codex can use it for automated keyword research. It converts Trends’ 0–100 relative index into approximate real daily search volume using 59 published Google Ads anchors (the author measured “gemini 4 carbon” at about 18,000 US searches a day); local-IP use is free and unlimited, and when you hit 429s you can switch to an open-source public Actor or self-host the same code. Try it with `npx -y -p google-trends-for-agent gtfa snapshot "gemini 4 carbon" --geo US --json --pretty`.

Free for 3 days, then $3.49 a month or $35 a year. https://www.semantic-zoom.com/ https://news.ycombinator.com/item?id=50676102

## 科技新闻
1. **Hackers breached Hex.pm, the main package manager for Erlang and Elixir, through a 10/10 zero-day**: per Risky Business, an attacker exploited an untrusted-deserialization flaw (CVE-2026-129514) on November 23 to take over six of Hex.pm’s backend servers; the team says it deployed a fix within 20 minutes of detection and found no unauthorized changes to any package, but cannot rule out that user data was collected because database reads were not logged. Hex has rotated all backend credentials and asks developers to change passwords, reset 2FA and update their Hex clients for the new backend and signing keys; CISA and ENISA were notified. https://risky.biz/risky-bulletin-hackers-breach-erlang-and-elixir-package-manager/ https://news.ycombinator.com/item?id=50674376
> [zh] **Erlang/Elixir 最主要的包管理器 Hex.pm 被黑客利用 10 分零日漏洞入侵**：据 Risky Business 报道，攻击者 11 月 23 日利用一个不可信反序列化漏洞（CVE-2026-129514）接管了 Hex.pm 的 6 台后端服务器；团队称发现后 20 分钟内上线修复，检查后未发现任何包被篡改，但由于没有记录数据库读取，无法排除用户数据被窃取。Hex 已轮换所有后端凭据，要求开发者修改密码、重置两步验证并升级 Hex 客户端以适配新后端和签名密钥，并已通报美国 CISA 和欧盟 ENISA。
2. **Donald Knuth pauses error reports because LLM-assisted readers are flooding him**: on a new “Moratorium” page he writes that “the rise of LLMs has increased the productivity of my readers so greatly that error reports are now being submitted much faster than I can read them”, that random sampling shows most recent reports repeat issues already submitted, and that he will not look at reports sent after November 25 until he posts updated errata for each book. On HN (167 points) readers mourned the likely end of his famous reward cheques and called it another thing “ruined by LLMs”, since Knuth could run an LLM over his own books if he wanted. https://www-cs-faculty.stanford.edu/~knuth/moratorium.html https://news.ycombinator.com/item?id=50674452
> [zh] **高德纳因读者借助 LLM 狂发勘误，宣布暂停接收错误报告**：他在新页面「Moratorium」上写道，LLM 让读者的效率大增，错误报告提交得远比他读得快；随机抽查显示近期大部分报告是别人已经报过的重复问题，因此 11 月 25 日之后提交的报告，他要等每本书更新已知勘误列表后才会看。HN（167 分）上读者惋惜他著名的奖励支票可能就此成为历史，也有人说这又是一件「被 LLM 毁掉」的事——高德纳真想要的话完全可以自己用 LLM 过一遍书。
3. **Heretic’s author archives the censorship-removal tool and says farewell**: Philipp Emanuel Weidmann (p-e-w) archived Heretic, his open-source tool for automatically removing refusals from language models, writing that “my journey has now come to an end”; he deliberately named no successor and asked contributors to organize elsewhere, arguing that controlling the models you use “gradually transforms from an issue of Free Speech into an issue of Free Thought”. HN commenters shared a community Discord for a fork and argued over whether unrestricted open-weight models are needed as closed models refuse more. https://github.com/p-e-w/heretic/issues/601 https://news.ycombinator.com/item?id=50676672
> [zh] **去审查工具 Heretic 作者归档项目并告别**：Philipp Emanuel Weidmann（p-e-w）把他自动去除语言模型拒答的开源工具 Heretic 设为只读，写道「我的旅程到此结束」；他刻意不指定继任者，请贡献者自行组织，并认为控制自己所用的模型「正逐渐从言论自由问题变成思想自由问题」。HN 评论区有人贴出社区 Discord 组织分叉，也有人争论在闭源模型拒答越来越多的情况下，是否更需要不设限的开源权重模型。
4. **Pi coding agent gets a draft “Google AI plan” provider**: a 13-commit draft PR in earendil-works/pi adds sign-in with Google (loopback OAuth with PKCE and DPoP-bound refresh tokens) so the plan’s Gemini models run through the Interactions API, with streaming, signed thought replay, tool calls and plan-specific errors such as daily limits, defaulting to gemini-4-hydrogen; forks must register their own Google OAuth client. HN commenters (posted as “Google adding official support”) noted the code targets the Ultra plan only and asked why Pi specifically. https://github.com/earendil-works/pi/pull/12614 https://news.ycombinator.com/item?id=50675069
> [zh] **编程 Agent Pi 出现「Google AI 套餐」接入草稿 PR**：earendil-works/pi 的一个 13 次提交的草稿 PR 加入了 Google 登录（回环 OAuth + PKCE，刷新令牌绑定 DPoP），让套餐里的 Gemini 模型通过 Interactions API 调用，支持流式输出、带签名的思考回放、工具调用以及每日上限等套餐专属错误，默认模型为 gemini-4-hydrogen；分叉版需自行注册 Google OAuth 客户端。HN 上（标题称谷歌官方加入支持）有人指出代码只面向 Ultra 套餐，也有人好奇为什么偏偏是 Pi。
5. **IT之家：美国多个学区屏蔽谷歌 AI 功能，并考虑弃用谷歌产品**：据美联社报道，洛杉矶学区已在学校配发的设备上静默禁用谷歌搜索的 AI 概览；谷歌 11 月初说将对 K-12 学校默认关闭 Gemini 和搜索中的 AI 工具，但不提供彻底关掉 AI 的选项，此前数百名谷歌员工请愿要求允许学校使用不含 AI 的搜索。洛杉矶学区 CIO 表示「几乎可以在一夜之间更换默认搜索引擎」，纽约、芝加哥等学区也在评估替代方案。https://www.ithome.com/1/033/977.htm
> [en] **IT Home: several US school districts block Google’s AI features and weigh dropping Google**: per the AP, Los Angeles schools have quietly disabled Search’s AI Overviews on school-issued devices; Google said in early November it would turn off Gemini and Search AI tools by default for K-12 but offers no way to switch AI off entirely, after hundreds of Google employees petitioned for AI-free Search for schools. LA’s CIO said the district could change its default search engine “almost overnight”, and New York, Chicago and others are evaluating alternatives.

> [en] **V2EX: Page Agent Lite, an open-source browser agent extension that remembers experience, inspired by Hermes**: tired of copying online quiz questions into Doubao, the poster tried tools like Alibaba’s Page Agent and then wrote a Chrome/Edge extension: describe the task in a side panel and it reads the page, fills forms, clicks and paginates, and you can add instructions or pause and take over mid-run; borrowing from Hermes it reviews each finished task and stores useful experience and steps locally for next time (no training, just reusable notes).
