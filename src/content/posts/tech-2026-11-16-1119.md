## 新产品
1. **Mount Thor**: a cloud provider that rents macOS on Apple silicon as elastic compute for AI agents, from bare-metal Macs (SSH or virtual desktop, physical isolation) to VMs on its own Apple-native virtualization that provision in seconds, with more Macs allocated by one API call. Its announcement lists computer-use RL environments for research labs, secure macOS sandboxes for agent platforms, macOS instances that run for weeks so an agent can work across a user’s devices under one Apple identity, build and test farms for Apple software, and cheaper open-model inference on Apple silicon. It raised $45M across Seed and Series A (Series A co-led by CRV and Conviction; angels from Cognition, Daytona, Meta, OpenAI, Together AI and Vercel), said it deployed its first data center in under six months, and plans to build an inference lab for open-source models on Apple silicon; the round surfaced on Techmeme in this window (company announcement dated 12 Nov). https://mountthor.com/ | https://blog.mountthor.com/a | https://www.techmeme.com/261115/p23#a261115p23
> [zh] **Mount Thor**：把苹果芯片上的 macOS 当作弹性算力出租给 AI Agent 的云服务，既有裸金属 Mac（SSH 或虚拟桌面、物理隔离），也有基于自研苹果原生虚拟化、几秒开好的虚拟机，一次 API 调用就能加机器。公告列出的用途包括：给研究实验室做电脑操作强化学习环境、给 Agent 平台提供安全的 macOS 沙盒、让 macOS 实例连跑数周以便 Agent 用同一个 Apple 身份在用户各设备间干活、苹果软件的构建测试机群，以及在苹果芯片上用开源模型降低推理成本。公司完成种子轮和 A 轮共 4500 万美元融资（A 轮由 CRV 和 Conviction 联合领投，天使投资人来自 Cognition、Daytona、Meta、OpenAI、Together AI 和 Vercel），称首个数据中心不到六个月建成，下一步要建苹果芯片上的开源模型推理实验室；这轮融资在本时段登上 Techmeme（公司公告日期为 11 月 12 日）。
2. **db-branch**: self-hosted, Apache-2.0 tool that creates copy-on-write branches of MySQL and PostgreSQL databases on ZFS clones in seconds, with nothing copied at creation, so you can test a migration, give every PR its own database (auto-removed via `--ttl`), or “let an AI agent loose.” A built-in MCP server lets an agent create a branch, run a risky query or migration on it and delete it without touching production. The README (status: beta) reports a PostgreSQL branch in about 0.5 s and MySQL in about 3 s on the authors’ 3-node test cluster, plus a `branch upgrade --check-only` mode for major-version upgrades; some history features are paid modules. Its Show HN post had 35 points and 10 comments in this window; commenters asked whether it uses Postgres 18’s `file_copy_method = clone` and whether branch changes can be merged back, and one compared it with Database Lab. https://github.com/db-branch/db-branch | https://demo.db-branch.com/ | https://news.ycombinator.com/item?id=50506940
> [zh] **db-branch**：自托管、Apache-2.0 许可的工具，基于 ZFS 克隆在几秒内给 MySQL 和 PostgreSQL 数据库建写时复制分支，创建时不拷贝数据，可用来试迁移、给每个 PR 一份独立数据库（用 `--ttl` 自动清理），或者「放手让 AI Agent 折腾」。内置 MCP 服务器，Agent 可以自己建分支、在分支上跑危险查询或迁移再删掉，不碰生产库。README（标注 beta）写在作者的 3 节点测试集群上，PostgreSQL 分支约 0.5 秒、MySQL 约 3 秒可用，并提供 `branch upgrade --check-only` 用于大版本升级预检；部分历史功能属于付费模块。本时段 Show HN 帖有 35 分、10 条评论，有人问是否用了 Postgres 18 的 `file_copy_method = clone`、分支改动能否合并回主库，也有人拿它和 Database Lab 比较。
3. **NVIDIA SkillEvaluator**: an Apache-2.0 framework from NVIDIA for checking agent skills (folders defined by the Agent Skills spec) and measuring whether they actually change task results: it starts with deterministic quality checks that need no API key (`skillevaluator validate ./my-skill --tiers 1`), then compares agent runs with and without a skill, and adds semantic-overlap detection and synthetic eval-set generation. It can open a CI setup PR (`skillevaluator ci init`) or be added to Claude Code or Codex as a skill (`npx skills add NVIDIA/SkillEvaluator`), and is part of NVIDIA’s Verified Skills pipeline with docs, a paper and a developer blog post. It was on GitHub Trending today (about 1,800 stars, 122 today). https://docs.nvidia.com/skills/skillevaluator/ | https://github.com/NVIDIA/SkillEvaluator
> [zh] **NVIDIA SkillEvaluator**：英伟达开源（Apache-2.0）的 Agent Skill 评测框架，用来检查遵循 Agent Skills 规范的技能包，并衡量它们到底有没有改变任务结果：先做不需要 API key 的确定性质量检查（`skillevaluator validate ./my-skill --tiers 1`），再对比装和不装某个技能时的 Agent 运行结果，另有语义重叠检测和合成评测集生成。可以一键开一个 CI 配置 PR（`skillevaluator ci init`），也能作为技能装进 Claude Code 或 Codex（`npx skills add NVIDIA/SkillEvaluator`）；它属于英伟达 Verified Skills 流程，配有文档、论文和开发者博客。今天上了 GitHub Trending（约 1,800 star，当日 +122）。
