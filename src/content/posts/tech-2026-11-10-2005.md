Lessons: run a BEDROCK/DUAL/DECIDER switch on real traffic, and sort JSON keys — key order moved probabilities by up to 0.19. https://strandsagents.com/blog/amazon-saves-millions-replacing-sonnet-with-strands-decider/ | https://news.ycombinator.com/item?id=50436640

## 科技新闻
1. **Fireworks AI's second breach in weeks reaches Notion AI chats**: Fireworks says hackers accessed some customers' datasets, incomplete model weights and billing info over the past month; Notion says <1% of workspaces may be affected, through unattributable Notion AI chat transcripts used for its Insights feature (no tool-call results, no workspace or user labels). Notion disconnected Fireworks on Nov 3, disabled Insights, stopped serving open-weight models there, and advises rotating any credentials pasted into Notion AI; Bloomberg reports Fireworks is also working with Cursor and other customers. https://www.notion.com/help/security-incident-involving-a-third-party-ai-vendor | https://news.ycombinator.com/item?id=50437106 | https://www.techmeme.com/261110/p14
> [zh] **Fireworks AI 数周内第二次被黑，波及 Notion AI 对话**：Fireworks 称过去一个月黑客取得了部分客户数据集、不完整的模型权重和账单信息；Notion 表示不到 1% 的工作区可能受影响，泄露的是用于 Insights 功能、无法归属到人和工作区的 Notion AI 对话记录（不含工具调用结果）。Notion 已于 11 月 3 日断开 Fireworks、停用 Insights、不再经其提供开源权重模型，并建议轮换曾粘贴进 Notion AI 的凭据；彭博称 Fireworks 也在与 Cursor 等客户处理此事。
2. **Claude Code's "don't ask again" rules are leaking secrets onto GitHub**: approved commands are written verbatim into `.claude/settings.local.json`; Apiiro found 100,000+ such files in public repos, ~1,100 of them from 63 orgs holding database passwords, API tokens or private keys, and 215 of those secrets slipped past gitleaks and TruffleHog. The file is in the global `.gitignore`, not the repo's, so clones or new repos can commit it — sometimes Claude Code itself does. Boris Cherny says the team is looking into fixes, suggests auto mode and secret scanners, and is considering built-in scanning. https://arstechnica.com/ai/2026/11/claude-code-settings-files-expose-thousands-of-secrets-on-github/
> [zh] **Claude Code 的「不再询问」规则把密钥泄露到 GitHub**：批准过的命令会原样写进 `.claude/settings.local.json`；Apiiro 在公开仓库里发现 10 万多个此类文件，其中约 1100 个（来自 63 个组织）含数据库密码、API token 或私钥，有 215 个密钥 gitleaks 和 TruffleHog 都没扫出来。该文件只在全局 `.gitignore` 而不在仓库级别，克隆到别处或目录后来变成仓库时就可能被提交，有时还是 Claude Code 自己提交的。Boris Cherny 表示团队正在研究修复，建议用 auto mode 和密钥扫描工具，并考虑内置扫描。
3. **Google DeepMind's AlphaProof Code formally verifies the Signal protocol**: researchers used the agentic framework to verify Signal's cryptographic guarantees in a four-week proof of concept (Wired). https://www.techmeme.com/261110/p14#a261110p14
> [zh] **Google DeepMind 用 AlphaProof Code 形式化验证 Signal 协议**：研究人员用这一 Agent 框架在四周的概念验证中证明了 Signal 的密码学保证（据 Wired）。
4. **Meituan releases LongCat-2.5 weights under MIT**: the 1.6T-parameter MoE (~48B active), natively multimodal and built for long-horizon agentic work, was unveiled Nov 1 and now ships on Hugging Face; the model card adds W4A4 INT4 quantization tuned for domestic Chinese accelerators. Early users praise long-horizon tasks but complain about overthinking and speed. https://www.techmeme.com/261110/p5#a261110p5 | https://x.com/Meituan_LongCat
> [zh] **美团以 MIT 许可开源 LongCat-2.5 权重**：这款 1.6T 参数 MoE（约 48B 激活）、原生多模态、面向长程 Agent 任务的模型于 11 月 1 日发布，现已上架 Hugging Face；模型卡还提供针对国产加速卡调优的 W4A4 INT4 量化。早期用户肯定其长程任务表现，也吐槽过度思考和速度慢。
