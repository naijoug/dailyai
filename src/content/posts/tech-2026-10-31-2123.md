## 新产品
1. **T3 Code: open-source control plane for the coding agents already on your machine**: drives Claude Code, Codex, Cursor CLI, Grok Build, OpenCode and Google Antigravity through a mobile app (iOS/Android), web app and Electron desktop; free and open-sourced by the Ping/t3 team so you can fork if the product drifts, and it only needs one of those CLIs authenticated locally. https://t3.codes/ [GitHub](https://github.com/pingdotgg/t3code)
> [zh] **T3 Code：开源的编程 Agent 控制面，接管你本机已装好的那些**：经手机 App（iOS/Android）、网页和 Electron 桌面去驱动 Claude Code、Codex、Cursor CLI、Grok Build、OpenCode 与 Google Antigravity；由 Ping/t3 团队开源免费，产品跑偏了也能自己 fork，只要本机已登录其中一个 CLI。
2. **Orkas: a local-first, open-source AI team on your desktop**: tell the Commander what you need and it finishes small jobs alone or plans bigger work with specialist agents plus the coding agents you already use (Claude Code, Codex, OpenCode, OpenClaw, Hermes-Agent); projects keep goals, rules, memory and files across chats, with to-dos, auto-advance and scheduled automations; MIT, macOS/Windows builds, 500 free credits for the built-in model so you can start without an API key. https://orkas.ai/ [GitHub](https://github.com/Orkas-AI/Orkas)
> [zh] **Orkas：本地优先的开源桌面 AI 团队**：跟 Commander 说目标，小事它自己做完，大事则拆步骤并拉上专长 Agent，以及你已在用的 Claude Code、Codex、OpenCode、OpenClaw、Hermes-Agent；项目里保留目标、规则、记忆和文件，带待办、自动推进和定时自动化；MIT，提供 macOS/Windows 安装包，内置模型送 500 积分，可不带 API Key 起步。
3. **Lightpanda: a headless browser written in Zig for AI agents and automation**: not a Chromium or WebKit fork; claims ~16× less peak memory and ~9× faster than headless Chrome on a 100-page crawl (123 MB / 5 s vs 2 GB / 46 s on an EC2 m5.large), with a CDP-compatible path so existing agent tooling can plug in; Homebrew nightly and GitHub releases, today on GitHub Trending. https://lightpanda.io/ [GitHub](https://github.com/lightpanda-io/browser)
> [zh] **Lightpanda：用 Zig 从零写的、面向 AI Agent 与自动化的无头浏览器**：不是 Chromium/WebKit 分支；在 EC2 m5.large 上爬 100 页自称峰值内存约少 16 倍、速度快约 9 倍（123 MB / 5 秒 vs 无头 Chrome 的 2 GB / 46 秒），并提供 CDP 兼容路径方便现有 Agent 工具接入；有 Homebrew nightly 与 GitHub 发行版，今天上了 GitHub Trending。
4. **Imza: a plan → build → review coding agent that keeps you reading the code**: Plan mode is read-only and produces a Markdown spec you revise with pinned notes; Build streams every edit as a live diff against that approved plan; Review drops the whole change into a review UI so findings go back into the next plan revision—aimed at stopping “summary-driven” agent use. Native/local, no telemetry; site and wiki at imza.run. https://imza.run/ [GitHub](https://github.com/umutsevdi/imza) [HN](https://news.ycombinator.com/item?id=50314538)
> [zh] **Imza：Plan → Build → Review 的编程 Agent，逼你继续读代码**：Plan 只读仓库并产出可带批注修订的 Markdown 规格；Build 按已批准规格实施，每个改动以实时 diff 流出；Review 把整次变更放进评审界面，意见再回流成下一版计划——针对「只看摘要」式用 Agent。本地原生、无遥测；站点和 wiki 在 imza.run。
5. **OpenMAIC: one-click multi-agent interactive classroom**: open-source (MIT) immersive lesson UI from THU-MAIC with a live demo, JCST'26 paper, OpenClaw integration and Lemonade local-AI path; ships agent workbench hooks so coding agents can help assemble the classroom. https://open.maic.chat/ [GitHub](https://github.com/THU-MAIC/OpenMAIC)
> [zh] **OpenMAIC：一键生成的多智能体沉浸式课堂**：清华 MAIC 团队开源（MIT）的互动课堂界面，有在线 Demo、JCST'26 论文，并接 OpenClaw 与 Lemonade 本地模型；带 Agent 工作台钩子，方便编程 Agent 协助搭课。

## 科技新闻
1. **Parameter.ai took over ChatGPT accounts via a public share link**: a conversation with an HTML Preview plus a MathLive graph could break out of the sandbox into the victim's signed-in `chatgpt.com` session—enumerate private chats, read never-shared threads and call authenticated APIs—just by opening the share; no app install or paste required. OpenAI fixed it Oct 26 as P1; the write-up hit HN today (77 points). https://www.parameter.ai/labs/we-found-a-gap-at-openai [HN](https://news.ycombinator.com/item?id=50314699)
> [zh] **Parameter.ai 靠一条公开分享链接接管了 ChatGPT 账号**：对话里的 HTML Preview 加上 MathLive 图表可逃出沙箱，进入受害者已登录的 `chatgpt.com` 会话——枚举私密对话、读取从未分享过的线程并调用已认证 API——打开分享链接即可，无需装 App 或粘贴代码。OpenAI 于 10 月 26 日按 P1 修复；报告今天上了 HN（77 分）。
2. **npm `open` PowerShell injection lets malicious MCP servers run code on Windows/WSL**: CVE-2026-119025 — `open` 7.2.0–10.x put the URL unescaped inside a PowerShell double-quoted string so `$(...)` ran; OpenCode 1.0.137–1.18.32 (fixed 1.18.33) and MCP Inspector 2.0.0–2.11.0 (fixed 2.12.0) were named, and a hijacked remote MCP OAuth URL is enough at connect/sign-in time. `open` 11.0.0 escapes correctly; macOS/Linux unaffected; VulnCheck High (CVSS 4.0 7.7). https://pwn.watch/i/opencode-mcp-oauth-rce-windows
> [zh] **npm `open` 的 PowerShell 注入让恶意 MCP 服务器能在 Windows/WSL 上执行代码**：CVE-2026-119025——`open` 7.2.0–10.x 把 URL 未转义塞进 PowerShell 双引号字符串，`$(...)` 会被执行；点名受影响的有 OpenCode 1.0.137–1.18.32（1.18.33 已修）和 MCP Inspector 2.0.0–2.11.0（2.12.0 已修），连上被劫持的远程 MCP OAuth URL 就够。`open` 11.0.0 已正确转义；macOS/Linux 不受影响；VulnCheck 评 High（CVSS 4.0 7.7）。
3. **Node2Shell / HTTP2Shell: critical Brotli RCE across Node.js, Envoy, Istio and more**: CVE-2026-111497 is an out-of-bounds write in the Brotli decoder—Express 5 / body-parser 2.x with `Content-Encoding: br`, `fetch()` of Brotli responses, or `node:zlib` on untrusted input can yield code execution; fixed in Node 26.12.1 / 24.22.1 / 22.23.4 (EOL lines unpatched), Envoy 1.40.0+ line, Istio 1.29.9+, and downstream .NET/PHP Windows builds. OpenAI Codex Security reported the Node issue; NVD CVSS 4.0 9.2. https://pwn.watch/i/nodejs-october-2026-security-releases
> [zh] **Node2Shell / HTTP2Shell：Brotli 解码器致命 RCE，波及 Node.js、Envoy、Istio 等**：CVE-2026-111497 是 Brotli 解码越界写——Express 5 / body-parser 2.x 带 `Content-Encoding: br` 的请求体、`fetch()` 拉 Brotli 响应、或对不信任输入用 `node:zlib`，都可能直接执行代码；已在 Node 26.12.1 / 24.22.1 / 22.23.4（EOL 线无补丁）、Envoy 1.40.0 一线、Istio 1.29.9+ 以及下游 .NET/PHP Windows 构建中修复。由 OpenAI Codex Security 报告 Node 侧问题；NVD CVSS 4.0 9.2。
4. **Scribd notifies users after a breach touching Scribd, Slideshare, Everand and Fable**: email plus last-4 / issuer / expiry of cards and payment history (not full PAN); Tell HN thread today at 263 points with the full notice text, and users are warned to watch for phishing. https://news.ycombinator.com/item?id=50312756
> [zh] **Scribd 通报安全事件，波及 Scribd、Slideshare、Everand 与 Fable**：可能泄露邮箱以及银行卡后四位、发卡行、有效期和支付历史（非完整卡号）；今天的 Tell HN 帖（263 分）贴出完整通知原文，并提醒警惕钓鱼。
5. **Blackstone tells investors Anthropic may get a high junk rating after IPO**: FT reporting (via IT之家) says ratings agencies are more likely to assign a high speculative-grade rating than investment grade after the planned listing, complicating financing for Anthropic's large compute spend; the firm is still aiming at what could be the largest IPO on record. https://www.ithome.com/1/020/610.htm
> [en] **Blackstone tells investors Anthropic may get a high junk rating after IPO**: per the FT (via IT之家), ratings agencies are likelier to give a high speculative-grade mark than investment grade after the planned listing, making it harder to fund Anthropic's heavy compute spend; the company is still aiming at what could be the largest IPO on record.
