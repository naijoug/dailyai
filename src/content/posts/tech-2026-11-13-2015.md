## 新产品
1. **Open Code Review (Alibaba)**: an AI code review CLI that started as Alibaba's internal official review assistant, used by tens of thousands of developers over two years. It pairs deterministic engineering (exact file selection, bundling related files into isolated sub-agent units, template-matched rules, separate comment-positioning and reflection modules) with an agent for dynamic context lookup, and leaves line-level comments; on its 200-PR AACR-Bench it reports higher precision and F1 than Claude Code on the same model at about 1/9 of the tokens, with deliberately lower recall. Works with OpenAI- and Anthropic-compatible APIs; ~50k GitHub stars and on GitHub Trending today. https://open-codereview.ai | https://github.com/alibaba/open-code-review
> [zh] **Open Code Review（阿里巴巴）**：一款 AI 代码评审命令行工具，前身是阿里内部官方评审助手，两年里服务了数万名开发者。它把确定性工程（精确选文件、把相关文件打包成上下文隔离的子 Agent 单元、模板匹配规则、独立的评论定位和反思模块）和负责动态检索上下文的 Agent 结合起来，给出行级评论；在 200 个 PR 的 AACR-Bench 上，同模型下精确率和 F1 高于 Claude Code、token 只用约九分之一，召回率则有意偏低。兼容 OpenAI 和 Anthropic 接口，GitHub 约 5 万星，今天上了趋势榜。
2. **Codex Security CLI and SDK (OpenAI)**: the open-source `@openai/codex-security` CLI, TypeScript SDK and GitHub Action behind Codex's security workflows. `cs scan .` scans a repo, paths or a diff and saves a report with source evidence; it can validate findings, generate and verify patches, draft `SECURITY.md` and threat models, import third-party scanner results, file issues in Linear, Jira or GitHub, and export SARIF, JSON or CSV. The repo passed ~12.8k stars and is on GitHub Trending today. https://developers.openai.com/codex/security | https://github.com/openai/codex-security
> [zh] **Codex Security 命令行和 SDK（OpenAI）**：Codex 安全工作流背后的开源 `@openai/codex-security` 命令行、TypeScript SDK 和 GitHub Action。`cs scan .` 可扫描整个仓库、指定路径或改动，保存附源码证据的报告；还能验证发现、生成并核验补丁、起草 `SECURITY.md` 和威胁模型、导入第三方扫描结果、在 Linear/Jira/GitHub 建单，导出 SARIF、JSON 或 CSV。仓库约 1.28 万星，今天上了 GitHub 趋势榜。
3. **Plannotator Inbox**: a local, browser-based review layer for agent work. When Claude Code, Codex, Copilot CLI, Gemini CLI, OpenCode, Amp, Pi and others propose a plan or finish a task, Plannotator opens so you can annotate plans, specs, HTML artifacts or diffs and send feedback straight back; the new Inbox is one window where agents and personal assistants leave questions, files and guided reviews without holding a session open, and your reply arrives as their next turn (other agents connect over MCP). ~10k GitHub stars, on GitHub Trending today. https://plannotator.ai | https://github.com/backnotprop/plannotator
> [zh] **Plannotator Inbox**：一个在本地浏览器里运行的 Agent 工作评审层。Claude Code、Codex、Copilot CLI、Gemini CLI、OpenCode、Amp、Pi 等提出计划或完成任务时，它会弹出来让你批注计划、规格、HTML 产物或代码 diff，再把反馈直接发回 Agent；新的 Inbox 是一个统一窗口，Agent 和个人助理可以把问题、文件和引导式评审留在这里，不用一直占着会话，你的回复会作为它们的下一轮输入（其他 Agent 通过 MCP 接入）。GitHub 约 1 万星，今天上了趋势榜。
4. **ArtCraft: 17 open-source Rust apps cloning Photoshop, Acrobat, Figma and more, built mostly by agents**: Latent Space's recap of CEO Brandon Thomas's AI Engineer Code Summit talk. The team gave a model a detailed prompt of Photoshop's tools, data structures and importers, made everything MCP- and CLI-compatible, and had "a pretty good approximation" within 24 hours; PhotoCraft is now about 60% of the way to parity by his estimate, and the apps are downloaded about 1.7 million times a day with ~300 more community apps in progress. His rule of thumb: let humans own backend, schema migrations and API design, and throw agents at desktop apps and games; an autonomous "AutoCraft" software factory will be open-sourced. https://getartcraft.com | https://latent.space/p/artcraft/
> [zh] **ArtCraft：17 款开源 Rust 应用复刻 Photoshop、Acrobat、Figma 等，主要靠 Agent 写成**：Latent Space 整理了 CEO Brandon Thomas 在 AI Engineer Code 大会上的演讲。团队把 Photoshop 的工具、数据结构和导入器写成详细提示交给模型，所有功能都做成 MCP 和 CLI 可调用，24 小时内就有了「相当接近」的版本；他估计 PhotoCraft 目前约达到 60% 的功能对齐，这些应用每天下载约 170 万次，社区还在做约 300 款。他的经验是后端、数据库迁移和 API 设计交给人，桌面应用和游戏放心交给 Agent；完全自主的「AutoCraft」软件工厂也将开源。

2. **Brave Search API now accepts agentic payments via x402 (HN ~130 pts)**: agents can query Brave's independent index with no account or API key. A request without payment gets an HTTP 402 with the price, the agent signs a USDC payment on Base and retries, and results come back with an on-chain receipt; LLM Context (search grounding for agents) and web, news, image, video and local search cost $0.005 per request, gas is covered for a limited time, and Brave suggests Stripe's Purl CLI wallet for the agent. https://brave.com/blog/search-api-agentic-payments/ | https://news.ycombinator.com/item?id=50477649
> [zh] **Brave 搜索 API 支持 Agent 通过 x402 协议按次付费（HN 约 130 分）**：Agent 无需账号和 API Key 就能查询 Brave 的独立索引。未付费的请求会收到带价格的 HTTP 402，Agent 在 Base 链上签一笔 USDC 付款后重试，结果附带链上收据；给 Agent 做检索增强的 LLM Context 以及网页、新闻、图片、视频、本地搜索都是每次 0.005 美元，限时免 gas，Brave 推荐用 Stripe 开发的 Purl 命令行钱包。
