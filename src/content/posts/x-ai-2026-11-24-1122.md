2. **Google DeepMind: teams of Gemini 4 agents found cheaper quantum circuits, each result proved in Lean**: because such circuits cannot be tested on classical computers or today’s small quantum chips, every improvement had to be proved formally. Separate agent teams worked on each problem, ideas entered a shared notebook only after Lean verification, and every four hours the teams met at a “virtual conference” to trade and debate ideas. Results: an inertial-confinement-fusion circuit 11.8x cheaper, with memory cut from 5,650 to 4,338 error-corrected qubits; a common light-sensitive molecule 8x cheaper to simulate; Cytochrome P450 2.5x cheaper (481 → 333 qubits); a 2.57x speedup for one implementation of Grover’s algorithm and 290x for the arcsin routine many algorithms use to load numbers. The Lean library, problem specs and verified solutions are open source. François Chollet: “A 10x reduction in simulation cost is essentially a hardware leap achieved through software.” 3.7k likes. https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/ https://x.com/GoogleDeepMind/status/2124911073266413634 https://x.com/fchollet/status/2124926345948148042
> [zh] **Google DeepMind：Gemini 4 Agent 团队找到更省资源的量子电路，每项结果都用 Lean 证明**：这类电路既没法在经典计算机上、也没法在现有小型量子芯片上测试，所以每个改进都必须做形式化证明。每道题由独立的 Agent 团队攻关，想法先过 Lean 验证才能进入共享笔记本，各队每四小时在「虚拟会议」上交换、辩论想法。成果包括：惯性约束聚变相关电路成本降到 1/11.8，内存从 5650 个纠错量子比特降到 4338 个；一种常见光敏分子的模拟便宜 8 倍；细胞色素 P450 便宜 2.5 倍（481 → 333 个量子比特）；某个 Grover 算法实现提速 2.57 倍，许多算法用来加载数值的 arcsin 例程提速 290 倍。Lean 库、题目规格和已验证的解都已开源。François Chollet 评论：「模拟成本降低 10 倍，本质上是用软件实现了一次硬件飞跃。」3.7k 赞。

## 有趣用法和干货
1. **One sentence that stops agents from obeying stale CLAUDE.md / AGENTS.md rules**: Vox summarizes a paper in which Claude Code and Codex, given a CLAUDE.md that still said “Use print() for progress messages” after the code had moved to logging, noticed the mismatch and used print anyway in 79 of 80 runs across 40 such projects; in 441 company repos, 73.8% of AI config files were committed once and never touched again. Adding this line to the global ~/.claude/CLAUDE.md (or ~/.codex/AGENTS.md) raised agreement with the existing code from 4.2% to 91.4% with all tests passing: “When a repository's documentation and its existing code disagree, follow the conventions used in the existing code, and in your final reply point out each inconsistency you found between the documentation and the code.” He also shares a review prompt that lists outdated rules first and changes nothing until you approve. https://x.com/Voxyz_ai/status/2124880659889938848
> [zh] **一句话让 Agent 不再死守过期的 CLAUDE.md / AGENTS.md**：Vox 转述的一篇论文发现，代码早已改用 logging，CLAUDE.md 却还写着「用 print() 输出进度」，Claude Code 和 Codex 会在回复里指出二者不一致，然后照样用 print——40 个类似项目的 80 次运行里有 79 次如此；在 441 个公司仓库中，73.8% 的 AI 配置文件提交一次后再没改过。把下面这句加进全局 ~/.claude/CLAUDE.md（Codex 用 ~/.codex/AGENTS.md），遵循现有代码的比例从 4.2% 升到 91.4%，测试全部通过：「当仓库文档与现有代码不一致时，遵循现有代码的约定，并在最终回复中逐条指出你发现的文档与代码之间的不一致。」他还给了一段审查提示词：先列出过期规则、经你确认前不改任何文件。
