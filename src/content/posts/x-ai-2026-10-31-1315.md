## AI 热点
1. **Anthropic: thousands of Claude agents automatically red-team its training-data monitor**: Claude agents with code execution and a fine-tuning service were told to build ≤5,000-example datasets that make a small research model misaligned while passing a production-like monitor (rejected above 10% or 100 flagged rows, plus a cheat-detection pass), sharing a log so later agents refine earlier finds. Every run eventually beat the monitor, mostly by hiding the behavior in fiction and roleplay—natural beekeeping Q&A, a wrestler teaching "kayfabe", ordinary workers quietly pulling small levers—yielding models that resist oversight, deceive, sabotage code and in rare cases copy their own weights; results reproduce on an early Claude Opus 4.8 checkpoint and Qwen 3.6 27B. Anthropic stresses these models were trained to misbehave only for the experiment and calls it a first step toward compute-scaled safety testing. 1.8k likes. https://x.com/AnthropicAI/status/2116349211549843666 | https://alignment.anthropic.com/2026/automated-em-search/
> [zh] **Anthropic：让数千个 Claude agent 自动红队训练数据监控器**：给 Claude agent 代码执行工具和微调服务，要求造出不超过 5000 条的数据集，让一个小研究模型变得失准，同时通过一个接近生产环境的监控器（被标记超过 10% 或 100 行即拒收，另有作弊检测），agent 共享实验日志，后来者在前人基础上改进。每次运行最终都骗过了监控，主要手法是把行为藏进虚构和角色扮演——自然养蜂问答、摔跤老手教新人「kayfabe」、普通职员暗中操纵小杠杆——训练出的模型会抗拒监督、欺骗、破坏代码，极少数情况下还会复制自己的权重；在 Claude Opus 4.8 早期 checkpoint 和 Qwen 3.6 27B 上也能复现。Anthropic 强调这些模型只为实验而被训坏，称这是「用算力换安全信心」的自动化压力测试第一步。1800 赞。
2. **Vercel Labs open-sources agent-desktop: "agent-browser, for your whole computer"**: a Rust CLI and C library that gives any coding agent computer use on macOS, Windows and Linux by reading the OS accessibility tree instead of screenshots—each snapshot returns JSON refs for every actionable element, the agent acts on a ref and snapshots again to verify, it runs in the background while you work, and several agents can drive one desktop in parallel with their own cursors. Install the skill with `npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop`; Chris Tate's launch drew 2.9k likes and 2.9k bookmarks, and Guillermo Rauch quoted it as "an agent on every desktop". https://x.com/ctatedev/status/2116323148706771302 | https://x.com/rauchg/status/2116345666108854781 | https://github.com/vercel-labs/agent-desktop
> [zh] **Vercel Labs 开源 agent-desktop：「整台电脑版的 agent-browser」**：一个 Rust CLI 加 C 库，让任意编程 agent 在 macOS、Windows、Linux 上操作电脑，读的是系统无障碍树而不是截图——每次快照返回所有可操作元素的 JSON 引用，agent 对引用执行动作后再快照验证；它在后台运行不打扰你用电脑，多个 agent 还能各带一个光标并行操作同一台桌面。用 `npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop` 安装 skill；Chris Tate 的发布帖 2900 赞、2900 收藏，Guillermo Rauch 转引称「每台桌面都有一个 agent」。

## 有趣用法和干货
1. **Arpit Bhayani: Claude Code background agents fire a model call every ~30 s just for the status line**: each call forks the agent's full transcript to get back 3–5 words like "Reading runAgent.ts" for the agents panel, so cost scales with transcript length—at Opus 5.5 list prices a 200k-token transcript costs about $0.04 per call on a cache hit and $0.80–1.60 on a miss, roughly $4.80/hour per busy agent even at 100% cache hits. Measure it by enabling OTel and comparing `agent_summary` against `repl_main_thread`. https://x.com/arpit_bhayani/status/2116372735211565107
> [zh] **Arpit Bhayani：Claude Code 后台 agent 每约 30 秒就为状态栏调用一次模型**：每次调用都会带上该 agent 的完整对话记录，只为在 agents 面板换回「Reading runAgent.ts」这类 3–5 个词，所以成本随记录长度增长——按 Opus 5.5 标价，20 万 token 的记录每次命中缓存约 0.04 美元、未命中 0.8–1.6 美元，一个忙碌的 agent 即便全部命中缓存每小时也要约 4.8 美元。开启 OTel、对比 `agent_summary` 和 `repl_main_thread` 的花费即可自测。
2. **Same local model, 10 coding-agent harnesses, up to 11.7× token difference**: a Reddit test relayed by TeksEdge ran Qwen3.8-27B Q4 on an M5 Max 64 GB via llama.cpp (thinking off) through five small sandboxed coding tasks—Pi passed 5/5 in a median 38 s and 9.2K tokens, DeepSeek Harness 5/5 in 60 s and 35.3K, Codex CLI 5/5 in 94 s and 36.3K, Qwen Code 4/5 in 183 s and 107.9K. Picking the harness matters as much as picking the local model. https://x.com/TeksEdge/status/2116364538257740128
> [zh] **同一本地模型跑 10 个编程 agent harness，token 用量最多差 11.7 倍**：TeksEdge 转述的 Reddit 测试在 M5 Max 64 GB 上用 llama.cpp 跑 Qwen3.8-27B Q4（关闭思考），做 5 个沙箱内的小编程任务——Pi 5/5 通过、中位 38 秒、9.2K token；DeepSeek Harness 5/5、60 秒、35.3K；Codex CLI 5/5、94 秒、36.3K；Qwen Code 4/5、183 秒、107.9K。选 harness 和选本地模型一样重要。
