## 要点

- AI has inverted software economics: high upfront cost with zero marginal cost once made SaaS a licence to print money, but cheap generation collapses that margin and turns “selfie software” into disposable skills that non-technical staff create directly in Claude Artifacts with MCP connectors.
  > [zh] AI 颠倒了软件的经济账：过去前期投入高、边际成本为零，让 SaaS 像印钞许可证；如今生成成本极低，这份利润被压垮，「自拍式软件」变成非技术员工直接在 Claude 工件里配合 MCP 连接器就能做出的一次性 Skill。
- Single-function SaaS tools are already being replaced outright by Claude skills with live MCP data connections, not merely augmented; Gary stopped building his own SaaS presentation layer once customers could generate bespoke UIs on top of his MCP backend in Claude Artifacts.
  > [zh] 单一功能的 SaaS 工具已经被接入实时 MCP 数据的 Claude Skill 整体替代，而不只是增强；当客户能在 Claude 工件里基于他的 MCP 后端自己生成定制界面后，Gary 就不再做自家 SaaS 的界面层了。
- The emerging playbook: vertical SaaS gives way to forward-deployed engineering, which itself gets automated into a “meta-skill”, proprietary know-how packaged as repeatable, agent-assisted setup for each new client.
  > [zh] 正在成形的打法是：垂直 SaaS 让位于驻场工程（forward-deployed engineering），而驻场工程本身又被自动化成一种「元 Skill」，把自有经验封装成可重复、由 Agent 辅助的新客户上线流程。
- The real bottleneck is no longer technical ability but safe deployment: version control, preview environments, security scanning and access control have to be built invisibly into workflows made by people who don’t know what “prod” means.
  > [zh] 真正的瓶颈不再是技术能力，而是安全上线：版本控制、预览环境、安全扫描和权限控制，必须悄无声息地嵌进那些由不懂「生产环境」为何物的人搭出来的工作流里。
- In SMEs that adopt AI successfully there is usually a “Claude Lord”, often not the most senior or technical person, who drives skill creation; Gary’s practical tip is to run all agent sessions in the cloud (Claude Code Cloud, Codex Cloud and the like) rather than locally, for speed, continuity and less load on your machine.
  > [zh] 成功用上 AI 的中小企业里通常有一位「Claude 领主」，往往不是最资深或最懂技术的人，由他推动 Skill 的创建；Gary 的实操建议是把所有 Agent 会话放到云端（Claude Code 云端、Codex 云端等）而不是本地跑，速度更快、能持续运行，也减轻电脑负担。
