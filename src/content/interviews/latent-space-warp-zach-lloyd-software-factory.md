## 要点

- Warp defines its software factory in code and the demo follows a request from Slack all the way to a pull request.
  > [zh] Warp 用代码定义自己的软件工厂，演示中一个需求从 Slack 一路走到 PR。
- The team shares agent traces and scores runs on cost, throughput and quality, using benchmarks built from their own real engineering tasks rather than public suites.
  > [zh] 团队共享 Agent 轨迹，并从成本、吞吐和质量给每次运行打分，基准来自自己的真实工程任务而非公开题库。
- Zach reports that tuning models and subagent use brought Warp's internal cost from about $80 per PR to roughly $15–20, alongside higher throughput, and agents now help improve the factory that runs them.
  > [zh] Zach 称，通过调整模型和子 Agent 的用法，Warp 内部每个 PR 成本从约 80 美元降到 15–20 美元，吞吐同时提升；Agent 也在反过来改进运行它们的工厂。
- The conversation closes on who needs software factories and how the roles of product engineers and "factory engineers" are splitting.
  > [zh] 最后讨论了哪些团队需要软件工厂，以及产品工程师与「工厂工程师」的角色如何分化。
