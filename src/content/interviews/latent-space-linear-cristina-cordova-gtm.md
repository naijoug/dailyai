## 要点

- Agents created 3% of Linear’s work a year ago and more than half now; since its May 2025 MCP server Linear has added an agents platform with new APIs, integrations with Codex, Cursor and GitHub Copilot, and its own Linear Agent. It passed $100M ARR this year with 40,000+ paying customers and 177% net revenue retention.
  > [zh] 一年前 Linear 里 3% 的工作由 Agent 创建，现在超过一半；自 2025 年 5 月推出 MCP 服务器后，Linear 又做了带新 API 的 Agent 平台、与 Codex、Cursor、GitHub Copilot 的集成，以及自家的 Linear Agent。今年 ARR 突破 1 亿美元，付费客户 4 万多家，净收入留存 177%。
- She warns SaaS companies against settling for being a database with an MCP server on top: the agent workflows inside your product must beat the ones outside it. She tracks two lines, agent (MCP) usage and app usage; if agent usage climbs while app usage doesn’t, you are becoming a commodity. At Linear both are rising.
  > [zh] 她提醒 SaaS 公司不要满足于当「上面挂个 MCP 服务器的数据库」：产品内的 Agent 工作流必须比外部的更好。她盯两条线：Agent（MCP）用量和应用用量；如果前者上升而后者不动，你就在变成大宗商品。Linear 两条线都在涨。
- After Karri Saarinen’s “Issue tracking is dead” post, customers asked what they were buying; Linear’s answer is a product development system built around agent orchestration where humans stop manually filing, labeling, assigning and closing issues. Frontier labs running on Linear and companies like Ramp and Coinbase building internal agents pushed it there.
  > [zh] Karri Saarinen 发出《Issue tracking is dead》后，客户问「那我买的是什么」；Linear 的回答是围绕 Agent 编排的产品开发系统，人不再手动建、打标签、分派和关闭 issue。推动这一转向的是在 Linear 上运转的前沿实验室，以及 Ramp、Coinbase 等自建内部 Agent、需要 API 接入的公司。
- AI budgets are speeding purchases, but buyers now sign one-year deals and paid pilots instead of three-year contracts, and some overnight $100M stories are a handful of $30–40M contracts; renewals will show whose ARR was real. Linear ended all-seat pricing in June: Linear Agent chat stays free, coding sessions pass through published OpenAI/Anthropic API prices plus a small markup, and Loops run on AI credits.
  > [zh] AI 预算让采购变快，但买家现在签一年期合同和付费试点，而非三年合同；一些「一夜 1 亿美元」的故事其实是几笔 3000–4000 万美元的大单，续约时才见真章。Linear 6 月结束了纯席位定价：Linear Agent 聊天免费，编程会话按 OpenAI/Anthropic 公开 API 价格加少量加价转嫁，Loops 用 AI 积分计费。
- Go-to-market choices: no SDRs ever, no forward-deployed engineering, and support stays in-house with AI drafting replies but a human deciding what goes out; she wishes an outcome-based model like Intercom Fin fit Linear, but what auto-triaging a bug is worth differs by company.
  > [zh] 市场化选择：从不招 SDR，不做前线部署工程，客服留在内部，AI 起草回复但由人决定发什么；她希望能用 Intercom Fin 那种按结果收费的模式，但自动分派一个 bug 值多少钱，每家公司看法不同。

## 金句

- “I think you have to bring the agentic workflows into your tools, and you have to make them better than the tools that people would be using externally to interoperate with your system.”
  > [zh] 「我认为你必须把 Agent 工作流放进自己的工具里，而且要让它们比人们在外部用来对接你系统的工具更好。」
- “it doesn't mean that, like, now that agents exist, you, like, don't have to care about the interface.”
  > [zh] 「这并不意味着有了 Agent，你就不用在乎界面了。」
- “we probably shouldn't have a world where people are like manually tracking work.”
  > [zh] 「我们大概不该再处在一个人们手动追踪工作的世界里。」
