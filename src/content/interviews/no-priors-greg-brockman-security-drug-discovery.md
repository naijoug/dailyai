## 要点

- Brockman says nearly 400 century-old math problems have been solved with OpenAI’s agents, and biology/drug discovery is next.
  > [zh] Brockman 称 OpenAI 的 Agent 已解决近 400 个百年数学难题，生物与药物研发是下一站。
- Proactive, always-on agents like Dots change productivity; he argues the best UI is no UI at all.
  > [zh] Dots 这类主动、常驻的 Agent 改变生产力；他认为最好的 UI 是没有 UI。
- Cybersecurity is in a critical window to use peak intelligence to find and fix vulnerabilities, while keeping humans in the driver’s seat.
  > [zh] 网络安全正处于关键窗口期，应借助最强智能发现并修复漏洞，同时让人类始终掌控方向。
