  > [en] In nine months Treg pivoted three times: from the design agent SuperDesign, to a fully automated growth agent, to Treg, which supplies data and tools to agents.

  > [en] A Codex plugin unexpectedly changed their growth curve; they argue data browsers can’t reach is where the agent tool market’s value lies.

  > [en] The guests argue the ‘zero-person company’ doesn’t hold up, and that running 5–10 sessions at once makes humans the bottleneck.

  > [en] Takeaway: build on Claude Code and Codex — tools growing around coding agents (Ego, ChatCut, etc.) are the new platform opportunity.
