## 要点

- Agents are approaching the point of using computers faster than expert humans, making the UI a universal interface for AI.
  > [zh] Agent 使用电脑的速度正逼近专家级人类，UI 本身成为 AI 与软件交互的通用接口。
- Computer-using agents already navigate legacy ERPs, reconcile financial data and handle procurement without APIs.
  > [zh] 会用电脑的 Agent 已能在没有 API 的情况下操作老旧 ERP、对账和处理采购。
- The harness around the model can matter as much as model intelligence; enterprises can set deterministic guardrails on agent behavior.
  > [zh] 模型外围的 harness 与模型智能同样重要；企业可以给 Agent 行为设定确定性护栏。
